セキュリティ

続報Next.js が定例更新で脆弱性 7 件を修正

Next.js は 9 月 30 日の定例セキュリティリリースで 16.3.8（Active LTS）と 15.5.27（Maintenance LTS）を公開し、脆弱性 7 件（high 1・medium 5・low 1）を修正した。最も重いのは画像最適化の SSRF（CVE-2026-94483）で、images.remotePatterns に攻撃者が操作できるリモートホストを許可している場合に影響する。

medium は自己ホスト環境の SSG/ISR キャッシュ汚染や、Cache Components 下での Draft Mode コンテンツ漏洩などが中心。当初 9 件を予告していたが、critical 1 件と high 1 件は上流依存の遅延で見送られ、後続リリースに回った。対象バージョンを使う現場は即時アップグレードが要る。

フレームワーク・ランタイム

Cloudflare が Vite 版 Next.js の Vinext 1.0 を公開

Cloudflare は 9 月 28 日、Vinext 1.0 を公開した。Next.js の API をそのまま保ちながら、ビルド基盤を Next.js 本体から Vite に置き換えるもので、next を vinext に差し替えるだけで App Router・Pages Router の両方が動く。

狙いは Next.js アプリの可搬性だ。Cloudflare Workers の無料プランや Netlify、AWS Lambda など任意の環境へデプロイできる。顧客要望の機能で 99% を超える互換を達成したとするが、use cache を使う Cache Components は対応が限定的で、元は 1 週間の AI 実験として始まったプロジェクトが製品版に達した形だ。

ブラウザ・プラットフォーム

続報Chrome 155 が安定版に到達

Chrome 155 が安定版に入り、10 月 6 日からデスクトップで広く配信される。iOS/iPadOS には 10 月 1 日に到達済み。同じ 9 月 30 日には次の Chrome 156 が beta 入りしており、2 週間周期のリリースが実際に連続して回っている。

9 月は Chrome と Firefox がともに隔週リリースに移った最初の月で、Chrome 153・154、Firefox 155〜157、Safari 27 が相次いで安定版になった。周期が半分になったぶん、beta 追従と stable 展開の間隔管理が実務で効いてくる。

デザイン・UI（CSS）

CSS の progress() などが Baseline に加わる

9 月の Web プラットフォームまとめで、複数の CSS 機能が Baseline（newly available）に到達した。目玉は数式関数 progress()で、Firefox 155 の対応により、開始値と終了値の間の位置を数値で返し、ビューポートに応じた滑らかなサイズ指定ができる。

ほかに透明度だけを変える相対色関数 alpha()、画像（URL・グラデーション）も扱えるようになった light-dark()、ルール適用前に戻す revert-rule、font-stretch の正式名となる font-width、スクロールアンカリングの overflow-anchor が加わった。
