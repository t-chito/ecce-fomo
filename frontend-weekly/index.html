まとめ

先週号の主役だった「予告つきセキュリティの定例運用」が、今週はフレームワークからランタイム層へ飛び火した。Node.js が 7 月 29 日に協調セキュリティリリースを出し、11 件（高 3・中 5・低 3）を 26.5.1／24.18.1／22.23.2 で一斉に塞いだ。高深刻度は HTTP/2 の 2 件と Permission Model のパス境界の 1 件で、Next.js の月次と同じ「まとめて・同時に」という運用律がそのまま runtime に現れた。もう一つの通奏低音「ネイティブで速い基盤」は、今週は大玉の GA ではなく足元のツール層で進んだ。SvelteKit 3 が @next プレビュー入りし、Oxlint 1.75 が型認識リントを stable 化、Rolldown 1.2 も HMR 周りを詰めた。一方で先週 RC まで来た二枚看板、Vue 3.6 は RC のまま（GA は秋見込み）、TS7 のテンプレート型チェック解禁も 7.1（10 月ごろ）待ちという足踏みは今週も動かず、「速い実装は先行するが、型基盤の全面解禁は秋にまとめて」という構図が続いている。

今週の重要ポイント

Node.js が協調セキュリティリリース — 11 件を 3 系列同時に、高深刻度は HTTP/2 と Permission Model

先週号が「Next.js の月次セキュリティ＝予告つき・まとめて着地」を最大の焦点に据えた直後、同じ運用律がランタイム側でも回った。7 月 29 日（水）、Node.js が 26.x／24.x／22.x の全アクティブ系列で協調リリースを出し、26.5.1・24.18.1・22.23.2 をそろって公開した。修正は計 11 件（高 3・中 5・低 3）で、依存もあわせて undici（8.9.0／7.29.0／6.28.0）と llhttp 9.4.3 を引き上げている。「決まったタイミングでまとめて来る」ため、CI やインフラ側で検証・ロールアウトの枠を組みやすい点は Next.js の月次と同じ狙いだ。

高深刻度の 3 件は運用インパクトが読みやすい。CVE-2026-56846 は HTTP/2 の保持ヘッダが maxSessionMemory の上限を回避してリモートからメモリを枯渇させられるもの、CVE-2026-56848 は nghttp2_session_mem_recv() 実行中に送信処理が再入して起きるヒープ use-after-free、CVE-2026-58043 は Permission Model の radix-tree なプレフィックス境界処理の綻びで、--permission の allowlist 外のパスを読み書きできてしまうというもの。HTTP/2 を終端しているサーバと、--permission でサンドボックス的に締めている構成が優先更新対象になる。先週の「安全運用が予告どおり届く」という確定が、今週は基盤ランタイムでも同じ形で示された。

SvelteKit 3 が @next プレビュー入り — 13 本の先行版で shallow routing と設定・環境変数を再編

先週まで RC・GA の主役は Vue と Next.js だったが、今週はもう一つの Volar 系スタックである Svelte が大きく動いた。月次の「What's new in Svelte（8 月）」で SvelteKit 3 の最初の @next リリースが告知され、7 月中に 13 本のプレビュー版が積まれたことが明らかになった。目玉は shallow routing の goto への統合で、pushState／replaceState を goto の state オプション（+persistState）に一本化する（3.0.0-next.13）。あわせて noScroll／keepFocus を単一の reset に畳み、ナビゲーション API の面積を絞っている。

構成面の変更も実務に効く。SvelteKit の設定を vite.config.js に直接書けるようになり、svelte.config.js を省略可能にする方向へ舵を切った。加えて $env/* を将来的に置き換える明示的な環境変数の初回プレビュー、ビルド情報を露出する $app/manifest、旧 $service-worker を差し替える $app/service-worker、本番ソースマップ対応（next.11）などが入った。安定版側も remote forms の submitted 追加（2.69.0）や defineEnvVars の @sveltejs/kit/env への移設（2.70.0）が進む。Svelte のテンプレート型チェックも Vue 同様 TS7.1 待ちである点は変わらないが、フレームワーク本体は次メジャーの輪郭を先に固めにきた。

型認識・Rust 製ツールチェーンが前進 — Oxlint 1.75 が型認識リントを stable 化、Rolldown 1.2 も成熟

「ネイティブで速い基盤」という先週からの軸は、今週フレームワークではなくリンタ／バンドラの層で具体化した。Oxlint 1.75 で型認識リント（type-aware linting）が stable に到達し、型情報を要する 43 個のルールが追加で有効化された。TS7（tsc ネイティブ化）はテンプレート型チェッカ勢をまだ載せられない一方で、Rust 製リンタ側は「型を見るチェック」を先に実運用へ出してきた格好で、`tsc は TS7・型情報付きリントは別系統` という折衷の現実的な受け皿になる。

バンドラ側でも Rolldown 1.2 が HMR・watcher・tree-shaking・ソースマップを一段詰め、Vite 8 が採る Rust 単一バンドラ路線の安定化が続く。周辺では pnpm 11.11〜11.14 がワークスペースのリリース管理と診断ツールを拡充し、magic-string 1.0 がソース操作ユーティリティの節目を迎えた。TS ネイティブ化・Rolldown・Oxlint と、フロントの下回りが軒並み Rust／ネイティブへ載せ替わる流れの中で、今週は「速い基盤の上でリント精度を落とさない」ための整備が前に出た。

フレームワーク・ランタイム

Next.js 16.3 の Instant Navigations が preview で成熟 — 7/21 セキュリティ修正も canary/preview に取り込み

先週は 16.3 preview の Turbopack 永続キャッシュを取り上げたが、16.3 系のもう一つの目玉Instant Navigations（と Partial Prefetching）も preview で形を整えつつある。リンクごとの prefetch をやめ、ルート単位で再利用可能なローディングシェルを 1 つだけ prefetch してクライアントにキャッシュする設計で、ナビゲーションを Streaming（Suspense のシェル表示）か Caching（use cache の再利用）で即時化し、必要な経路だけ Block でサーバ待ちに戻せる。cacheComponents と partialPrefetching の両フラグを有効化して next@preview で試せる、opt-in の段階提供だ。DevTools の Navigation Inspector や Playwright 用 instant() ヘルパといった検証系も同梱される。

運用面では、先週の月次セキュリティとの接続が見える。7 月 21 日に 16.2.11／15.5.21 で塞いだ高 4・中 5 の修正が、16.3.0-canary.92／preview.7 にも取り込まれ、16.3 が stable 化した時点でその系列にも入る。安定版ラインを 16.2 に据えつつ、preview 側で新機能とセキュリティ修正を並走させる「メジャーで飛躍・パッチで均す」サイクルが、16.3 でも一貫している。

Vue 3.6 は RC のまま GA 待ち — Vapor は feature-complete、解禁は秋にまとまる見込み

先週号で「3.0 以来最大」と評した Vue 3.6 は、今週は新展開ではなく据え置きの確認だった。7 月 18 日の rc.1／22 日の rc.2 のあと、stable（GA）は秋ごろ見込みという位置づけが続く。Vapor Mode は feature-complete だが RC 段階では unstable 扱いのままで、alien-signals による reactivity 刷新（省メモリ）は既存アプリにも効く一方、Vue のテンプレート型チェック（Volar 系）は TS7.0 では動かず 7.1 待ちという壁も先週から不変だ。今週 @next に入った SvelteKit 3 と合わせ、「本命の新実装は RC・preview まで来たが、型基盤の全面解禁は TS7.1（10 月ごろ）へ束ねられている」という秋待ちの構図が、SFC 系スタック全体で共通している。

エコシステム・ツール

shadcn が React Aria を一級サポート、CSS は Lightning CSS 1.33、そしてエージェント評価の ReactBench

コンポーネント／CSS 周りも動いた。shadcn CLI 4.13.1 が Radix・Base UI に続いて React Aria を一級のヘッドレス選択肢として加え、アクセシビリティ基盤の選択肢が広がった。CSS ツールでは Lightning CSS 1.33 が alpha()、アンカー配置の @position-try、擬似要素サポートを追加し、先週の Chrome 143/144 系で進む anchor positioning のブラウザ実装に、ビルド側の変換が追随している。周辺では Astro 7.1 がページネーション制御・CSP 設定・複数 dev サーバを載せてパッチ整備を継続した。

異色の一手として、Million.js チームが ReactBench を公開した。実プロダクト規模の React タスクでコーディングエージェントの成果を、挙動・パフォーマンス・アクセシビリティ・コード品質の観点から採点するベンチマークで、初期の首位は GPT 5.6 とされる。フレームワークやツールの更新と並んで、「AI にフロントの実装をどこまで任せられるか」を定量で測る土俵づくりが、エコシステムの話題として一段前に出てきた。

来週の注目ポイント

Next.js 月次セキュリティの「二号目」— 8 月の定例が予定どおり出るか

先週の最大の宿題がそのまま残る。初号（7/21）と追いパッチ（7/25）が予告どおり回った以上、8 月に予定される二号目が同じ日程規律で着地するかが継続ウォッチだ。今週 Node.js が協調リリースを出したことで「予告つきセキュリティ」は runtime にも広がったが、Next.js 側の二号目はまだ公開されていない。あわせて、16.2 が backport した TS7 対応を 15.5 系が受け入れる方向へ転じるのか、「拒否」を維持するのかも、旧 LTS 継続チームの移行計画に直結する論点として残る。

Vue 3.6 の GA と、SvelteKit 3 プレビューの安定化

秋に束ねられた解禁の前段として、Vue 3.6 が rc から stable（GA）へいつ進み、feature-complete でも unstable と位置づけられた Vapor Mode が本番推奨に格上げされる条件が最初の焦点。今週 @next 入りした SvelteKit 3 のプレビューがどこまで詰まるか（設定の vite.config.js 統合、明示的環境変数の固まり具合、shallow routing 統合の安定度）も、両 SFC 系スタックの次メジャー移行を占う材料になる。

TypeScript 7.1 のプログラマティック API — テンプレート型チェック解禁の前提

Vue・Svelte・Angular・Astro・MDX のテンプレート型チェックを TS7 上で動かす鍵となる安定版プログラマティック API は 7.1（10 月ごろ想定）が主要成果物。今週 stable 化した Oxlint の型認識リントは別系統で先行したが、Volar 系の型チェッカと typescript-eslint／ts-morph などが TS7 に載るのは 7.1 待ちで、当面は @typescript/typescript6（tsc6）併用が続く。この API の preview やロードマップ更新が出れば、Vue 3.6 GA・SvelteKit 3 と足並みをそろえた型基盤の全面移行計画を描ける。
