セキュリティ

続報Next.js が臨時更新で致命的 RCE 2 件を修正

Next.js は 10 月 14 日に帯域外のセキュリティ更新を公開した。修正は v16.4.1（Active LTS）と v15.5.28（Maintenance LTS）に入り、9 月の定例で上流依存の遅れにより見送られていた分が含まれる。自己ホストする現場は速やかな適用が要る。

致命的な 2 件はいずれも認証不要の遠隔コード実行（RCE）だ。use cache が複数の TypedArray を返す場合の RCE には回避策が無く、該当機能を使っていなくても更新が推奨される。画像最適化の SVG 処理の RCE は、同梱の sharp を 0.35.5 以上にすることで回避できる。

フレームワーク

TanStack Start 1.0 が安定版に到達

フルスタックフレームワーク TanStack Start が 1.0 になった。React と Solid の両方に対応し、SPA 的なルーティングとキャッシュを土台に、サーバレンダリングと型付きのサーバ関数を足す「クライアント優先」の構えを取る。

ルートパラメータ、検索パラメータ、ローダのデータ、サーバ関数の入力まで型が通る。RSC は任意で有効化する方式とし、配信は Vite と Nitro（Rsbuild も可）を通す。

ランタイム・プラットフォーム

Deno チームが Cloudflare に合流する

Ryan Dahl 氏は 10 月 9 日、Deno チーム全員が Cloudflare に加わると発表した。今後は Workers と Durable Objects を軸にした共通基盤に注力し、独自ランタイムとホスティングの単独路線からは退く。

影響は段階的だ。Deno ランタイムはあと 1 年、毎月のバグ・セキュリティ修正を受けたうえで開発を終える（OSS としては存続）。Deno Deploy は半年で停止し、有料顧客には Workers への移行支援が付く。JSR は Cloudflare 基盤へ移して存続する。

Web プラットフォーム・ブラウザ

主要ブラウザが JPEG XL と新しい CSS を載せる

ブラウザ側の足並みも進んだ。画像形式の JPEG XL が Chrome 155 と Firefox 158 に入り、Safari は部分対応となった。長く停滞していた形式が、主要エンジンでようやく実装の段階に入る。

CSS では Safari Technology Preview 254 が calc-size() と interpolate-size を載せ、auto への高さアニメーションに道を開いた。Chrome 154 は frame-sizing: content-height を出荷し、iframe を中身の高さに合わせられるようにした。
