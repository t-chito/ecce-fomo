続報React 本体に認証不要の遠隔コード実行

React Server Components（RSC）に、認証不要の遠隔コード実行（RCE）が見つかった。深刻度は Critical（9.5）で、細工したペイロードが RSC 対応フレームワーク上でサーバ側のコード実行につながる。影響は react-server-dom-webpack ・ -turbopack ・ -parcel の 19.0.0〜19.3.0 に及ぶ。

修正は 19.0.9 / 19.1.10 / 19.2.9 / 19.3.1 に入り、Server Functions の DoS 修正も同梱される。クライアント専用の SPA は対象外だが、キャレット指定やロックファイル、推移的依存が脆弱な版を抱え込むことがあるため、npm ls react-server-dom-webpack などで実際の解決版を確かめるとよい。

Shopify Hydrogen がライブラリへ転換

Shopify の Hydrogen 2026-10 が一般提供になった。これまでの独自フレームワークをやめ、既存フレームワークに足すライブラリに作り替えた。カートやバリアント選択、顧客ログインといった商取引の部品を担い、ルーティングやデータ取得、描画は乗せる側のフレームワークに任せる。

スタータは React Router と Next.js 向けが用意され、WebMCP にも対応する。ホスティングは任意で、無料の Oxygen も引き続き使える。既存プロジェクトは 2026-04 以前から移行でき、React Router 系パッケージの版を揃えて一括更新するよう案内されている。

Web プラットフォーム・ブラウザ

Chrome 156 が CSS の乱数と遷移元疑似クラスを搭載

Chrome 156 が 10 月 20 日に安定版となった。CSS に乱数を生む random() と、ページ遷移を起こしたリンクやボタンに当たる :navigation-source 疑似クラスを載せた。後者は View Transitions と組み合わせ、遷移元の見せ方を CSS で指定できる。

スクロール関連も進んだ。overflow: scroll clip で片方の軸だけをスクロールコンテナにでき、scroll-snap-type: pair は両軸を同じ要素にスナップさせる。内部では IndexedDB の保存先を SQLite 基盤へ移し、353 件のセキュリティ修正も入った。

Edge 156 がネイティブ XSLT を非推奨化

Microsoft Edge 156 が 10 月 22 日に出た。Chrome と同じ random() や :navigation-source、単軸スクロールコンテナを入れつつ、ブラウザ内蔵の XSLT を非推奨とし、XSLTProcessor API を既定で無効化する方針を示した。CSS からのスタイルシート参照は影響を受けない。
