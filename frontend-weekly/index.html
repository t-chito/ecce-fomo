セキュリティ

続報Next.js がキャッシュ周り中心に 7 件の脆弱性を修正

Vercel は予告どおり 11 月 3 日に定例セキュリティ更新を出した。修正版は 16.4.5（Active LTS）と 15.5.29（Maintenance LTS）。7 件のうち最も重いのは高深刻度の「テナント間キャッシュ漏えい」で、unstable_cache と use cache を組み合わせたとき、別テナントの結果が混ざりうる。

残り 6 件は中深刻度で、Cache Components とキャッシュまわりに集中する。Edge ルートで HttpOnly クッキーが内部ヘッダ経由で漏れる問題や、画像最適化で SVG 拒否を回避される問題も含む。Cache Components を使うアプリは早めに更新する。

GitHub Actions が pull_request_target を既定で遮断

GitHub は 12 月 2 日から public リポジトリで pull_request_target を既定で無効化すると告知した。このトリガは fork からの PR でも書き込み権限付きで走るため、秘密情報の漏えいや任意コード実行の踏み台になりやすかった。必要なワークフローは設定で明示的に許可する形に変わる。

Next.js が先読み遷移と Go ルートを試験導入

Next.js に実験的な機能が相次いで入った。router.experimental_prepare() は pointerdown で遷移を先に始め、click で確定する。create-next-app は App Router に固定され、ルータ選択のプロンプトを廃止した。さらに route.go ファイルで Go 製のルートハンドラを書ける実験も始まった（まず Route Handlers と Proxy から）。

React Native・モバイル

React Native 0.89 RC が 12 月の正式版へ前進
