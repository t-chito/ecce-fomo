まとめ

先週は「速く回す列車が平時と有事の両方で走った週」と書いた。今週、その有事のほうが「臨時」から「定例」へと座を移した。先週予告された out-of-band は 9 月 22 日に16.3.6 / 15.5.26 として実際に着地し、伏せられていた正体は next/og（Satori 経由）の RCE だと開示された。そして翌 23 日、Next.js は間髪入れず次の「定例」セキュリティリリースを 9 月 30 日に予告——今度は 1 件ではなく9 件（critical 1・high 2・medium 5・low 1）をまとめて配る。片やブラウザ側では Chrome 155 が 2 週間 cadence の「2 本目」を回し、周期は「宣言」から「習慣」に変わった。速い周期は、機能でもパッチでも、もう常態だ。今週は「速さが例外でなくなった週」だ。

今週の重要ポイント

先週の「上流依存の謎」が判明 — 正体は next/og（Satori）の RCE、16.3.6 で修正済み

先週「来週の最大の関心事」に挙げた GHSA-vcvr-r3jv-pc5j の全貌が、予告どおり 9 月 22 日のリリースと同時に開けた。out-of-band 更新は 16.3.6（Active LTS）と 15.5.26（Maintenance LTS）として着地し、伏せられていた上流依存の正体は Satori——next/og の Node.js 版 ImageResponse が生成する SVG のエスケープ不備から、他の上流依存の脆弱性と連鎖してリモートコード実行（RCE）に至りうる、という critical だった。影響は >=16.2.0 <16.3.6。修正は依存の巻き上げで行われ、Edge 版 ImageResponse は非該当、15.5.26 は関連 hardening のみ（15.x は RCE の影響を受けない）。先週の見立て「アプリのコードは 1 行も間違っていなくても晒される」は、OGP 画像を動的生成しているだけの現場が該当しうる、という形で具体になった。

「臨時」の翌日に「定例」を予告 — Next.js が 9/30 に脆弱性 9 件をまとめて配る

out-of-band の翌日、9 月 23 日に Next.js は次のセキュリティリリースを 9 月 30 日に予定と告知した。先週の緊急パッチが 1 件を臨時で差し込んだのに対し、今回は9 件——critical 1・high 2・medium 5・low 1——をまとめて、通常の予告つき定例として配る。公開されるのは 16.3.7 と 15.5.27で、影響・対象バージョン・アップグレード手順を含む advisory がリリースと同時に出る。ポイントは、たった 1 週間で「速く小さく」の対象が機能から緊急パッチへ、さらに定例のまとめ配信へと段階を上げたことだ。事前告知でアップグレードの計画時間を渡す運用は先週と同じ形。16 系・15 系を運用する現場は 9/30 に即時アップグレードの再演を見込んでおきたい。

  • Next.js Security Advisories — nextjs.org

Chrome 155 が「2 本目」を回した — cadence は宣言から習慣へ

先週の Chrome 154 が 2 週間 cadence の「最初の通常ラップ」だった。今週その2 本目が回った。Chrome 155 は 9 月 16 日に beta へ出て、Android では 9 月 23 日から Early Stable（一部ユーザー先行）に入り、大半への展開は 10 月 6 日から。154 のわずか約 2 週間後という間隔で、「宣言どおりの周期が 2 回続いた」——これで新 cadence は「言った」ではなく「回っている」段階に入った。先週書いた「2 本目が本当に 2 週間で来るか（宣言→習慣）」への答えは Yes だ。中身も実務に効く小粒〜大玉が揃う（後述）。beta 追従の重要度は、周期が半分のまま今週さらに定着した。

React 19.3 対応の波が広がる — Astro React 7 は Babel を捨て Oxc へ

先週「卒業生が現場に配属」と書いた React 19.3 のエコシステム追従は、今週も裾野を広げた。React Three Fiber 9.8 が 19.3 対応と同期的な root 構成を入れ、TanStack の同期版 React 再実装 Redact 0.1 も 19.3 API を前提に GitHub 公開。React Redux 9.4 alpha は react-redux/signals 経由で useSignalSelector() と <SignalProvider> を追加し、数千接続規模の最適化に踏み込んだ。象徴的なのは @astrojs/react 7.0——JSX コンパイルと Fast Refresh のBabel を Oxc（Rust 製）に置き換え、@vitejs/plugin-react を v6 に上げ、Oxc 経由の実験的 React Compiler 対応（compiler: true）まで入れた。19.3 という「卒業生」を受け入れる足場そのものが、Babel から Rust ツールチェインへ置き換わりつつある。

セキュリティ

「OGP 画像を動的生成しているだけ」が攻撃面になる — next/og 運用の点検

今回の RCE で現場が読んでおきたいのは、攻撃面が「派手な機能」ではなく next/og の ImageResponse という日常にあった点だ。動的な OGP 画像や動的 SVG 生成を Node ランタイムで回しているアプリは、ユーザー入力が SVG に混ざる経路を持てば該当しうる。実務は 3 つ——(1) 16.3.6 へ即上げる（15.x は RCE 非該当だが hardening 込みの 15.5.26 へ）、(2) ImageResponse を Edge ランタイムで動かしていれば非該当なので自分の構成を確認、(3) 上流の Satori（GHSA-wx4j-mvgx-mqwp）を別経由で抱えていないか依存ツリーを点検する。そして 9/30 の定例 9 件が控える以上、この「上げる→点検」を来週も一度回す前提でおくのが安全だ。先週の「同じ上流の広がり」への回答が Satori だったことで、監査の当たりどころは絞れた。

ブラウザ・プラットフォーム

Chrome 155 の中身 — CSS の形づくりと、壊れないモジュール読み込み

2 本目らしく、Chrome 155 は形（shape）と堅牢さ（robustness）に効く更新が並ぶ。CSS では corner ショートハンド（corner-top-left ほかで border-radius と corner-shape を同時指定）と、@counter-style なしでインライン定義できる symbols()、余白を刈る margin-trim、そして先週の 154 に続く text-decoration-skip-spaces が入る。JS 側の目玉は失敗したモジュール読み込みのリトライ——不安定なネットワークで import がコケても再試行できる長年の要望に応えた。import … with { type: "text" } の Text Modules でテキストを文字列として読み込める。Web API では Window Management（maximize()/minimize()/restore()/setResizable()）、JPEG XL の復号（Rust 製 memory-safe デコーダ jxl-rs）、Digital Credentials、WebTransport のカスタムヘッダなどが加わる。「小さく確実に」を 2 週間で積む号だ。

足回りも Rust 化と自動化へ — pnpm 12.6・Turborepo 2.11・Node 26.10・ESLint 10.11

Astro React 7 の Oxc 採用に象徴される Rust ツールチェインへの移行は、周辺の足回りでも進んだ。pnpm 12.6 は自動 dedupeと型定義の自動導入、file:/link: catalog 対応を入れ、CI で手動 dedupe を回す手間を消した。Turborepo 2.11 は Rust / Python / Go のネイティブ対応と起動高速化を追加し、モノレポの守備範囲を JS の外へ広げた。Node.js 26.9 / 26.10 は Web Workers 対応、ネイティブ throttle/debounce、bench を、ESLint 10.11 は初期化 20〜25% 高速化を、jsdom 30.1 は性能・メモリ・正確性の改善を届けた。派手な GA が足踏みする間も、ビルド・テスト・依存管理の土台は着実にマイナーを刻み、その方向は一貫して「速い言語で書き直し、手作業を自動化する」だ。

Vue 3.6 は今週も RC のまま — 「秋 GA」窓は開かず

先週に続き Vue 3.6 は今週もRC 段階に留まった。仮想 DOM を外す Vapor Mode と alien-signals ベースのリアクティビティ刷新は feature-complete としつつ、「秋 GA」の予告は据え置きのまま。React が 19.3 で波を 1 つ卒業させ、そのエコシステム追従が今週さらに広がったのと対照的に、Vue の次の卒業生はまだ足踏みだ。「一斉ではなく 1 つずつ、見立てと違う順に割れる」という数週来のパターンは今週も崩れていない。

来週の注目ポイント

9/30 の Next.js 定例 9 件 — critical の中身と、上げ直しの週

来週の最大の予定は 9 月 30 日の Next.js セキュリティリリースだ。16.3.7 / 15.5.27 と同時に 9 件の advisory が公開され、とりわけ critical 1 件が何か——先週の Satori/next/og のように「日常の機能」が攻撃面になるのか——が焦点になる。今週 16.3.6 へ上げたばかりの現場も、1 週間で再度の上げ直しを迫られる可能性が高い。out-of-band から定例へと続いたこの 2 週間で、依存監査を「定期業務」として回す構えが問われる。

Chrome 155 の 10/6 本展開と、2 週間 cadence の「3 本目」

Chrome 155 は 10 月 6 日から大半への展開に入る。2 本連続で回った cadence が3 本目も同じ間隔で来るか——「習慣」がさらに「制度」に固まるかを来週以降で確かめたい。合わせて、Vue 3.6 の「秋 GA」窓（9 月後半〜10 月）と SvelteKit 3 の RC 脱出がどちらが先かも引き続き見どころ。速い周期が常態化する中で、「1 つずつ、違う順に割れる」パターンが続くのかを追う。
