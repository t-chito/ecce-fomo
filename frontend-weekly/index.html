セキュリティ

Node.js が 3 系統で高深刻度の脆弱性を一斉修正

Node.js は 11 月 11 日に 22・24・26 系統の定例セキュリティ更新を出した。修正は 15 件で、うち 7 件が高深刻度。多くが HTTP/2 と TLS まわりに集中する。ストリーム破棄時の use-after-free で解放済みメモリ（TLS 鍵を含みうる）が相手に送られる問題や、TLS 1.2 の再ネゴシエーションでクライアント証明書認証を迂回される問題を含む。

修正版は 22.23.5・24.22.3・26.13.1。HTTP/2 や mTLS を使うサーバは影響が出やすいので、該当ラインは早めに更新する。

フレームワーク・ランタイム

X が web アプリを Vite と React で作り直し

X が web アプリを一から書き直したと公表した。ビルドを Webpack から Vite、サーバを Express から Fastify に替え、React のストリーミング SSR と Relay・GraphQL でページを上から順に描画する。GraphQL の応答はページに埋め込み、ブラウザ側の再取得を省く。

低速 4G での初投稿表示は約 24 秒から 約 2.7 秒に縮んだという。大規模サービスが近年のビルドツールとサーバ構成に乗り換えた実例として注目された。

React Native・モバイル

Discord が Electron と React Native をやめ Rust へ

Discord が desktop と mobile のクライアントを Rust 製の共有コアに作り直すと CTO が明らかにした。desktop は Electron をやめ、UI 描画に Zed 発の GPUI を使う。mobile は React Native をやめ、ネイティブ UI に Rust のロジックを共有する。

初期の Windows ビルドは 約 290MB のメモリで動いたという。時期は未定だが、脱 Electron・脱 RN の大きな事例として話題になった。
