フレームワーク・ランタイム

Next.js 16.4 が Cache Components を全アプリで推奨

Vercel は 10 月 6 日に Next.js 16.4 を公開した。目玉は Cache Components で、'use cache' を付けたコンポーネントだけをキャッシュ対象に印付けする段階的なキャッシュモデルだ。16.4 から全アプリへの推奨構成となり、create-next-app の既定で有効、次の v17 では標準になる。

新たに ensureStatic が入り、静的であるべきルートに動的処理が紛れ込むとビルドを失敗させられる。prefetch から特定の内容を外す navigation() も加わった。同梱の React 19.3 は View Transitions と Fragment Refs を安定化している。

土台の改善も多い。Turbopack はディスクキャッシュを 20〜25% 削減し、共有ランタイムで配信量も減らした。Rust 版 React Compiler はメモリを 30%、コンパイル時間を 15% 削減し、next upgrade --agent などエージェントによる更新支援も広げた。

セキュリティ

続報Next.js が 10 月 14 日に臨時セキュリティ更新を予告

Next.js は 10 月 14 日に帯域外（out-of-band）のセキュリティ更新を出すと予告した。上流依存にある critical 2 件と high 1 件の脆弱性を修正する。9 月 30 日の定例リリースで上流の遅れにより見送られた分が、ここで公開される見込みだ。

公開前のため、対象の依存・修正版・CVE 番号はまだ開示されていない。critical を含むので、Next.js を自己ホストする現場は、公開後にすみやかな適用の判断が要る。詳細は当日の security ページで確認する。

React Foundation・コミュニティ

React Foundation が体制を強化しイベントを拡充

React Foundation が組織とイベントを広げている。Barbara Markiewicz 氏が Director of Community に就任し、コミュニティ運営の専任体制が整った。

11 月には地域イベントが続く。React Conf Ghana が 11 月 4〜5 日にアクラで、Contributors Summit が 11 月 10〜12 日にロンドンで開かれる。サミットは招待制だが、エコシステムの貢献者は自己応募もできる。

React Native・モバイル

React Native Skia 3.0 が Graphite で描画を刷新

React Native Skia 3.0 が公開された。描画基盤を Skia Graphite に載せ替え、マルチスレッド描画、WebGPU との対称性、Three.js とのゼロコピー連携を実現した。

下回りも整理し、Android の最小 SDK は 26 に上がり、OpenGL を廃して Vulkan に一本化した。あわせて Callstack の React 特化コーディングモデル Apex が一般提供を始めた。
