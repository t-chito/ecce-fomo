セキュリティ

Next.js が全 PR に敵対的なセキュリティ審査を導入

Next.js は新しいコードに脆弱性を入れないため、Vercel Agent の Security Review を全 PR で走らせ始めた（11 月 17 日公表）。独自のガイドラインに沿って変更を攻撃者の視点で突き、CI を通過してマージ直前だった PR から問題を見つけた例もあるという。

背景には advisory の急増がある。AI が既存コードのバグ発見を安くしたためで、2026 年の 51 件のうち 70% は 1 年以上前のコードに由来する。利用者向けには next dev・next build が脆弱な版を警告し、npx next@canary upgrade --agent で安全な版へ上げられる。

フレームワーク・ランタイム

Solid 2.0 が非同期をリアクティブグラフに統合

Solid 2.0 が安定版になった（11 月 16 日）。計算が Promise や async iterator を返せるようになり、isPending と Loading で保留中の UI を扱う。投機的な状態は自動で巻き戻る。Server Functions がコアに入り、RPC と Server-Sent Events に対応した。

開発ビルドはリアクティブの誤りを、安定したコードと修正案つきで報告する。一方で createResource・batch・startTransition などの API は削除された。SolidStart は廃止され、役割はコアとフレームワーク非依存の Vite プラグインが引き継ぐ。

ビルド・ツールチェーン

Webpack が CSS と HTML をプラグインなしで扱えるように

Webpack 5.109 は CSS と HTML をビルトインで扱えるようにした（11 月 16 日）。import "./styles.css" が動き、@import と url() を解決し、*.module.css を CSS Modules として扱う。HTML をエントリにすれば、参照したスクリプトや画像をまとめて URL を書き換える。

これにより css-loader・style-loader・mini-css-extract-plugin・html-webpack-plugin などが非推奨になった。既存設定はそのまま動き、移行用の codemod も用意される。

Oxlint が型を見る lint の高速なバックエンドを追加

Oxlint に型を見る lint の新バックエンド tsrs が入った（11 月 17 日）。TypeScript を Rust に移植したもので、従来の tsgolint 比で最大 5 倍速く、メモリ使用は約 70% 少ない。typescript-eslint と比べればさらに大きな差が出るという。

tsgolint v7.0.2007 の 61 ルールをすべて実装し、設定や診断はそのまま使える。pnpm i -D oxlint tsrs の後、oxlint --type-aware で試せる。

デザイン・UI

Vercel が agent 操作を前提にした UI SDK を beta 公開

Vercel UI SDK の beta が出た（11 月 12 日）。キーボード操作・フォーカス・ポップアップなどの振る舞いを createRovingFocus のような関数で提供し、必要な ARIA 属性も含む。React・Vue・Svelte・Solid・Web Components で同じ部品が使え、スタイルは利用者が付ける。

createAgent を使うと、agent が利用者の定めた権限の範囲でページを読んで操作できる。ブラウザ内蔵 agent 向けの WebMCP にも対応する。
