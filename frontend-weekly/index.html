2026年8月25日（火） 過去1週間

まとめ

先週号は「サプライチェーン攻撃の実害と、それを織り込んだ制度設計」で締めたが、今週はエコシステムが次の段へ進んだ。最大の特徴は次期メジャーが一斉に RC に並んだこと——pnpm 12（Rust 全面書き換え）、Vitest 5、Solid 2.0、SvelteKit 3、Preact 11、Effect v4 がそろって release candidate 入りし、GA ラッシュの前段が形になった。もう一つの軸は React Compiler がツールチェーンの標準機能へ落ちたことで、Oxlint 1.79・oxc-transform-react・Biome 2.5.8・Bun 1.4 が相次いで対応し、「opt-in の実験」から「どのビルド系でも効く自動メモ化」へ移った。その先に React 19.3（Fragment refs と ViewTransition の stable 化）が視界に入る。そして先週の通奏低音だったセキュリティは、Next.js が 8 月 26 日のセキュリティリリースを事前予告する形で継続した。攻撃の週の次は、道具立てを一段まとめて更新する週だった。

今週の重要ポイント

React Compiler がツールチェーン標準へ — Oxlint 1.79・oxc-transform-react・Biome 2.5.8・Bun 1.4 が一斉対応

これまで React Compiler は Babel プラグインや各フレームワーク個別の opt-in として扱われてきたが、今週その前提が変わった。8 月 18 日、Oxlint 1.79 が React Compiler サポートを追加し、あわせて新パッケージ oxc-transform-react が自動メモ化を担う。Oxc が自前で React Compiler を抱え込み Oxc の AST 上で直接動かすことで統合を密にし、これは @vitejs/plugin-react でも近く使えるようになる見込みだ。同時に Biome 2.5.8 が nursery（実験）ルール useReactCompiler を入れ、Bun 1.4 は --react-compiler フラグと Bun.build({ reactCompiler: true }) でビルド段の自動メモ化を組み込む。

要は、Rust ベースの lint/transform 系（Oxc・Biome）とオールインワンのランタイム（Bun）が、判で押したように同じ週に React Compiler を取り込んだということだ。開発者が Babel を挟まずとも、使っている lint・bundler・runtime の側で自動メモ化が既定の選択肢になる。先週まで「React 本体の周辺機能」だった Compiler が、今週はツールチェーン全体の共通装備へと位置づけを変えた。

次期メジャーが一斉に RC 入り — pnpm 12（Rust 書き換え）、Vitest 5、Solid 2.0、SvelteKit 3、Preact 11、Effect v4

今週の地力は「GA」ではなく「RC の波」に出た。パッケージマネージャの pnpm 12 が RC に到達し、install エンジンを Rust で全面書き換え、Node.js ランチャーを捨てたネイティブバイナリとして配布する。API・フラグ・設定・lockfile 形式は pnpm 11 と互換で、差分は 5 点のみ。キャッシュ済み install は 381ms→12ms（約 30 倍）、クリーン install も 6.5s→2.2s（約 3 倍）と、体感に直結する数字が並ぶ。テスト側では Vitest 5 RC が mock を既定でクリアし、fake timers が Temporal API をモックできるようになった（stable は 2〜3 週後の見込み）。

フレームワーク層も足並みをそろえた。Solid 2.0 RC は async を第一級で扱い、Rust ベースの新コンパイラと簡素化した API を打ち出した。先週プレビュー継続と報じた SvelteKit 3 も RC へ進み、Vite 8 + Rolldown 統合、error boundaries、検証付き環境変数、remote functions を載せる。ビュー層では Preact 11 RC が use()・createPortal()・useEffectEvent() を追加し、関数型エフェクトの Effect v4 RC は reactive Atom と一級の React バインディングを備えた。「速い基盤を stable 一歩手前まで詰める」動きが、先週は個別だったのに対し、今週は複数プロジェクトで同時に RC として噴き出した。

  • This Week In React #294（pnpm 12 / Vitest 5 / Solid 2.0 / SvelteKit 3 / Preact 11 / Effect v4）— thisweekinreact.com

React 19.3 が視界に — Fragment refs と ViewTransition が stable 化、parallel transitions は全面有効化

Compiler の標準化と歩調を合わせるように、React 本体の次版も近づいた。Next.js チームの確認として、Fragment refs と ViewTransition が React 19.3 で stable 機能になることが示された。さらに、これまでフラグ扱いだった parallel transitions が全環境で有効化される（Meta では既に本番稼働中）。19.3 自体の正式リリースは「近く」とされ、日付は未確定だが、周辺のツールチェーンが Compiler を取り込み終えたタイミングで本体の安定版が来る流れが見えてきた。エコシステム全体としては、「Compiler が下回りに定着 → 本体が新プリミティブを stable 化」という順序で世代交代が進んでいる。

  • This Week In React #294（React 19.3 / Fragment refs / ViewTransition / parallel transitions）— thisweekinreact.com

Next.js が 8/26 のセキュリティリリースを予告 — critical 1 件、16.3.3 と 15.5.24 を同時公開予定

先週の主役だったセキュリティは、今週は「予告」という穏当な形で継続した。Next.js は 8 月 26 日にスケジュール済みのセキュリティリリースを行うと事前告知し、critical 深刻度の脆弱性 1 件に対応する。パッチは 16.3.3 と 15.5.24 として、影響範囲・対象バージョン・アップグレード手順を含む正式アドバイザリと同時に公開される予定だ。事前に日付だけ知らせてチームに準備期間を与えるこの運用は、先週号で runtime に広がったと書いた「予告つきセキュリティリリース」が、フレームワーク側でも定着していることを示す。攻撃の実害が出た直後の週に、防御側は淡々と予定を通す構えを見せた。

フレームワーク・ランタイム

Vue 3.6 は今週も RC のまま — Node 26.7 と Astro 7.2 が周辺を進める

RC の波の一方で、先週から動かない銘柄もある。Vue 3.6 は今週も rc.2（7 月 22 日）から進まず、Vapor Mode が feature-complete でも unstable 扱いという構図は変わっていない。秋の GA 待ちが続く。ランタイムでは Node.js 26.7 が Perfetto トレーシング対応を追加し、プロファイリングの選択肢を広げた。静的サイト側では Astro 7.2 がインクリメンタルな静的ビルドを有効化し、任意の session サポートも入れた。今週の「一斉 RC」に乗らなかったプロジェクトも、通常リリースの範囲で着実に前進している。

エコシステム・ライブラリ

TanStack が速度と API を刷新 — Router 再実装で最大 19 倍、Form 2.0 alpha

先週 Table V9 の GA を報じた TanStack は、今週はルーティングとフォームで動いた。コントリビュータによる TanStack Router の再実装が「ドロップイン置換で最大 19 倍高速」をうたい、内部の作り直しで実効性能を大きく引き上げると主張する。TanStack Form 2.0 alpha は API を再設計し、新しいバリデーションパイプラインと性能改善を盛り込んだ。加えて TanStack Start への移行事例（Lovable.dev が Next.js から段階移行）も共有され、DX は良い一方で bundler のカスタマイズが増える、という実運用の手触りが記録された。先週の「JS ライブラリはメモリと再描画を締める」流れに続き、今週は速度と API 刷新が前面に出た。

  • This Week In React #294（TanStack Router 再実装 / Form 2.0 alpha / Start 移行）— thisweekinreact.com

UI・head 系ライブラリも更新 — shadcn React 0.3、Unhead 3.3、React Hook Form 7.85、Meta の Astryx

周辺ライブラリの更新も続いた。shadcn React 0.3 は多段の質問フローを組む <Questionnaire> コンポーネントを追加。<head> 管理の Unhead 3.3 はフレームワーク非依存の <head> コンポーネントと <Fragment> サポート、React 向けの修正を入れた。React Hook Form 7.85 は React の <Activity>（描画を保留・再開する新プリミティブ）に対応。デザインシステム側では、Meta が StyleX ベースのカスタマイズ可能なデザインシステム Astryx（0.3 / 0.4）を出した。先週の React Aria 1.20・Base UI 1.7 に続き、アクセシビリティとスタイリングの土台がさらに厚くなっている。
