セキュリティ

Node.js の Brotli デコーダに遠隔コード実行の脆弱性

Node.js 同梱の Brotli デコーダに、高深刻度の領域外書き込み（CVE-2026-111497）が見つかった。不正なブロック切り替えを「入力が足りないだけ」と誤って扱い、ストリーミング復号が 8 バイトの内部バッファを越えて書き込む。クラッシュやメモリ漏えい、遠隔コード実行につながりうる。

影響は 26.x・24.x・22.x に及ぶ。修正版 22.23.4 / 24.22.1 / 26.12.1 が出ている。node:zlib で信頼できない Brotli データを展開するアプリは早めに更新する。報告は OpenAI Codex Security による。

TanStack が AI 1.0 と軽量ランタイム Redact を公開

Firefox 159 がスクロール駆動アニメーションを既定化

Firefox 159 が 10 月 27 日に出た。スクロール量に動きを紐づける スクロール駆動アニメーション を既定で有効にした。影の DOM ごとに独自の CustomElementRegistry を持てる スコープ付きカスタム要素レジストリ も入り、同名要素の衝突を避けやすくなった。

Sanitizer 系では、Element.setHTML() が解析の途中で不要な要素・属性を取り除くようになった。また旧 masonry 構文（grid-template の masonry 値と masonry-auto-flow）を削除し、display: grid-lanes に寄せた。
