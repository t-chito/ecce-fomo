まとめ

先週号は「卒業と cadence」——React 19.3 の GA と Chrome の 2 週間リリース移行——の 2 語で今週を占った。その cadence が今週、予定と非常時の両方で同じ 9 月 22 日に本番を迎えた。定時側は Chrome 154 が今日から stable の本展開に入り、153 で始めた 2 週間サイクルの最初の通常ラップを回した。非常時側は Next.js が上流依存の重大脆弱性を突き、16.3.6 / 15.5.26 を out-of-band で今日リリース——速く小さく配る体制が、機能ではなく緊急パッチで試された。先週卒業した View Transitions も早くも各アプリが next-view-transitions を捨てて native へ乗り換え始め、卒業生が現場に配属された。今週は「速く回す列車が、平時と有事の両方で走った週」だ。

今週の重要ポイント

Next.js が上流依存の重大脆弱性で緊急パッチ — 16.3.6 / 15.5.26 を本日 out-of-band 配布

今週いちばんの出荷は機能ではなくセキュリティだった。Next.js チームは 9 月 21 日に事前告知を出し、上流依存（upstream dependency）に見つかった critical な問題に対して 16.3.6 と 15.5.26 を本日 9 月 22 日に out-of-band で公開すると予告した。詳細は advisory GHSA-vcvr-r3jv-pc5j にリリースと同時に載る予定で、影響範囲・対象バージョン・アップグレード手順はそこで開示される。ポイントは、これが Next.js 自身のコードではなく依存先由来である点と、通常リリース列を待たず臨時で差し込んだ点だ。先週の「小さく速く配る」cadence の議論が、機能ではなく緊急対応でまず現実になった格好で、16 系・15 系の両方を使う現場は即時アップグレードが必要になる。

  • Upcoming Next.js Security Update for a Critical Upstream Issue — nextjs.org（2026-09-21）
  • GHSA-vcvr-r3jv-pc5j — vercel/next.js Security Advisory

Chrome 154 が本日 stable 本展開 — 2 週間 cadence の「最初の通常ラップ」

先週の Chrome 153 は「2 週間リリースへ短縮する」という宣言だった。今週その宣言が実走に変わった。Chrome 154 は 9 月 2 日に beta へ出たのち、本日 9 月 22 日から stable の大半展開に入る——153 の直後、公約どおり約 2 週間で次が届いた形で、新 cadence の最初の通常ラップが確かに回ったことを示す。中身も web プラットフォームの実務に効くものが並ぶ（詳細は後述）。「beta 追従の重要度が上がる」という先週の見立ては、現実の周期が半分になったことで今週から効き始めている。

  • Chrome 154 beta — Chrome for Developers（2026-09-02）
  • Chrome's two-week release cycle — Chrome for Developers

卒業した View Transitions が現場へ — アプリが next-view-transitions を捨て native に乗り換え

先週 React 19.3 で stable になった <ViewTransition> は、リリースの翌週にはもう移行の波を作った。9 月中旬、複数のプロジェクトがサードパーティの next-view-transitions を外し、React 19.3 の native な <ViewTransition> へ置き換えるPR を出している。shared-element 遷移や方向付きアニメーションを、ポリフィル頼みからフレームワーク標準のプリミティブへ寄せる動きだ。先週「来週の注目」に挙げた「stable 化が各フレームワークにどう波及するか」は、まずNext.js アプリ側の依存差し替えという具体で回答が出た。卒業生が現場に配属され、ポリフィルという足場が外れ始めている。

  • React 19.3（<ViewTransition> stable）— react.dev
  • This Week in React #296（React 19.3 / 移行事例）— ThisWeekInReact.com

Vue 3.6 は今週も RC — 「秋 GA」の窓はまだ開かない

先週に続いて視線を集めた Vue 3.6 は、今週もRC のままだった。最新の安定版は依然 3.5 系で、3.6 は rc 段階に留まっている。alien-signals ベースのリアクティビティ刷新と、仮想 DOM を外す Vapor Mode は feature-complete としつつ「秋 GA」の予告のまま据え置きで、エコシステム側の追従（UI ライブラリの vaporInteropPlugin 経由対応など）も途上にある。先週 React が波を 1 つ卒業させた後、次の卒業生と目される Vue 3.6 はまだ足踏み——「一斉ではなく 1 つずつ、見立てと違う順に割れる」というこの数週のパターンが今週も続いた。

セキュリティ

「上流依存」由来という座り — 自分のコードを直さずに晒される構図

今回の Next.js の件で読んでおきたいのは、原因がNext.js 本体ではなく上流依存にあるという座りだ。フレームワークを最新に保っていても、その依存の 1 つに critical が出れば連鎖的に影響を受ける——アプリ側のコードは 1 行も間違っていなくても、である。だからこそ Next.js は通常のリリース列を待たず、16 系（16.3.6）と 15 系（15.5.26）の両方に同時にバックポートして out-of-band で配る。advisory GHSA-vcvr-r3jv-pc5j がリリースと同時に公開され、そこで初めて具体的な影響と対象範囲が判明する設計なので、事前告知の段階では「詳細は伏せたまま、まずアップグレード準備を促す」形を取っている。運用側の実務は明快で、16.3.6 / 15.5.26 が出たら即上げる、そして自分たちの依存ツリーに同じ上流を別経由で抱えていないかを点検することだ。

  • Upcoming Next.js Security Update for a Critical Upstream Issue — nextjs.org
  • GHSA-vcvr-r3jv-pc5j — vercel/next.js Security Advisory

ブラウザ・プラットフォーム

Chrome 154 の中身 — UI の取りこぼしを潰す小粒と、暗号の大玉

2 週間 cadence の第 1 弾らしく、Chrome 154 は派手な 1 本より実務の穴埋めが目立つ。CSS では scroll-marker-group に tabs / links モードが入り、適切な ARIA ロールでカルーセルのマーカーがアクセシブルになった。下線まわりも text-decoration-inset（下線の余白制御）と text-decoration-skip-spaces（空白部分に線を引かない）で仕上げが効く。地味に効くのがpopover / dialog の light-dismiss を pointer から click イベントへ変更した点で、スクロールや右クリックでの誤クローズが防げるようになった。JS では Iterator.prototype.includes() が加わり、配列化せずにイテレータをそのまま探索できる。大玉は WebCrypto の耐量子暗号で、ML-KEM / ML-DSA / X-Wing / ChaCha20-Poly1305 が使えるようになった。ほかに streamAppendHTML() などのストリーミング挿入、WebGPU の fragment depth 修飾も入る。2 週間で「小さく確実に」届く典型的な号だ。

  • Chrome 154 beta（scroll-marker-group / 耐量子暗号 / Iterator.includes ほか）— Chrome for Developers

エコシステム・ツール

RC 待ちの裏で足回りは進む — Vite 8.3・Astro 7.3・SvelteKit 3 の移行タスク

大玉の GA が足踏みする間も、周辺ツールは着実にマイナーを刻んだ。Rolldown ベースの Vite 8 は 8.3.0（9 月 10 日）まで進み、3 月の 8.0 以来の高速ビルド路線を継続している。Astro 7.3.0（9 月 3 日）も出て、6 月の Astro 7（Vite 8 ベースのビルドと Rust コンパイラ）の系列を伸ばした。Svelte 側では SvelteKit 3 が依然 RCだが、移行の地ならしは進む——sv migrate に sveltekit-3 移行タスクが入り、依存の bump・$lib から Node subpath imports の #lib への書き換え・$app/state タスクなどが用意された。新 CLI アドオンは mcp を ai-tools に置き換え済み。「3 系が来る前提」で足場を整える動きが、Vue・Svelte 双方で続いている。

来週の注目ポイント

GHSA-vcvr-r3jv-pc5j の全貌 — 影響範囲と「同じ上流」の広がり

今日リリースと同時に公開される advisory の中身が、来週の最大の関心事になる。どのバージョン帯が影響を受け、攻撃条件は何で、問題の上流依存が具体的に何か——それが分かって初めて、Next.js 以外の（同じ依存を抱える）エコシステムへの波及が見える。1 月・5 月にも React/Next.js 系の脆弱性対応があった流れの延長として、依存監査を回す週になりそうだ。

  • GHSA-vcvr-r3jv-pc5j — vercel/next.js Security Advisory

2 週間 cadence の第 2 ラップと、Vue 3.6 の「秋 GA」窓
