まとめ

今週の LLM 業界は、競争の主戦場が「どのモデルが賢いか」から「賢さを支える土台を誰が握るか」へ一段降りた週だった。土台の最深層——シリコンでは、OpenAI が自社初の推論チップ「Jalapeño」の実測値を公開し、「ワットあたりの知能」を軸に年末からの自社インフラ投入と多世代ロードマップ（Gen 2 開発中・Gen 3 構想中）を打ち出した。先週 Cerebras を借りて速度を出した OpenAI が、今週は推論の半導体そのものを内製化する側に回った格好だ。経済の土台では GPT-5.6 Sol の API 価格を 3 か月 2 割引き下げ、価格対性能の競争が続く。チャネルの土台では xAI が Grok Voice を Starlink のサポートに投入し、日次 1.5 万件の通話を処理——音声エージェントが実運用の主戦力に入った。安全の土台では Anthropic が専用セキュリティモデル「Mythos 5」を公開し $35M のディフェンダー基金を設けた。加えて computer use・Skills/Files API・MCP エンタープライズ認証が一斉に GA となり、メモリと定時タスクが「常駐して働くアシスタント」への地ならしを進めた。速さと安全を競った先週から、各社はその足場——半導体・価格・チャネル・防御・記憶——を同時に固めにかかっている。

今週の重要ポイント

OpenAI が自社推論チップ「Jalapeño」の実測値を公開 — フロンティアが半導体を内製化

OpenAI は自社初のカスタム推論チップ Jalapeño をテスト段階から前進させ、実測値を公表した。「ワットあたりの知能が向上し、スループット増とレイテンシ低下を単一アーキテクチャで同時に達成」とし、年末までに自社の計算基盤へ投入する。sama は「we made a chip and it is fast」、gdb は「推論数値を公開した、チームは見事な仕事をした」と添えた。先週の Cerebras による Ultrafast に続き、速度と単価の競争が自前シリコンの層まで降りた。

Grok Voice が Starlink で日次 1.5 万件 — 音声エージェントが本番の主戦力へ

xAI（SpaceXAI）は Grok Voice Think Fast 2.0 を音声 Speech-to-Speech の指標で首位に据え、同じ日に Starlink のインバウンド対応で日次 1.5 万件超の通話・チャットを処理していると明かした。ハードの故障診断から交換手配、週 3,000 件超の注文処理までを担う。先週の Cursor 取り込み（コーディング）に続き、xAI は音声チャネルの実運用へ版図を広げた。

Anthropic が専用セキュリティモデル「Mythos 5」と $35M ディフェンダー基金

Anthropic は最上位のセキュリティ特化モデル Claude Mythos 5 を全 Enterprise 向けの public beta で提供開始。GitHub リポジトリに向けるだけでデータフローを横断して脆弱性を探し、CWE 分類・確信度・深刻度・修正案を返す。あわせて OSS セキュリティ向けに $35M のクレジットを配る Defender Advantage Fund を設立。フロンティアの能力を防御側へ広く届ける路線が、名を持つ製品として具体化した。

エージェント基盤が一斉 GA — computer use・Skills/Files API・MCP 認証

Anthropic は computer use・ブラウザツール・Skills API・Files API を GA に引き上げ、新ツールセットで1 ターンに複数操作（往復 20〜40% 減）を可能にした。さらに MCP コネクタのエンタープライズ管理認証が GA となり、組織のツール接続が個別 OAuth なしで一元化される。エージェントを「デモ」からversioned な手順とバージョン管理された接続で回す本番基盤へ整える動きだ。

推論シリコンと価格競争

Jalapeño — 「ワットあたりの知能」を掲げる自社チップ、多世代ロードマップ

OpenAI の Jalapeño は、同社が「最初のカスタム推論チップ」と位置づける半導体だ。公開された実測は「より多くの知能をより少ない電力で／より速い応答で／高スループットと低レイテンシを一つの設計で両立」を強調する。狙いは ChatGPT の応答高速化・Codex やエージェントの応答性・需要増に耐える安定供給で、年末から自社インフラへの展開を開始する。さらに「Gen 2 は開発が深く進み、Gen 3 も形になりつつある」と多世代計画を明言した。gdb は別途「AI によるチップ設計は過小評価されている」と投稿し、設計そのものに AI を用いる潮流を示唆した。先週の Cerebras 依存（Ultrafast）から、今週は推論の半導体を内製し、電力・計算のコスト構造ごと握る構えへ踏み込んだことになる。

  • OpenAI (X) — Jalapeño, our first custom inference chip: more intelligence per watt
  • OpenAI (X) — Deploying by year-end; Gen 2 deep in development, Gen 3 taking shape
  • Greg Brockman (X) — inference numbers published for Jalapeño
  • Sam Altman (X) — we made a chip and it is fast
  • Greg Brockman (X) — AI for chip design is underrated

GPT-5.6 Sol が API 価格を 2 割引き下げ — 効率化を値下げに還元

OpenAI は「能力のフロンティアを押し進めつつ効率も高める」として、GPT-5.6 Sol の API・クレジット価格を今後 3 か月にわたり 20% 超引き下げると発表した。適用は API と ChatGPT Work・Codex クレジットで、Pro・Plus・Business のサブスク利用は据え置き。外部でも即座に反映され、Cognition は「先週の 70% 割引と合わせ、10/3 まで Sol は定価から 76% オフ——Devin Desktop・CLI で最も安いフロンティアモデル」と告知した。Jalapeño による効率改善の物語と対をなし、「同じ知能をいかに安く届けるか」という先週来の競争軸が、値下げの連鎖として続いている。

  • OpenAI (X) — dropping API and credit pricing of GPT-5.6 Sol by over 20%
  • OpenAI (X) — on the API and eligible ChatGPT Work and Codex credits
  • Cognition (X) — Sol is now the most affordable frontier model on Devin (76% off through Oct 3)

音声フロンティアとモデル普及

Grok Voice Think Fast 2.0 — 指標首位と Starlink 実運用、そして API 開放

xAI（SpaceXAI）は音声エージェント Grok Voice Think Fast 2.0 を Artificial Analysis の Speech-to-Speech Index で首位に押し上げた。この指標は「聞いた音声を推論し、実際の顧客課題を解決し、ツールを使ってタスクを正しく完了できるか」を測るもので、単なる音声品質でなくタスク遂行能力を評価する。実運用の裏づけも同時に示され、Starlink では Grok Voice が日次 1.5 万件超の問い合わせを処理し、故障診断・交換手配・週 3,000 件超の注文までこなす。さらに Grok Voice は API と Agent Builder で一般提供され、他社も音声エージェントを構築・調整・展開できる。先週の Cursor 取り込みと合わせ、xAI はコーディングと音声という 2 つの実務チャネルで垂直に攻める姿勢を鮮明にした。

  • SpaceXAI (X) — Grok Voice Think Fast 2.0 is #1 on the Artificial Analysis Speech-to-Speech Index
  • SpaceXAI (X) — Starlink resolves 15,000+ inbound calls a day with Grok Voice
  • SpaceXAI (X) — Grok Voice Think Fast 2.0 available via API or Agent Builder

Grok 4.6 の配信面が拡大、Gemini 3.7 は「過去最速の立ち上がり」

先週投入された Grok 4.6 は配信面を広げ、Google Vertex AI・Nous Research の Hermes（50% 割引）・OpenCode Go などへ順次搭載された。フロンティアモデルを自社チャネルに閉じず外部プラットフォームへ載せて普及を稼ぐ動きが続く。Google 側では、先週公開の Gemini 3.7 について Logan Kilpatrick が「過去最速で伸びているローンチ」と報告し、価格対性能の刷新が開発者・利用者の取り込みに効いていることを裏づけた。モデルそのものの発表が一巡した今週は、「どれだけ多くの現場・プラットフォームに行き渡らせるか」という普及フェーズの指標が前面に出た。

  • SpaceXAI (X) — Grok 4.6 is now available on Google Vertex AI
  • Grok (X) — Grok 4.6 now included in OpenCode Go
  • Logan Kilpatrick (X) — Gemini 3.7 is our fastest growing model launch to date

エージェント基盤の一般提供と相互運用

computer use・Skills/Files API が GA、MCP はエンタープライズ認証へ

Anthropic は computer use・ブラウザツール・Skills API・Files API を Claude Platform で GA に引き上げた。API を持たないアプリの操作をより少ない往復で自動化でき、versioned な Skills と再利用可能な Files の上に Managed Agents を組める。新ツールセット（computer_toolset_20260801 / browser_toolset_20260801）は1 ターンにクリック・入力・キー・スクショなど複数操作をまとめ、初期顧客では往復が 20〜40% 減った。ブラウザ操作もピクセル座標依存からページ構造（要素参照）ベースへ移り、レイアウト変化に強くなった。さらに MCP コネクタのエンタープライズ管理認証が GA となり、Asana・Atlassian・Canva・Datadog・Figma・Linear・Notion・Slack・Supabase などがIdP 経由の一元認証に対応。エージェントを本番運用に載せるための手順・接続・権限の土台が一段そろった。

Notion がスキルを各エージェントへ持ち出し可能に — 相互運用の芽

Notion は、チームの手順を教える スキルを Notion 上に置いて「単一の真実の源」とし、Claude Code・Codex・Cursor・Gemini・Grok へダウンロードして使えるようにした。書き出しは SKILL.md ＋承認済みファイルという形で、特定ベンダーに縛られない可搬なスキルとしてローカルエージェントにも渡る。各社が独自のエージェント基盤を GA する一方、手順・ナレッジの層はベンダー横断で持ち運べるという相互運用の芽が出てきた。開発ツール層では、Cognition が Slack 上に Devin 専用のコードチャンネルを切る機能を、CodeRabbit が Cursor 向けプラグインを投入するなど、既存の作業場所へエージェントを差し込む動きが続いた。

セキュリティとディフェンダー

Claude Mythos 5 と Defender Advantage Fund — 「防御側へ能力を配る」を製品化

Anthropic は最上位のセキュリティ特化モデル Claude Mythos 5 を全 Enterprise 顧客向け public beta で提供開始した。GitHub リポジトリに向けるだけで、データがファイルをまたいでどう流れ、コンポーネントがどう相互作用するかを推論しながら脆弱性を探索し、各所見に CWE 分類・確信度・深刻度・修正案を付けて返す。修正案はチームが既に使うモデルで Claude Code on the web に開き、「スキャンの背後でモデルが動き、所見だけを返す」——防御側にモデルへの直接アクセスを求めずに結果を届ける設計だ。あわせて OSS セキュリティ向けに $35M のクレジットを配る Defender Advantage Fund を設立し、Mythos 5 を他社のセキュリティ製品へ統合するパートナーシップや Cyber 拡大も進める。gdb らが数週にわたり掲げた「防御側の底上げ」という主張が、名を持つモデルと資金の形で具体化した。

OpenAI、長時間・自律作業のリスク監視をプレビュー — ZDR は継続

メモリと自律実行

Claude が chat と Cowork で記憶を統合、ChatGPT は定時タスクと安全なサインイン

常駐して働くアシスタントへ向けた記憶と自律実行の整備も進んだ。Anthropic は chat と Claude Cowork で単一のメモリを持たせ、Cowork にタスクを渡すと過去のチャットで話したプロジェクトや上長の好み、前四半期の顧客から始められるようにした。記憶はトピックの一覧として Settings で読み・編集・削除でき、健康や信条などセンシティブな話題は既定でメモリに入らない。bcherny も「メモリはよりシンプルで強力になった」と添えた。OpenAI 側では gdb が ChatGPT Work の「安全なアカウントサインイン」と ChatGPT の定時トリガー（triggered tasks）を相次いで示し、文脈を覚え・自分で予定を回し・必要なサービスにログインして働くアシスタント像を、記憶と自動実行の両面から具体化した。

  • Claude (X) — Claude now has one memory across chat and Claude Cowork
  • Claude (X) — sensitive topics stay out of memory unless you turn them on
  • Greg Brockman (X) — triggered tasks in ChatGPT
  • Greg Brockman (X) — ChatGPT Work can now securely sign into accounts

来週の注目ポイント

最大の観測点は Jalapeño の展開。年末の自社インフラ投入に向けた歩留まり・供給の続報と、「AI によるチップ設計」がどこまで実像として語られるか。価格面では、Sol の値下げと Jalapeño の効率がフロンティア全体の単価にどう波及し、各社が追随するか。音声では、Grok Voice の Starlink 事例に続く本番導入と、他社（OpenAI・Google）の音声エージェントとの Speech-to-Speech 指標での競り合い。エージェント基盤では、GA した computer use・Skills/Files API・MCP 認証の企業採用と、Notion 発の可搬スキルがベンダー横断の相互運用として根づくか。セキュリティでは、Mythos 5 の他社製品への統合と $35M 基金の使われ方。そしてメモリ＋定時タスク＋安全なサインインが、長時間・自律で働くアシスタントの実用度をどこまで押し上げるかが焦点になる。
