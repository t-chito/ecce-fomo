まとめ

今週の GitHub 週間トレンドは、先週まで続いた「自律・長時間エージェント本体」熱がひと段落し、代わりにエージェントを取り巻く周辺——表現・記憶・実行環境へ関心が広く散った一週間だった。首位は Claude Code / Codex 向けの編集品質ダイアグラム集 diagram-design（週間 +11,325★・今週トップ）で、「エージェントに図を描かせる」という新しい切り口が突出して伸びた。ふたつめの軸は先週から続く「記憶・文脈をどう持つか」で、ByteDance/Volcengine の自己進化型コンテキスト DB OpenViking、コーディング CLI 間の引き継ぎを狙う ai-memory、説明可能性を核に据えた semantica（先週に続き上位）が並んだ。みっつめは「手元のハードで動かす」ローカル志向で、14MB のオンデバイス基盤モデル needle、手持ちマシンで動くモデルを探す llmfit、ローカル学習・実行 UI の unsloth、画像から 3D を生成する modly が同じ潮流に乗った。加えて LLM ルーティングの NVIDIA-NeMo/Switchyard、Rust 製の Logitech 代替 OpenLogi、DHH の Linux ディストロ omarchy、そして定番の public-apis・MoneyPrinterTurbo が高い伸びを保った。エージェント「そのもの」から「図・記憶・実行環境・手元で動くこと」へ——関心の重心が周辺インフラへ移ったのが、今週の見どころだった。

今週の首位 — エージェント向けの表現とツール

cathrynlavery/diagram-design — エージェントに描かせる編集品質のダイアグラム集（今週トップ・週間 +11,325★ / 累計 2.5万★）

今週いちばんスターを伸ばしたリポジトリ。ページ上部の説明は「38 editorial diagram types for Claude Code, Codex, and Pi. Self-contained HTML + SVG. No shadows. No Mermaid slop.」で、Claude Code・Codex・Pi といったコーディングエージェントに「まともな図」を描かせるための、38 種類の編集品質ダイアグラムテンプレート集。自己完結した HTML + SVG として出力され、Mermaid の機械的な見た目に頼らない設計を掲げる。

フローチャートから Sankey ダイアグラムまで幅広い図種をカバーし、ブランドに合わせた自動調整、draw.io / Mermaid からのインポート、PNG / SVG へのエクスポートに対応する。topics には agent-skills・claude-code・codex・data-visualization・diagrams・drawio・mermaid・svg などが並び、ライセンスは MIT。エージェントに「コードを書かせる」「調べさせる」に続いて「図を描かせる」という用途が独立した Skill 群として立ち上がり、突出した勢いでトレンド首位に立った。

  • cathrynlavery/diagram-design

CodebuffAI/freebuff — API キー不要の「無料のコーディングエージェント」（週間 +1,133★ / 累計 1.0万★）

ページ上部の説明は「The free coding agent」。サブスクリプションや API キーを用意せずに使える、AI コーディングエージェント群を提供するプロジェクト。Desktop・CLI・Web・Cloud・Chat の 5 つの形態で提供され、複数の AI モデルを束ねたマルチエージェント構成で動く。

コードベースの分析・実装・調査・コードレビューといったタスクを、専門化された複数のエージェントが分担して処理する設計。主体は TypeScript、ライセンスは Apache 2.0。有償の商用コーディングエージェントが並ぶなか、「無料・鍵不要」を前面に出した選択肢として今週ランキングに顔を出した。

  • CodebuffAI/freebuff

macro-inc/macro — メール・チャット・ドキュメントを AI 記憶で束ねる統合ワークスペース（週間 +1,456★ / 累計 3.9千★）

ページ上部の説明は「Macro is a unified workspace for teams: email, chat, docs, tasks, agents, calls, and CRM — @-linked together with shared AI memory.」。メール・メッセージ・ドキュメント・タスク・CRM をひとつのインターフェースに統合し、双方向リンクと共有された AI メモリで全モジュールをまたいで情報を流通させるチーム向けワークスペース。

複数の分断されたツールを行き来する必要をなくすことを狙い、@ 記法で各要素をリンクし、AI 記憶を全体で共有する。topics には ai-agents・all-in-one・crm・slack-alternative・workspace などが並ぶ。主体は Rust バックエンドと SolidJS フロントエンド（TypeScript）、ライセンスは AGPL-3.0。「エージェント時代のオフィススイート」を志向する統合型ツールとして支持を集めた。

  • macro-inc/macro

エージェントの「記憶・文脈」をどう持つか（先週から継続）

volcengine/OpenViking — 自己進化するエージェント向けコンテキスト DB（週間 +2,444★ / 累計 3.1万★）

ページ上部の説明は「Self-evolving Context Database for AI Agents. Unify Agent Memory, Knowledge RAG and Skills.」。エージェントの記憶（メモリ）・知識 RAG・スキルを、仮想ファイルシステム風のインターフェースの下に統合するコンテキストデータベース。エージェントが従来のファイルディレクトリをたどるように、観察・デバッグ可能な検索パターンで情報を辿れるようにする。

段階的なローディング（tiered loading）でトークンコストを抑えつつ、検索の過程を透明に保つのが特徴。topics には agent-memory・agentic-rag・context-database・self-evolving などが並ぶ。主体は Rust（Python コンポーネントを含む）、ライセンスは本体が AGPLv3・CLI とサンプルが Apache 2.0。Volcengine（ByteDance のクラウド部門）発で、先週の Tencent 系メモリハブに続き大手クラウドが「エージェントの記憶層」に本腰を入れる流れを象徴する。

  • volcengine/OpenViking

akitaonrails/ai-memory — コーディング CLI 間の「引き継ぎ」を狙う長期記憶（週間 +1,952★ / 累計 3.8千★）

ページ上部の説明は「Solution for long term memory for agent coding CLIs and to facilitate handoff between different agent vendors」。AI コーディングエージェントがセッションをまたいで記憶を保ち、異なるベンダーのエージェント間を文脈を失わずに乗り換えられるようにするツール。

Claude Code・Codex など複数の対応エージェントからライフサイクル上の観察を収集し、検索可能な Markdown の Wiki にまとめ、ツールを移行するときの引き継ぎを提供する。ベクトルデータベースを使わず、SQLite の FTS5 による全文検索と、任意で LLM による要約の統合を組み合わせる設計。主体は Rust、ライセンスは MIT。特定のエージェントに囲い込まれない「ベンダー横断の記憶」という切り口で伸びた。

  • akitaonrails/ai-memory

semantica-agi/semantica — 説明可能性を核に据えたグラフネイティブ基盤（先週から継続・週間 +3,674★ / 累計 1.0万★）

先週に続き今週も上位に残った。ページ上部の説明は「Graph-Native Infrastructure for Context and Accountable AI Systems」で、決定の追跡や説明可能性を欠いたまま動く AI に対し、LLM とベクトルストアの下に決定論的な基盤層を敷く。とくに、決定が規制当局の審査に耐える必要のある規制産業を意識する。

複数ソースの企業データから照会可能な文脈グラフを構築し、AI の決定を因果系譜つきの第一級オブジェクトとして記録、W3C PROV-O 準拠の来歴トレイルを生成する。前向き連鎖・Rete・Datalog・SPARQL によるルールベース推論を LLM なしで実行し、Databricks や Snowflake のネイティブコネクタ、RDF トリプルストア／プロパティグラフ／ベクトルストアを差し替え可能な構成を持つ。主体は Python、ライセンスは MIT。「速く答える」より「後から説明・監査できる」ことに軸足を置く基盤が、二週続けて支持を集めた。

  • semantica-agi/semantica

ローカル／オンデバイスで動かす AI

cactus-compute/needle — 14MB のオンデバイス基盤モデル（週間 +3,409★ / 累計 8.2千★）

ページ上部の説明は「14MB foundation model for tiny devices; phones, wearables, smart home, and robots.」。スマホ・ウェアラブル・スマートホーム・ロボットといった資源の限られた小型デバイス向けに設計された、コンパクトな基盤モデル。

README によれば、Needle 2 は約 4,500 万パラメータで、モデルサイズ 14MB・実行時メモリ約 28MB という極小フットプリントを保ちながら、ツール呼び出し・デバイス自動化・データ抽出をこなす。Simple Attention Network 型のアーキテクチャを採り、信頼度スコア、ツール検索、文法制約付きデコードによる構造化出力といった機能を内蔵する。topics には gemma・llm・on-device-ai などが並ぶ。主体は Python、ライセンスは Apache-2.0。「クラウドに投げない・端末で完結する AI」の実装例として突出して伸びた。

  • cactus-compute/needle

AlexsJones/llmfit — 手持ちマシンで「動くモデル」を一発で探す（週間 +1,842★ / 累計 3.3万★）

ページ上部の説明は「Hundreds of models & providers. One command to find what runs on your hardware.」。自分のマシンの RAM・CPU・GPU を調べ、どの大規模言語モデルが快適に動くかを推薦するターミナルアプリ。

ハードウェアを検出したうえで、モデルを性能・品質・速度・文脈長といった軸でスコアリングし、最適な組み合わせを提示する。対話的なターミナル UI と CLI の両モードを備え、Ollama・llama.cpp・MLX といったバックエンドに対応する。topics には gguf・llm・localai・mlx などが並ぶ。主体は Rust、ライセンスは MIT。「そのモデル、自分の PC で動くのか？」という素朴な悩みに一発で答える点が、ローカル志向のトレンドと噛み合って伸びた。

  • AlexsJones/llmfit

unslothai/unsloth — ローカルで LLM・拡散モデルを動かし学習させる UI（週間 +3,300★ / 累計 7.4万★）

ファインチューニングの高速化ライブラリとして知られる Unsloth のリポジトリ。ページ上部の説明は「Local UI to run and train LLMs and diffusion models」とあり、ローカルで各種 AI モデルを実行・学習・デプロイするためのデスクトップ／Web スタジオとして紹介されている。

言語モデル・拡散モデル・埋め込みモデル・音声モデルなど複数のモデル種を扱い、「標準的な手法に比べて学習が 2 倍速く VRAM を 70% 削減」といった最適化を掲げる。topics には fine-tuning・llm・reinforcement-learning・self-hosted・stable-diffusion などが並ぶ。主体は Python、ライセンスは Apache-2.0 と AGPL-3.0 のデュアル。累計 7万★超の定番が、ローカル実行 UI という切り口で今週も +3,300★ と伸びを保った。

  • unslothai/unsloth

lightningpixel/modly — 画像やプロンプトから 3D モデルをローカル生成（週間 +1,855★ / 累計 7.1千★）

ページ上部の説明は「Desktop app to generate 3D models from images or prompt using local AI — runs entirely on your GPU」。写真やプロンプトから 3D メッシュモデルを生成するデスクトップアプリで、オープンソースの AI モデルを手元の GPU 上で完結して実行する。

Windows・Linux・Apple Silicon の macOS に対応し、Hunyuan3D や TripoSG といった追加モデルを導入できる拡張機能システムを備える。topics には 3d・ai-local・desktop-app・self-hosted などが並ぶ。主体は TypeScript（Python バックエンド）、ライセンスは MIT。「クラウドに送らずローカル GPU で 3D 生成」という点が、needle・llmfit・unsloth と同じローカル志向の流れに乗った。

  • lightningpixel/modly

ルーティング基盤と Rust 製デスクトップ

NVIDIA-NeMo/Switchyard — モデル／プロバイダをまたぐ LLM ルーティング（週間 +932★ / 累計 2.0千★）

ページ上部の説明は「Switchyard lets LLM applications route traffic across models and providers while preserving native OpenAI and Anthropic API compatibility」。OpenAI と Anthropic の API 形式を相互変換しながら、複数のモデルバックエンドやプロバイダへリクエストを振り分ける Rust 製のプロキシ。

クライアントは自分の使い慣れた API を保ったまま、A/B テスト・コスト最適化・リクエスト特性に応じた動的なモデル選択といった複数のルーティングアルゴリズムを利用できる。ベンチマークやコスト・性能の最適化を狙う。主体は Rust、ライセンスは Apache 2.0。先週の loopx や cloudflare/computer に続き、NVIDIA の NeMo チームが「エージェントの実行を束ねる中間層」に加わったことを示す。

  • NVIDIA-NeMo/Switchyard

AprilNEA/OpenLogi — Rust 製・ローカル完結の Logitech Options+ 代替（週間 +2,674★ / 累計 1.2万★）

ページ上部の説明は「A native, local-first alternative to Logitech Options+, written in Rust — remap buttons, DPI, and SmartShift over HID++. No account, no telemetry.」。Logitech 純正の Options+ ソフトを置き換える、ローカル完結・プライバシー重視の入力デバイス設定ツール。アカウント登録もテレメトリもなしに、HID++ 経由でボタンのリマップや DPI、SmartShift を調整できる。

ネイティブ GUI を備え、macOS・Linux・Windows をまたいでボタンリマップ・DPI 調整・ジェスチャ制御・SmartShift 設定に対応する。topics には hid・local-first・logitech・mouse-remapping・mx-master・privacy・rust などが並ぶ。ライセンスは Apache 2.0 と MIT のデュアル。純正ソフトの重さやアカウント要求を嫌うユーザーの受け皿として、AI 以外の実務ツールでも今週上位に食い込んだ。

  • AprilNEA/OpenLogi

basecamp/omarchy — DHH による「美しく現代的で主張のある」Linux（週間 +2,395★ / 累計 2.7万★）

ページ上部の説明は「Beautiful, Modern & Opinionated Linux」。Basecamp / Ruby on Rails で知られる DHH（David Heinemeier Hansson）が手がける、現代的な見た目と割り切った設計思想を掲げる Linux ディストリビューション。

基本操作から高度な設定までを網羅する詳細なマニュアルを備え、アプリケーション・開発ツール・カスタマイズの広範なサポートを提供する。主体は Shell、ライセンスは MIT。著名開発者が「意見の強い」既定値でまとめ上げたディストロとして注目を集め、AI 一色になりがちな週間トレンドのなかで存在感を示した。

定番の巨大リポジトリも高い伸び

public-apis・MoneyPrinterTurbo — 週間ランキング上位の定番

新顔のエージェント周辺ツールが並ぶ一方で、以前から巨大な定番リポジトリも週間で大きくスターを伸ばした。無料 API を categories 別に集めたリファレンス public-apis/public-apis（週間 +11,259★・累計 46万★超）は、開発者が自由に使える公開 API を探すための定番一覧で、今週は首位級の伸びを見せた。もうひとつは harry0703/MoneyPrinterTurbo（週間 +9,712★・累計 11.3万★）で、ページ上部の説明は「利用 AI 大模型和自动化工作流，根据主题或关键词一键生成高清短视频」。テーマやキーワードを与えると AI が台本・素材・字幕・BGM を組み立て、TikTok / YouTube Shorts 向けの HD 短尺動画をワンクリックで生成する。いずれも継続的に使われる大型リポジトリで、新顔のトレンドとは別の層として安定した人気を保っている。
