まとめ

先週は「エージェントの振る舞いを仕込む単体スキル」と、その配布口を公式化するカタログが週間トレンドの中心だった。今週はその熱がさらに一段深いレイヤーへ移った。週間の伸びで上位を占めたのは、単体スキルではなくエージェントを本番運用するための基盤だ。首位級にはアリババ発の AI コードレビュー open-code-review、Claude Code などの土台を最適化するハーネス ECC、複数エージェントを並列に走らせる ADE orca が並び、「書かせる」から「レビュー・並列運用する」への移行が鮮明になった。今週の新しい軸はエージェントの「記憶」で、長期記憶を扱う hindsight と、ベンダー間の引き継ぎまで担う ai-memory が揃って上位入りした。さらに、仕様を先に固める OpenSpec、職能別・金融特化のプラグイン集（knowledge-work-plugins・financial-services）、そして GPU なしで巨大 MoE を回す純 C の推論エンジン colibri といった尖った実装も伸びた。スキル流行の次として、記憶・オーケストレーション・仕様・縦展開という「運用の型」が一気に前景化した一週間だった。
