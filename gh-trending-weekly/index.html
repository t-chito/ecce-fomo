まとめ

今週の GitHub 週間トレンドは二つの流れが軸になった。ひとつは DeepSeek 4（Flash / PRO）の登場が呼んだローカル推論・コーディングエージェントの波。Redis 作者 antirez が C で書いた専用推論エンジン ds4（DwarfStar）、DeepSeek ネイティブのターミナルエージェント DeepSeek-Reasonix（週間 +4,203★）、単一 4GB GPU で 70B を動かす airllm（週間 +5,222★）が同じ週に並んだ。もうひとつは先週から続く「スキル」配布のさらなる拡大で、今週トップはセキュリティ／リバースエンジニアリング用のスキルルーター reverse-skill（週間 +10,091★・今週最大の伸び）。技術書をスキル化する book-to-skill、返答を要点先行に矯正する i-have-adhd も上位を維持した。さらにエージェントのチーム記憶を束ねる Tencent の TencentDB-Agent-Memory（週間 +6,444★）、人間とエージェントの協働基盤 block/buzz（継続）、Claude Cowork のオープン代替 openwork、Rust 製コードレビュー TUI tuicr、JVM 向けエージェント基盤 embabel-agent なども顔を出し、教材の定番 AI-For-Beginners も週間 +9,164★ と再燃した。

DeepSeek 4 が呼んだローカル推論・エージェントの波

antirez/ds4 — Redis 作者による DeepSeek 4 専用ローカル推論エンジン（週間 +1,319★ / 累計 2.1万★）

Redis の作者 Salvatore Sanfilippo（antirez）が公開した、コンシューマ機で大規模言語モデルをローカル実行するための推論エンジン。README では「DwarfStar」と名乗り、ページ上部の説明は「DeepSeek 4 Flash and PRO local inference engine for Metal, CUDA and ROCm」。クラウドに頼らず、DeepSeek V4 Flash / PRO と GLM 5.2 を手元のマシンやワークステーションで動かすことを狙う。

バックエンドは macOS を主対象とする Metal、マルチ GPU を含む NVIDIA CUDA、AMD Strix Halo 向けの ROCm。「自己完結していて、意図的に守備範囲を狭く取った、汎用の GGUF ランナーではない」設計を掲げ、モデルロード・プロンプト描画・ツール呼び出し・KV 状態管理・HTTP サーバー・コーディングエージェントを一体で作り込み・テストしている。128GB ラップトップや 512GB ワークステーションでの実行、テンソル／パイプライン並列による複数マシン分散といった用途を想定する。言語は C（CUDA・Metal 実装を含む）、ライセンスは MIT。汎用ランタイムを避けて特定モデルに特化する、という選択が今週の DeepSeek 熱を象徴する。

  • antirez/ds4

esengine/DeepSeek-Reasonix — DeepSeek ネイティブのターミナルエージェント（週間 +4,203★ / 累計 3.3万★）

ターミナル環境向けの AI コーディングエージェント。単一の静的 Go バイナリを土台に、設定とプラグインで駆動する構成を取る。ページ上部の説明は「A DeepSeek-native AI coding agent for your terminal. Engineered around prefix-cache stability — leave it running.」で、長時間セッションでのプレフィックスキャッシュ安定性を軸に、トークンコストを抑えて起動しっぱなしで使えることを狙う。

設定駆動・複数モデル対応・MCP サーバー経由のプラグイン駆動・文脈維持のためのキャッシュ意識・クロスプラットフォームのゼロフリクション配布を打ち出す。GitHub topics には coding-agent・deepseek・prompt-caching・r1・tui・tool-use などが並ぶ。主体は Go（VS Code 拡張は TypeScript）、ライセンスは MIT。ds4 が「動かす土台」なら、こちらは DeepSeek を前提に据えた「エージェント側」で、同じモデル世代の登場が両端を同時に押し上げた。

  • esengine/DeepSeek-Reasonix

lyogavin/airllm — 単一 4GB GPU で 70B 推論（週間 +5,222★ / 累計 3.0万★）

大規模言語モデルを最小の GPU メモリで動かすためのオープンソース推論フレームワーク。GPU 上に一度に 1 層だけを載せる方式で、推論時のメモリ要件を大きく削る。ページ上部の説明は「AirLLM 70B inference with single 4GB GPU」。

README は「量子化・蒸留・枝刈りを使わずに、70B の大規模言語モデルを単一の 4GB GPU カードで動かせるほど推論メモリ使用量を劇的に減らす」と説明する。topics には llama・llm・lora・qlora・chinese-llm などが並ぶ。主体は Python、ライセンスは Apache 2.0。既存プロジェクトだが、ローカルで大型モデルを動かしたい需要が高まる中で今週あらためて大きく伸び、DeepSeek 世代のローカル実行熱に乗った格好だ。

  • lyogavin/airllm

「スキル」配布はセキュリティまで広がる

zhaoxuya520/reverse-skill — セキュリティ／リバースエンジニアリングのスキルルーター（今週トップ・週間 +10,091★ / 累計 2.0万★）

今週いちばんスターを伸ばしたリポジトリ。Claude Code・Cursor・Cline などの AI エージェントを、サイバーセキュリティのタスクにおいて適切なツールとワークフローへ誘導する、ルーティングと方法論のパッケージ。ページ上部の説明は「Reverse Engineering / Authorized Penetration Testing / Security Research Skill Router Pack」で、AI ルーティング＋オンデマンドのツールチェーン・ブートストラップ＋自己進化する知識ベースを掲げる。

解決しようとするのは「エージェントがリバースエンジニアリング・ペネトレーションテスト・CTF に直面したとき、どのツールを使いどの手順を踏むべきかの指針を欠く」という課題。APK・バイナリ・.NET・JavaScript のリバースエンジニアリング、認可されたペネトレーションテスト、セキュリティ研究、CTF 競技を対象領域とし、自動ルーティング・ツール検出・反復可能なワークフローを提供する。主体は PowerShell／Python／Bash、ライセンスは MIT（CTF-Sandbox-Orchestrator サブモジュールは GPLv3）。先週まで「デザイン」「思考法」「書籍知識」へ広がったスキル配布の潮流が、今週はセキュリティ領域にまで及び、そのまま今週の首位を取った。

  • zhaoxuya520/reverse-skill

スキル配布の常連も継続 — book-to-skill・i-have-adhd

先週取り上げたスキル系も上位に残った。技術書 PDF をスキル化する virgiliojr94/book-to-skill（週間 +3,903★・累計 1.8万★）は、PDF・EPUB・DOCX などを章単位のオンデマンド読み込みに整理し、「本を丸ごと文脈に入れる場合の 24〜51 分の 1」のトークンで問い合わせに答えると謳う設計を維持。SKILL.md・章別ファイル・用語集・パターンカタログ・チートシートを生成し、Agent Skills 標準に準拠して複数プラットフォームで動く。返答を要点先行に矯正する ayghri/i-have-adhd（週間 +3,628★・累計 1.8万★）も、「まず行動」「番号付きの手順」「リストは 5 個まで」「前置きと締め文の排除」といった 10 の構造ルールを課す路線を保ち、Claude・Cursor・Gemini・Qwen・Kimi に対応する。どちらも MIT ライセンスで、スキルを配布物として磨く動きが今週も続いていることを示す。

エージェントの記憶と協働

TencentCloud/TencentDB-Agent-Memory — チーム単位のエージェント記憶ハブ（週間 +6,444★ / 累計 1.7万★）

AI エージェント向けに、会話・ドキュメント・コードを再利用可能な記憶資産へ変換する、チーム単位のメモリ管理システム。README では「会話・ドキュメント・コードを、Chat Memory・Skill・LLM-Wiki・Code-Graph という 4 つの再利用可能な記憶資産に変え、それらをガバナンスのもとでエージェントやフレームワーク横断に共有・装備する」と説明する。

狙いは、エージェントを使ったワークフローで繰り返し発生する作業を減らし、チームをまたいで永続的・体系的・共有可能な知識を作ること。topics には ai-agent・embedding・long-term-memory・memory・vector-search・local-first などが並ぶ。主体は JavaScript/TypeScript（npm パッケージあり）、ライセンスは MIT。エージェント「本体」の競争が一巡した先で、記憶をどう蓄え・共有するかという層に注目が移りつつあることを示す。

  • TencentCloud/TencentDB-Agent-Memory

block/buzz — 人間とエージェントが協働する自己ホスト基盤は今週も上位（継続・週間 +5,903★ / 累計 2.5万★）

先週の首位に続き今週も大きく伸びた、Block, Inc. 発の協働プラットフォーム。ページ上部の説明は「A hive mind communication platform」で、人間と AI エージェントが共有ルームで一緒に作業できる自己ホスト可能なワークスペースを提供する。Nostr リレーをベースにした統一イベントログと監査証跡を核に据える。

過去の経緯（レシート）付きで質問し、スコープ付き権限でエージェントに課題をトリアージさせ、機能ブランチを協働ルームに変え、会話をコードのパッチやワークフロー実行と一緒に検索し、エージェントに独自の暗号鍵を通じて人間と同じワークスペースアクセスを与える、といった機能を持つ。Rust ワークスペースとして Axum・PostgreSQL・Redis・S3/MinIO 上に構築され、NIP-01 Nostr プロトコル・認証・全文検索・監査ログ・マルチテナント分離を実装する。ライセンスは Apache 2.0。エージェントの協働を「どう記録し監査するか」という土台づくりが、今週も支持を集めた。

  • block/buzz

オープン代替とツール、そして教材の再燃

different-ai/openwork — Claude Cowork のオープンソース代替（週間 +2,939★ / 累計 2.1万★）

AI ワークフローを共有するための、無料・オープンソースのデスクトップアプリ。ページ上部の説明は「The open-source alternative to Claude Cowork (powered by opencode)」で、macOS・Windows・Linux に対応する。

ユーザーが AI のワークフロー・スキル・連携を作成・共有・再利用できるようにし、専用デスクトップアプリとして使うほか、MCP（Model Context Protocol）として Claude Code・Cursor・ChatGPT など他のエージェントとつなぐこともできる。主体は JavaScript/TypeScript（Electron ベース、pnpm ワークスペース構成）。商用のエージェント製品に対する「オープンな置き換え」を掲げるリポジトリが、今週も一定の支持を集めた。

  • different-ai/openwork

agavra/tuicr — vim キーバインドのコードレビュー TUI（週間 +741★ / 累計 2.5千★）

ターミナル上で動くコードレビュー用の TUI アプリ。ページ上部の説明は「a code review TUI with vim keybindings」で、README では「GitHub・GitLab・Bitbucket・クリップボードへエクスポートできる」と補う。GitHub 風の連続 diff をターミナルに表示し、行・範囲・ファイル・レビュー単位でのコメントに対応、レビューの進捗をセッション横断で追跡する。

git・jj（Jujutsu）・Mercurial に対応し、未コミットの変更・コミット範囲・プルリクエストのレビューをこなせる。レビュー結果は GitHub・GitLab・Bitbucket へ直接送れる。topics は code-review・rust・tui・ai-tools。主体は Rust、ライセンスは MIT。AI コードレビュー系が続くトレンドの中で、こちらは「人間が端末で素早くレビューする」側のツールとして伸びた。

  • agavra/tuicr

embabel/embabel-agent — JVM 向けのエージェントフレームワーク（週間 +154★ / 累計 4.0千★）

Java 仮想マシン（JVM）上でエージェント型 AI アプリを構築するためのフレームワーク。ページ上部の説明は「Agent framework for the JVM. Pronounced Em-BAY-bel」。README は「LLM を用いた対話と、コードやドメインモデルをシームレスに混ぜてエージェント的なフローを JVM 上で書く」ことを掲げ、直接 LLM API を叩くより高い抽象度を提供して、AI 対応のエンタープライズ Java アプリを作りやすくすることを狙う。

主体は Kotlin（Java 開発者にとって自然な使い方も想定）で、Spring Framework・Spring Boot 上に構築される。topics には agentic-ai・multi-agents-orchestration・java・kotlin・spring などが並ぶ。ライセンスは Apache 2.0。エージェント基盤が Python・Rust・Go 中心で語られがちな中、JVM／Spring 圏に軸足を置く数少ない選択肢として存在感を示した。
