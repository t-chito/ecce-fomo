まとめ

先週は「器から中身へ」——スキルそのものが上位に現れ始めた週だった。今週はそれが加速し、週間トレンドの上位を Agent Skills がほぼ占拠した。しかも中身の性格が変わった。これまでのように「特定領域の知識」を配るのではなく、エージェントの振る舞いそのものを矯正するスキルが上位に並んだのが今週の中心だ。答えを埋もれさせず要点から返させる i-have-adhd、「一番怠けたシニア」のように書かせず不要なコードを書かせない ponytail、AI 特有の文体を消す humanizer——いずれも「何を知っているか」ではなく「どう振る舞うか」を仕込む。ふたつめの軸はドメイン特化のスキル束で、38 種の編集品質な図を生む diagram-design、マーケ一式の marketingskills が伸び、先週トップの archify も残った。みっつめはスキルを束ねる土台——メタハーネスの ECC と、文脈を 98% 圧縮する context-mode。加えて OpenAI と Anthropic の公式スキルカタログが揃ってトレンド入りし、ブラウザ・ファイル変換・動画生成といったエージェントの「手足」（chrome-devtools-mcp・markitdown・hyperframes）も並走した。エージェントに「知識」を配る段から、「作法と人格」を配る段へ——トレンドの主役がもう一段降りてきた一週間だった。
