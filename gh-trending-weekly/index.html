今週の筆頭 — 手元のエージェントを外から操る

pingdotgg/t3code — 手元のコーディングエージェントをスマホから操作する

自分のパソコンで動くコーディングエージェントを、スマホ・Web・デスクトップから操作するための制御層である。Claude Code や Codex、Cursor など対応 CLI を入れてサインインすると、t3code がそれを動かす。サーバーは背後で動き、外出先の端末からの遠隔操作にも対応する。README はまだ初期段階でバグが出る前提だと断り、外部からの大きな機能追加は受け付けないとする。週間で約16,200★を集め首位に立った。

エージェントに記憶とスキルを与える

thedotmack/claude-mem — セッションをまたいで文脈を覚えさせる

コーディングエージェントにセッションをまたぐ記憶を与えるツールである。作業中の操作をフックで捕え、AI で要約して SQLite に蓄え、次のセッションに関連する文脈を差し戻す。検索・時系列・詳細取得の三段で候補を絞ってから読むため、トークン消費を約10分の1に抑えられるとうたう。npm 版はライブラリのみでフックや常駐サービスは入らず、導入は npx か /plugin から行う。クラウド同期や画像解析は任意で既定は無効。週間で約9,300★。

anthropics/skills — Agent Skills の公式サンプル集

AI 臭い出力を避ける

Nutlope/hallmark — AI 臭いデザインを検査で弾くスキル

コーディングエージェントにデザインの語彙を与え、機械的に作ったような Web ページを避けさせるスキルである。50 種の「素材」から指示に合う 3 つを選んで作り、ship を止める床・理由で覆せる既定・止めない仕上げの三段で質を検査する。sloplint は 8 つの画面幅でブラウザ描画を調べ、別文脈のサブエージェントが結果を見直す。README はブラウザ検査には puppeteer-core と Chrome が要るとし、スキルが自動で発火しないことがあるとして名指しを促す。週間で約7,000★。

並行作業とレビューの土台

max-sixty/worktrunk — 並行作業向けに git worktree を使いやすくする

並行作業向けに git worktree を扱いやすくする CLI である。worktree はタスクごとに独立した作業ディレクトリを与える仕組みで、これをブランチ名で指し、switch・list・merge・remove の少数の操作で扱う。フックや共有ビルドキャッシュを持ち、複数の AI エージェントを同時に走らせる用途を想定する。ディレクトリ移動にはシェル統合の導入が要る。wt は Windows Terminal のコマンドと衝突するため、Winget 版は git-wt として入る。主要言語は Rust。週間で約1,800★。

LLM にプルリクエストをレビューさせ、質問にも答えさせるオープンソースのツールである。GitHub Action・CLI・Docker・Webhook で動き、GitHub や GitLab などに対応する。/describe・/review・/improve・/ask が各 1 回の LLM 呼び出しで動き、大きな PR は圧縮して扱う。今トレンドに入った背景には、Qodo がこのプロジェクトをオープンソースコミュニティに寄贈したことがある。PR-Agent org へ移り、Docker の公開先も pragent/pr-agent に変わった。週間で約1,400★。
