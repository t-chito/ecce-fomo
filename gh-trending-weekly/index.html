エージェントにブラウザとデスクトップを操らせる

Vercel が AI エージェント用のブラウザ操作 CLI を公開

AI エージェントに、一度に一つのコマンドで動かせるブラウザを与える Rust 製の CLI である。snapshot でページを簡潔なテキストにし、要素ごとに @e1 のような参照を振る。エージェントはその参照を指して操作し、ページを読み直して結果を確かめ、これを繰り返す。ブラウザはコマンド間で開いたままなので、各手順は短いシェル呼び出し一つで済む。背後の常駐プロセスが Chrome DevTools Protocol で制御し、MCP サーバーとしても起動できる。週間で約4,600★。
