まとめ

先週は「プラグイン／スキルの市場」が主役だったが、今週はその市場に並ぶスキルそのものが一気に上位を占めた。象徴は週間トップの archify——アーキテクチャ図をエージェントに描かせる Agent Skill が単独で 週間 +2.4万★ を集め、2 位以下を大きく引き離した。165 個の検証済みスキルで「AI を科学者にする」scientific-agent-skills、AI に現代的な Go を書かせる JetBrains の go-modern-guidelines、MCP サーバーのカタログ awesome-mcp-servers と、「エージェントに特定領域の作法を教える部品」が並んだ。ふたつめの軸は商用 SaaS を OSS で置き換えるで、Semrush/Ahrefs 代替の open-seo と ElevenLabs 代替の VoiceStudio が揃って伸びた。みっつめはモデルを自分の手で——64M の LLM をゼロから 2 時間で学習する minimind、Google の時系列基盤モデル timesfm、安全アライメントを自動除去する heretic。加えて、実データを載せた 3D 地球儀 gods-eye-view やマルチエージェント教室 OpenMAIC といったブラウザで体験させるデモが揃って週間 +1万★ を記録した。「エージェントに何をさせるか」を配る流れが、先週の器から中身へと降りてきた一週間だった。
