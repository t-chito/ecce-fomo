まとめ

先週はエージェントの「振る舞い」を仕込む単体スキルが週間トレンドを席巻した。今週はその熱が続きつつ、上位の顔ぶれが一気に広がったのが特徴だ。週間の伸びで首位に立ったのはスキルでも開発ツールでもなく、ブラウザ上でリアルタイムの空間情報を可視化する「スパイ衛星シミュレーター」gods-eye-view——AI 一色だった前週から、純粋に「動かして楽しい」バイラルなプロダクトが最上位に戻ってきた。二番手にはアリババが自社規模で鍛えた本番投入級の AI コードレビュー open-code-review が食い込み、エージェントが「書く」段から「レビューする」段へ進んだことを示した。三つめの軸はスキル／プラグインのカタログ化・公式化で、OpenAI の plugins、Anthropic の knowledge-work-plugins といったベンダー公式のカタログと、agent-skills・superpowers のような大型フレームワークが揃って上位に並んだ。前週トップだった振る舞い矯正系（i-have-adhd・humanizer）も勢いを保ち、並列開発の worktrunk、企業向け RAG の WeKnora といったエージェントの開発基盤も伸びた。単体スキルの流行が、配布の仕組みと本番ワークフローへと一段厚みを増した一週間だった。

今週の首位級 — バイラルと「本番投入」

bilawalsidhu/gods-eye-view — 実データで動く「スパイ衛星」シミュレーターが週間トップ（週間 約1.4万★）

About は「A spy satellite simulator in your browser, except the data is real. Live open source spatial intelligence on a photorealistic 3D globe.」。フォトリアルな 3D 地球儀の上に、航空機・船舶・衛星・地震・火災・カメラといった公開データをリアルタイムに重ねて可視化するブラウザアプリで、今週は週間の伸びで全体の首位に立った。

README によれば、1 万機超の航空機や 838 個の衛星カタログ、船舶や地震活動をライブのレイヤーとして表示し、追跡中の機体の内側に入り込む「コックピットモード」（地形との衝突判定つき）や、NVG・FLIR サーマル・CRT・ノワールといった複数のセンサー描画モードを備える。28 のツールを持つ AI エージェントによる音声操作でナビゲーションや注記・照会を行い、経路の描画や距離計測、公開 CCTV の 3D 地形への投影もできる。技術的には CesiumJS と Google 3D Tiles、素の JavaScript の上に構築され、SGP4 で衛星軌道を伝播し、データ点の間を補間して滑らかに動かす。多くのレイヤーは認証不要で動き、任意のキーで追加機能が開く。topics には osint・cesium・satellite-tracking・geospatial-intelligence などが並ぶ。AI 系が上位を占める中で、純粋に体験として強いプロダクトが週間トップを取った点が今週の象徴だった。

About は「Secure, fast, efficient, battle-tested at Alibaba's scale. max-sixty/worktrunk — 並列エージェント向けに git worktree を扱いやすくする CLI（週間 約1,100★）

About は「Worktrunk is a CLI for Git worktree management, designed for parallel AI agent workflows」。Git ネイティブの worktree の使い勝手の悪さを、ブランチ管理並みの手軽さへと引き下げるツールで、複数の AI エージェントを並行して走らせる用途に特化している。

README によれば、switch・list・remove の 3 コマンドで worktree 操作を単純化し、worktree をファイルパスではなくブランチ名で指定する。設定可能なテンプレートからのパス自動算出、post-create／pre-merge／post-merge のフック、差分からの LLM によるコミットメッセージ生成、CI 状態や PR プレビュー付きの対話的ブランチ選択、worktree 間で共有するビルドキャッシュ、PR ブランチへの直接チェックアウト、worktree ごとの開発サーバーなどを備える。-x フラグで作成と同時にエージェントを起動できる。primary language は Rust、topics は agents・claude-code・codex・worktrees など。並列エージェントが増える中で、各エージェントの作業ディレクトリを衝突なく分離する基盤側の需要を捉えた一本。
