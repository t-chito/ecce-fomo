まとめ

今週の GitHub 週間トレンドは、先週の「図・記憶・実行環境」といったエージェント周辺インフラへの関心が、はっきりと「プラグイン／スキルの市場」へと形を変えた一週間だった。象徴は Anthropic 自身が公開した公式のコミュニティ・プラグイン集 claude-plugins-community と、Cursor の cursor/plugins。加えて 530 件超の画像プロンプトを「Prompt as Code」＋ Skills として束ねた awesome-gpt-image-2 が週間 +1.1万★ を集め、「エージェントに何をさせるか」をパッケージ化して配る流れが一気に可視化された。ふたつめの軸は「無料で動かす」で、週間トップの伸びを見せた本家 openai/codex の隣に、無料トークンをまとめて配る free-claude-code・freellmapi が並んだ。みっつめはローカルファーストなエージェント基盤と記憶で、Apache インキュベータ入りした apache/maka、個人向け AI を謳う openhuman、先週から続く OpenViking が同じ潮流に乗る。omarchy・OpenLogi・PostHog・modular といった AI 一色でない実務ツールも高い伸びを保った。エージェント「本体」から「本体に差し込む部品と、それを配る場所」へ——重心が市場・エコシステム側へ移ったのが、今週の見どころだった。

今週の中心 — コーディングエージェントの「プラグイン／スキル市場」

anthropics/claude-plugins-community — Anthropic 公式のコミュニティ・プラグイン市場（週間 +2,069★ / 累計 2.5千★）

ページ上部の説明は「Community plugin marketplace for Claude Cowork and Claude Code. Read-only mirror — submit plugins at clau.de/plugin-directory-submission.」。Claude Cowork と Claude Code 向けの、コミュニティ製プラグインを集めた公式マーケットプレイスの読み取り専用ミラー。自動セキュリティスキャンと Anthropic の審査を通ったプラグインが並ぶ。

ユーザーは claude.com/plugins や Claude Code CLI からここのプラグインを導入でき、投稿は専用の申請ポータルを経由する設計。ベンダー自身が「エージェントに機能を追加する部品を集めて配る場所」を公式に立ち上げたことを示すリポジトリで、公開直後から一気にスターを伸ばした。エージェントの拡張が個々のツールではなく「マーケットプレイス」という単位で流通し始めた、今週を象徴する 1 本。

  • anthropics/claude-plugins-community

cursor/plugins — Cursor 公式のプラグイン仕様とプラグイン集（週間 +1,732★ / 累計 5.8千★）

ページ上部の説明は「Cursor plugin specification and official plugins」。AI コードエディタ Cursor 向けの、公式プラグイン仕様と各種公式プラグインをまとめたリポジトリ。GitHub・Playwright から Salesforce・HubSpot まで、開発ツールや SaaS 製品ごとにディレクトリを分け、それぞれにマニフェストを持つ構成で提供される。

各プラグインは Skills・ルール・MCP サーバー定義を含む標準化された構造に従い、エージェントが外部システムと連携できるようにする。主体は TypeScript。Anthropic の公式マーケットプレイスと同じ週に伸びたことで、「コーディングエージェントに拡張を差し込む標準」を各ベンダーが競って整備し始めた構図がはっきり見えた。

freestylefly/awesome-gpt-image-2 — 画像プロンプトを「Prompt as Code」＋ Skills 化した工業級テンプレート集（週間 +11,300★ / 累計 2.4万★）

ページ上部の説明は「Prompt as Code | GPT-Image2 工业级提示词引擎与模板库，530+ 个案例逆向工程，20+ 套工业级模板，并提炼出Skills，持续更新中」。GPT-Image2 向けに、530 件超のコミュニティ事例を逆解析して構造化した、再利用可能な画像生成プロンプトのテンプレート集。

「無料で動かす」— コーディングエージェント本体と無料 API 集約

openai/codex — ターミナルで動く軽量コーディングエージェント（今週トップ級・週間 +12,358★ / 累計 11.9万★）

npm や Homebrew でインストールし、codex と打てばコーディング支援が始まる。主体は Rust。累計 11万★超の本家が今週さらに週間で最大級の伸びを記録し、「エージェント本体そのもの」への需要が依然として最上位にあることを示した。周辺のプラグイン市場が賑わう一方で、その受け皿となる本体が同じ週にトップを走った点が対照的だった。

  • openai/codex

ページ上部の説明は「7.4 billion tokens per month. 34 free LLM providers. 635 free model endpoints. All behind one /v1 endpoint, plus any custom OpenAI-compatible endpoint. Smart routing, automatic failover, encrypted keys. Personal experimentation only.」。34 のプロバイダが提供する無料枠を、OpenAI 互換の単一エンドポイントに集約する API ルーター。
