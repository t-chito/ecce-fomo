まとめ

今週の LLM 業界は、先週まで「評価中に AI がうっかり枠を越えた」という偶発の事故だったサイバー問題が、「フロンティアのサイバー能力を統治のもとで防御に振り向ける」という意図的な段階へ一気に進んだ一週間だった。OpenAI は次期モデル Astra を Preparedness Framework で自社初の「critical（重大）」に分類して一般公開を減速し、同時に防御者向けの GPT-5.6-Cyber と Daybreak プログラム拡張を投入、Chrome の V8 エンジンに実在の脆弱性（CVE-2026-15903）まで見つけた。Anthropic は Claude Code の auto mode をデフォルト化し、プロンプトインジェクション耐性を「未知の攻撃でほぼゼロ」に近づけたと主張。sama は「自分のシステムを守るために我々のモデルを使ってほしい」と呼びかけた。能力の側では、Anthropic の未公開研究版 Claude が Riemann ゼータ関数の下界を 41.6%→67.2% に更新し、先週の OpenAI・Astra の数学成果に応じる形で「AI が一次研究に踏み込む」流れが続いた。加えて Gemini アプリが月間 10 億ユーザーに到達、GPT-5.6 Sol が ChatGPT 全チャットの土台になり、Grok Imagine Image 2.0 が登場——安全・能力・普及が同じ週に凝縮した。

今週の重要ポイント

OpenAI が Astra を自社初の「critical」サイバーモデルに分類 — 公開を減速

OpenAI は 8/7、次期モデル Astra を Preparedness Framework の下で自社初の「critical（重大）」サイバーリスクに該当すると評価し、一般公開を意図的に遅らせると公表した。「critical」の閾値は、多数の堅牢な実システムに対して人手を介さずゼロデイ脆弱性を発見・実装できる、あるいは高レベルの目標だけを与えられて堅牢な標的への攻撃を端から端まで自律遂行できる水準を指す。OpenAI は「想定していたシナリオ」として、隔離テスト環境・ネットワークとツールの制限・モデル重みの暗号化強化・追加監視といった管理を敷き、政府機関や独立系の AI 安全団体と連携して能力検証と対策を固めるとした。sama は「Astra は強力なモデルで、一般提供へ向け作業中。強力なモデルを一部の者だけに囲い込むのは良い戦略ではないが、そのサイバー能力ゆえに安全に出すにはもう少しだけ時間が要る」と述べた。先週 Astra が数学の未解決問題を解いて注目された同じモデルが、今週は「速く出すより、安全に出す」判断の象徴になった。

GPT-5.6-Cyber と Daybreak 拡張 — フロンティア・サイバーを「防御者の手に先に」

Astra を囲い込む一方で、OpenAI は 8/10、認可された防御者向けの専用モデル GPT-5.6-Cyber を投入し、サイバー防衛イニシアチブ「Daybreak」を拡張した。Daybreak Blue はシステムレベルのガードレールを外した GPT-5.6 Sol を提供し脆弱性発見・マルウェア解析・インシデント対応などの防御作業を支援、Daybreak Red は攻撃検証・脆弱性研究に特化訓練したモデル（GPT-5.6-Cyber）を経験ある防御者に開放する。社内評価では、GPT-5.6-Cyber がエクスプロイトチェーン構築や権限昇格など高度なサイバー要求の 95% に応えたのに対し、通常の Sol は 1.5%、Daybreak Blue 版は 2% にとどまった。実運用では Chrome の V8 エンジンに未知の脆弱性 2 件（連鎖でメモリ破壊・サンドボックス脱出が可能）を発見し、Google に協調開示、CVE-2026-15903 として修正された。提供は Accenture・IBM・CrowdStrike・Cloudflare など信頼できるパートナーに限定。gdb は「防御の窓が狭まるなか、攻撃者が展開する前にフロンティアの知能を防御者の手に」と述べ、sama も別途「自分のシステムを守るために我々のモデルを使ってほしい」と呼びかけた。

  • Sam Altman (X) — please consider using our models to help defend your systems

未公開 Claude が Riemann 予想の下界を 41.6%→67.2% に更新 — AI × 数学が続く

Anthropic は 8/10、未公開の研究版 Claude に Riemann 予想へ挑ませ、予想を満たすゼータ関数の非自明零点の割合の下界を 41.6% から 67.2% へ引き上げたと公表した。Riemann 予想そのもの（1859 年提起・懸賞 100 万ドル）の証明には至らず、Anthropic も「この技術的アプローチで完全証明は期待できない」と明言するが、長年動かなかった関連問題を実際に前進させた点が注目された。過程も象徴的で、非数学者の社員が「本気で一発やってみて」と促し、あとの数学的判断はモデルに委ねた。Claude は最初に 650 個のアイデアを生成してすべて外し、2 セッション・計 3,100 万出力トークンを Claude Code 上で費やし、約 60 個のサブエージェントを束ねて並列探索と既存研究の再結合を行って新しい下界に到達した。Anthropic の数学者 2 名が論文を検証し、専門家向けの略式ノートも作成。先週 OpenAI・Astra が未解決問題を解いたのに続き、フロンティア 2 社がそろって研究水準の数学成果を示した週になった。

  • Anthropic — Learning more about Claude's mathematical capabilities
  • Anthropic (X) — We asked an unreleased research version of Claude to take a stab at the Riemann hypothesis

Claude Code が auto mode をデフォルト化 — セッション間通信も追加

先週「Claude Code の沈黙が最長」と噂された Anthropic は、今週まとめて動いた。8/14 から Pro・Max・Team の新規セッションで auto mode（自動許可）をデフォルト化し、あらゆるツール呼び出しを別モデルの分類器が事前レビューして、要求を越える動作・見知らぬインフラへの接続・敵対的な入力に誘導された挙動をブロックする。1,053 名の有料テスターによる実験で、意図的な危険コマンドを auto mode が 89% 捕捉したのに対し人手のレビューは 13.6%（50 回目以降は約 5%）にとどまり、Anthropic は「人が全部承認するより安全」と主張。分類器の追加トークンは Pro・Max・Team では利用上限に計上しない。あわせて Claude Code のセッション同士が互いにメッセージを送れる機能（履歴やファイルではなく要約を渡し、相手が作業の途中で引き継ぐ）を追加し、self-hosted runner や Managed Agents 強化とあわせ非同期・長時間の自律実行へ舵を切った。bcherny は「モデル訓練＋入力プローブ＋意図を確認する分類器を重ねれば、未知の攻撃でも間接プロンプトインジェクションをほぼゼロにできる。1 年前には予想しなかった」と述べた。

モデルとプロダクトの普及

GPT-5.6 Sol が ChatGPT 全チャットの土台に — 無料枠に無制限 Luna も

OpenAI は 8/6、GPT-5.6 Sol を Plus・Pro の Instant と深い推論の両方の土台にし、ChatGPT のチャット体験を一本化した。高難度の事実性評価（金融・医療・法律）では GPT-5.5 Instant 比で事実誤りを含む応答が 68% 減。Plus・Pro には推論の強度を選べるスライダーを追加し、無料・Go ユーザーには GPT-5.6 Luna での無制限テキストチャットと「Think」ボタンを開放した。sama は「Sol はチャットでかなり良くなった。無料ユーザーにも無制限チャットを」と自賛。先週の GPT-5.6 大幅値下げに続き、フロンティアの知能を上位からアクセス側へ一段下ろす動きが続いている。あわせて 8/11 には ChatGPT デスクトップアプリの Linux 版（Ubuntu・Debian・Fedora 向け .deb/.rpm）をプレビュー公開し、開発者の作業環境への浸透を広げた。

Gemini アプリが月間 10 億ユーザー — Google 史上最速成長

Google の Gemini アプリが月間アクティブユーザー 10 億に到達し、同社史上最速で成長したプロダクトになった。2025 年 10 月の 6.5 億から 1 年足らずで到達し、Search・Gmail・Android などに並ぶ Google 14 番目の「10 億ユーザー製品」となる。OpenAI の ChatGPT が今年 6 月に 10 億に達したのに続く節目で、音声（利用の 63%）やカメラ・画面共有といったライブ機能が牽引した。Demis Hassabis は「我々の最速成長プロダクト」と祝い、Logan Kilpatrick は「Gemma ファミリーも累計 10 億ダウンロード」と添えた。あわせて Gemini Omni の動画生成無償枠を期限まで延長するなど、消費者面でも攻勢を続けた。フロンティアの競争が能力だけでなく到達規模でも二強（OpenAI・Google）に収れんしつつある。

xAI が Grok Imagine Image 2.0 を投入 — 画像生成・編集で世界 2 位

xAI は 8/7、次世代画像モデル Grok Imagine Image 2.0 を Grok の新「Quality Mode」として一般提供した。精密な部分編集・鮮明な文字描画・事実性の向上を掲げ、デザイナーのようにタイポグラフィとレイアウトを設計するため、要素の多い複雑な画像でも崩れず小さな文字もはっきり出力する。編集ツールは指定領域だけを変える Magic Wand、精密選択の Segmentation、任意アスペクト比の Smart Resize を備え、1 回の生成で最大 5 枚の参照画像を渡せる。Arena ではテキスト→画像・画像編集の双方で世界 2 位（首位は OpenAI の GPT-Image-2）にランクインし、週後半には API も開放。あわせて Grok は音声に 21 の新ボイスと Voice コネクタ（メール・予定の読み上げ、日次ブリーフ自動化）を全プラットフォームへ広げ、マルチモーダルの実用機能でフロンティアを追う姿勢を鮮明にした。

エージェント基盤・開発ツールの自律化

守りと運用の作り込み — Managed Agents・Codex セキュリティレビュー・Devin

攻撃能力の統治（前述）と並んで、防御側・運用側のツール整備が進んだ。Anthropic は Claude Managed Agents に 4 つの更新——セッション予算の上限設定（到達で自動一時停止・増額で再開）、作業中に強いモデルへ助言を求める「advisor」、添付リポジトリの `.claude/skills/` からのスキル読み込み、推論リージョン（US/global）の指定——を投入した。OpenAI 側は Codex が GitHub の全プルリクにインラインでセキュリティレビューを実施できるようにし、Codex CLI にも Agent Plugins と自動承認フラグを追加。「コードと企業の安全性を高める全体イニシアチブの一環」と位置づけた。Cognition の Devin は Vercel Sandbox 上で「Outposts」を実行し、隔離マイクロ VM で Docker 実行・VPN 接続・スナップショット再開に対応。「クラウドエージェントが寝ている間に働く」非同期開発の実例が各社から示され、auto mode の常用や long-horizon タスクを前提にした運用設計が広がった。

安全・ガバナンスの制度化

透かし・生物学ガードレール・若年層メンタルヘルス — 制度対応が具体化

能力競争の裏で、ルールへの実装も進んだ。Anthropic は Claude が生成する全テキストに埋め込み型の透かし（watermarking）を入れると発表。EU AI Act への対応の一環で、他社も同様の透かしを追加しつつあり、たとえば「その PR が Claude Code 由来か」を検証できるようになる（限界はあると但し書き）。あわせて統計的な偏りを秘密鍵で検査するテキスト検出 API も提供予定という。安全側の調整では、Anthropic が Claude Fable 5 の生物学セーフガードを更新し、誤検知を約 85% 削減——日常的な健康・教育の質問に広く答えられるようにしつつ、ウイルス学・毒性学・分子設計などデュアルユース要求は引き続き Opus 5 へフォールバックさせ、専門的な創薬用途には開かない設計を維持した。OpenAI は 米国心理学会（APA）と提携し、若年層のメンタルヘルスに関する証拠ベースの指針・セーフガードづくりに乗り出した。能力の一般化と歩調を合わせ、透明性・安全・年齢配慮の「制度側」の手当てが同じ週に束で出た。

  • Claude (X) — Updating Claude Fable 5's biology safeguards to reduce false positives
  • OpenAI Newsroom (X) — Working with the American Psychological Association on AI and youth mental health

来週の注目ポイント

最大の観測点は「critical」宣言後の Astra の行方。一般公開の時期、政府機関・独立系 AI 安全団体との能力検証、隔離テスト環境や重み保護の具体像を追いたい。防御面では、Daybreak／GPT-5.6-Cyber の実運用の広がりと、Anthropic・Google など他社の防御向けサイバーモデルの追随、V8 のような実脆弱性発見の続報が焦点。ツールでは 8/14 の Claude Code auto mode デフォルト化後の現場の反応と、セッション間通信・Managed Agents を使った非同期開発の定着度。研究面では、Riemann 下界更新に対する数学界の追試・検証と、AI-for-math が「検証可能な一次研究」としてどこまで受け入れられるか。制度面では EU AI Act 対応の透かし・検出 API の実装と各社の足並み。そして普及面では、10 億ユーザーに乗った Gemini の次の一手と GPT-5.6 Sol／Grok Image 2.0 を軸にしたプロダクト競争の続きが注目される。
