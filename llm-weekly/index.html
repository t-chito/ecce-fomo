モデルリリース

Anthropic が Haiku 5.5 を公開、Haiku 4.5 比で約 75% 安い小型モデル

Anthropic は小型モデル Claude Haiku 5.5 を公開した。これまでで最も安く速い小型モデルで、実行コストは平均で Haiku 4.5 比 約 75% 減という。

Haiku 系で初めてコストと知能を切り替える effort 設定を持ち、1M トークンの文脈に対応する。AWS・Google Cloud・Azure を含む全主要基盤で使え、高頻度・低コストの処理や上位モデルのサブエージェント用途を狙う。小型モデルの価格と速度の競争が一段進んだ。

出典（4）

  • Claude (X) — First Haiku with an adjustable effort setting, to optimize for cost or intelligence
  • Claude Developers (X) — Haiku 5.5 now available in the Claude Platform and Claude Code, pairs with Opus 5.5 or Sonnet 5.5
  • Cognition (X) — Haiku 5.5 scores 58.4% on FrontierCode 1.1, ahead of Sonnet 5 at ~1/8 the cost

OpenAI が GPT-6 を一般提供、回答に対話的 UI を生成する機能を追加

OpenAI は GPT-6 を ChatGPT の全ユーザーへ広げ、あわせて Intelligent UI を導入した。回答をテキストだけでなく、グラフや図、押せるボタンやフォーム、その場で使える小さな道具として組み立てる。

有料層では GPT-6 Sol、無料層では GPT-6 Luna が動く。検索や質問応答が、読む情報から操作できる画面へと変わりつつある。

推論の価格競争

小型モデルと長時間処理に価格引き下げが波及

モデルの値下げが、小型モデルと長時間動くエージェントの両方に及んだ。Anthropic は Haiku 5.5 を安く出し、Sonnet 5.5 のキャッシュ読み出しを半額（$0.10／百万トークン）にして、長い処理を約 20% 安くした。

あわせて Max・Team プランに毎月の API クレジットを付け、自分のコードや他社ツールでも使えるようにした。トークン単価の下げ合いが、使い方の幅を広げている。

項目価格（百万トークンあたり）
Haiku 5.5（10 万トークン未満）入力 $0.10 / 出力 $0.50（キャッシュ読み出し $0.01）
Haiku 5.5（10 万トークン超）入力 $0.50 / 出力 $2.50（キャッシュ読み出し $0.05）
Sonnet 5.5 キャッシュ読み出し$0.50 → $0.10（約半額、処理が約 20% 安く）
月次 API クレジットMax 5x $100 / Max 20x $200 / Team 最大 $500（共用）

エージェント・開発基盤

複数エージェントのオーケストレーションが各社で製品化

作業を多数のエージェントに分けて進める仕組みが、相次いで製品になった。Anthropic は Claude Managed Agents の動的ワークフローを公開ベータにした。親エージェントが計画を立て、最大 1,000 体を段階的に動かして結果を束ねる。

社内試験では、仕込んだ 70 個のバグを単体エージェントが 14〜27 個、ワークフローは 66 個見つけた。Cognition も Devin に同種の動的ワークフローを入れ、Claude Code Projects も並列スレッドでタスクを同時に進める形で公開ベータに入った。賢さに続き、仕事の割り振り方が差になりつつある。

出典（4）
  • Claude Developers (X) — Claude Managed Agents dynamic workflows now in public beta
  • Claude Developers (X) — 70 planted bugs: a single agent found 14/15/27, a workflow found 66 each run
  • Claude Developers (X) — Claude Code Projects now open to Pro and Max users
  • Devin (X) — Dynamic workflows let Devin split a job across its own Devins

自社開発インフラ

Anthropic が独自ソース管理 Scion を自作、マージ急増に対応

Anthropic はエンジニアリングブログで、自社で作ったソース管理システム Scion を紹介した。AI 支援開発でコード変更が急増し、日次のマージは 5 月の約 2,500 件から 9 月には 3 万件超へ伸び、人間規模で作られた開発基盤が追いつかなくなった。

そこで Git から独自システムへ、モノレポを 5 か月で全面移行したという。モデルを作る側自身の開発の進め方が、エージェント前提に組み替わっている。

  • oikon48 (X) — Anthropic built its own source control "Scion" and migrated its monorepo in five months

セキュリティ・サイバー防衛

OpenAI のモデルが Chrome の重大な脆弱性を発見

OpenAI の Greg Brockman は、同社のモデル GPT-5.6 Sol が Chrome の重大な脆弱性を見つけたと述べた。6 日・約 4 万ドルの計算資源をかけ、Google の 2026 年で初となる full-chain 報奨を得たという。推計で 10 億人規模の利用者に影響しうる欠陥で、防御側がこうしたツールを使う好機だと位置づけた。モデルの能力が攻防の両面で実務に入り込んでいる。
