モデルリリース

Google が Gemini 4 Argon を公開、まず政府とサイバー防衛向け

Google は新しいフロンティアモデル Gemini 4 Argon を発表した。長時間・複雑なワークフローでの深い推論を掲げ、ソフトウェア開発・法務・金融・サイバー防衛を主な対象とする。出力上限は 64K から 100 万トークンへ引き上げられた。

展開は段階的で、まず米政府と信頼できるサイバー防衛組織に Fairwind Program 経由で配布する。導入価格は入力 $2・出力 $10（百万トークン、期間後は $4・$20）で、Anthropic・OpenAI の同格モデルを下回る。Pichai は「フロンティアの安全策を備え、責任ある形で出す」と述べた。あわせて計画していた 3.5 Pro は取りやめた。

推論インフラ・ハードウェア

Cognition が NVIDIA Vera Rubin を初採用、SWE-2 推論で GB200 比 4.8 倍

Cognition が CoreWeave 経由で NVIDIA の新型 Vera Rubin を業界で初めて本番運用に乗せた。SWE-2 の推論で、同じデコード速度のまま GB200 比 約 4.8 倍のトークンスループットを得たという。エージェントの常時稼働が広がるなか、推論の速度とコストを左右する新世代チップの投入が前倒しで進む。OpenAI も Cerebras を「速度のフロンティアを押し広げる近い協業先」と位置づけており、専用ハードでの高速化が競争の一軸になっている。

  • Sam Altman (X) — Cerebras is a close partner on the frontiers of speed

エージェント・開発基盤

Claude Code が Mod 対応、挙動と UI をユーザーが書き換え可能に

Anthropic は Claude Code を利用者が改造できる Mod に対応させた。数行の TypeScriptで挙動の変更・UI のカスタマイズ・独自機能の追加ができ、Mod はプラグインとして配布・インストールする。

公式も例を複数公開した。出力を監視して見落としを拾う「You should Know」、文脈ウィンドウの残量を可視化する Token Weather、rm -rf などの危険なシェルコマンドを実行前に止める Blast Radius などで、いずれも作業の抜けや事故を減らす方向だ。あわせて開発者向けの新しい情報サイトも開設した。エージェントそのものを各人の作業に合わせて作り替える流れが強まっている。

  • Claude Developers (X) — New plugin: You should Know, surfaces info you might miss
  • Claude Developers (X) — Blast Radius catches risky shell commands before they run
  • Claude Developers (X) — Our new home for developers building with Claude

Claude が Google Workspace に常駐、ファイルを横で直接編集

Anthropic は Claude を Google ドキュメント・スプレッドシート・スライドの中で動かせるようにした。Claude はファイルの横のサイドバーに座り、開いている内容を読んで、その場で編集する。変更は 1 つずつ承認してから反映でき、アクセス範囲は Google 側の共有権限に従う。全有料プランでベータ提供。生成 AI が既存の業務スイートに入り込んで作業を代替する動きが、主要プロバイダ発で本格化している。

出典（2）
  • Claude (X) — Claude now works inside Google Docs, Sheets, and Slides
  • Claude (X) — Files open beside the chat; access follows your Google sharing permissions

エージェントの「記憶」が競争軸に、Devin が OSS 標準を提唱

Cognition は Devin にセッションをまたいで利用者の進め方を記録する Dreaming を導入した。夜間に記憶を自己改善し、古い記録を整理して隠れた情報を見つける。あわせて記憶形式を OSS 標準 Agent Memory Repo として公開し、グラフ構造・履歴付きの更新・git と Markdown での管理を、Devin 以外のエージェントでも使えるようにした。モデルの賢さに続いて、作業文脈をどう溜め、再利用するかがエージェントの差になりつつある。

リサーチ・ベンチマーク・AI for Science

OpenAI が内部モデルで新しい数学の結果、IAS の助言群と公開準備

OpenAI は社内のフロンティアモデルが生み出した多数の新しい数学の結果を公表すると表明した。報道では、Navier-Stokes に関する主張に加え、未解決問題を 100 件超解いたとされる。

公開にあたっては Princeton の高等研究所（IAS）に置かれた数学・AI 諮問グループ（Gowers、Witten、Hairer ら 9 名）に助言を仰ぐ。ただし同グループは無報酬で研究ペースへの権限はなく、当面の役割は未公開結果の公開を調整することにとどまる。Altman は「発見の新しい時代に入りつつある」と述べた。能力の検証と公開の手続きを外部の専門家で支える形が試されている。

ガバナンス・安全・信頼

OpenAI がテキストにも来歴の透かし、EU 規制に対応

OpenAI は画像・音声に続き、生成テキストにも来歴（provenance）を示す取り組みを広げると発表した。EU の規制要件への対応で、生成時にテキストへ統計的な信号を埋め込む。ただし短い文では検出が難しく、書き換えや翻訳で消える限界も自ら認めた。検出器は当面、承認された研究者にのみ提供する。規制がプロバイダの安全機能を具体的に動かす構図が続いている。
