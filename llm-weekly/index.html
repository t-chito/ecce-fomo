Opus 5.5 の高速版が正式提供、最大 2.5 倍速に

Anthropic は Opus 5.5 fast mode の研究プレビューと順番待ちを終え、正式提供にした。中身は同じ Opus 5.5 のまま最大 2.5 倍速で、価格は 100 万トークンあたり入力 $8・出力 $40 である。

Microsoft Foundry（Azure 上）でも使え、Google Cloud でも近く対応する。速度を選べる層を増やし、基盤を越えてモデルを配る動きが続く。

エージェントと開発基盤

Claude が自社コードの 9 割を書き、レビューを再設計

Anthropic は、Claude Code のコードの約 9 割を Claude が書いていると開示した。6〜9 月でマージされた PR は 2 倍以上に増え、取り消し（revert）の割合は 4 割以上下がったという。増える変更に品質を合わせるため、コードレビューの回し方を作り替えた。

あわせて Claude Code の Code Review を一般提供にした。Team・Enterprise 向けで、レビューは約 3 倍速くなり、リポジトリごとに Quick・Standard・Deep を選べる。AI が書いた大量のコードを、AI のレビューで支える形が整ってきた。

出典（3）
  • Claude Developers (X) — Claude writes about 90% of Claude Code's code; merged PRs more than doubled while reverts fell 40%+
  • Claude Developers (X) — Code Review is now generally available for Team and Enterprise plans
  • Claude Developers (X) — At GA: ~3x faster reviews, more of the bugs that matter, Quick/Standard/Deep per repo

Devin がコーディング指標で首位、運用監視にも展開

Cognition の Devin Fusion が、Artificial Analysis のコーディングエージェント指標でスコア 68 の首位に立った。Opus 5.5 を主、GPT-6 Luna を従に組み合わせ、Claude Code（Opus 5.5）を 1 タスクあたり 31% 安いコストで上回ったという。

同社は障害対応を自動化する Devin Oncall も出した。アラートを自ら調べて原因究明と修正を助け、大手で毎日数千件を処理しているとする。エージェントがコード生成から運用まで広がっている。

出典（2）
  • Cognition (X) — Devin Fusion scores 68 on the Artificial Analysis Coding Agent Index, beating Claude Code with Opus 5.5 at 31% lower cost
  • Cognition (X) — Introducing Devin Oncall, automatically investigating alerts and bugs for production incidents

科学応用

Claude がサソリ毒に対するタンパク質を設計

Anthropic は、Claude がサソリ毒を無力化するタンパク質バインダーを設計したと伝えた。毒が細胞に取り付く部分を狙い、64 時間で 30 万超の設計を生成し、211 個を実験に回したところ 17 個が条件を満たしたという。

同社は量子回路の設計でも、平易な指示から既存の最良を桁違いに上回る回路を作らせた例を示した。まだ探索段階だとしつつ、モデルを科学研究の道具として使う動きが具体化している。

出典（4）
  • Anthropic (X) — Designing protein binders against scorpion neurotoxins with Claude
  • Anthropic (X) — Over 64 hours Claude generated 300,000+ designs; 211 were sent for lab testing
  • Anthropic (X) — 17 of the 211 met the criteria for a binder
  • Anthropic (X) — STEM Fellows: Claude designed quantum circuits that improve on the best published ones by an order of magnitude or more
