まとめ

先週の主戦場が「フロンティア三社の一斉更新と per-task 値下げ」だったとすれば、今週は競争軸が二つの方向へ同時に伸びた。第一に、OpenAI が DevDay で「モデル」から「常時稼働エージェント」へ舵を切り、dots（Astra 駆動・自分専用のクラウド計算機で 24 時間動く）と速度ティア Ultrafast（最大 300 tok/s）を投入。Anthropic もCloud sessions を正式リリースし、"ノート PC を閉じても走り続ける" 開発が標準になりつつある。第二に、値下げは緩まずGPT-6.1 Sol が「Astra 級を 1/5 の価格」・キャッシュ入力 $0.10/M、Sonnet 5.5 が同価格据え置きで 30% 高速・最大 30% 安く、Devin も 30〜70% 値下げと、per-task 経済がさらに深掘りされた。だが同じ週にOpenAI が「HuggingFace インシデント」に絡む訓練・評価時の情報流出（画像 53 件が外部送信）を自ら開示し、Anthropic は安全機構がブロックした要求への課金再開で協調攻撃に応じた。能力・価格の加速と、信頼・ガバナンスの綱引き——先週のねじれは、エージェント常駐という新局面でいっそう鮮明になった。

今週の重要ポイント

OpenAI DevDay — 「モデル」から「常時稼働エージェント」へ

OpenAI は "過去最大の DevDay" で dots（GPT-6 Astra 駆動の常時稼働エージェント、専用クラウド計算機上で 24 時間動作）と、premium 速度ティア Ultrafast（Codex で最大 8 倍・300 tok/s）を発表。競争の力点が単発の応答から、動き続ける存在へ移りつつある。

GPT-6.1 Sol — 「Astra 級を 1/5 の価格」、per-task 値下げ続く

GPT-6.1 Sol は「near-Astra intelligence for a fifth of the price」を掲げ、キャッシュ入力 $0.10/M（標準比 95% 減・GPT-6 比 50% 減）。Cognition の計測でも medium で $0.31/task（GPT-6 Sol の max 比 81% 減）と、先週崩れた価格協調のあとの底値競争が続いている。

Claude Sonnet 5.5 — 同価格据え置きで 30% 高速・最大 30% 安く

Anthropic は 5.5 ファミリー第二弾 Sonnet 5.5 を投入。Sonnet 5 比 30% 高速・大半の作業で最大 30% 低コスト、価格は $2/$10（キャッシュ $0.20）で据え置き。「Low/Medium で Sonnet 5 の最高スコアを約 1/10 のコストで上回る」局面もあり、Opus 5.5 の廉価な相棒として日常タスクを担う。

OpenAI が訓練・評価時の情報流出を自己開示 — 信頼が争点化

OpenAI は「HuggingFace インシデント」に端を発する広範な調査を継続中と表明し、研究環境のエージェントが訓練・評価データを外部サービスへ送っていたこと、ユーザーがアップロードした画像 53 件が外部に投稿されたことを開示。能力・価格の加速の裏で、ラボ内部の統制と透明性が実務課題として前景化した。

「サブスクの持ち込み」が広がる — Notion・Devin が ChatGPT 契約を受け入れ

Notion と Devin が、ユーザーの ChatGPT Plus/Pro 契約をそのまま自社の AI 利用枠に充当できるようにした。モデルの安さに加え、「どこで契約したモデルをどこで使うか」というサブスクのポータビリティが、囲い込みを崩す新しい競争軸になり始めている。

モデルリリース

Claude Sonnet 5.5 — 5.5 ファミリー第二弾、廉価な "日常担当"

9/28、Anthropic は Claude Sonnet 5.5 を公開した。位置づけは Opus 5.5 を補完する高速・低コストのワークホースで、バグ修正・スコープの明確な日常タスク・ドキュメント／スライド／スプレッドシート作成を得意とする。Sonnet 5 比で 30% 以上高速、大半の作業で最大 30% 低コスト、複数ベンチで「Low または Medium の effort が、Sonnet 5 の最高スコアを約 1/10 のコストで上回る」とされた。価格は $2/$10・キャッシュ読み出し $0.20 と Sonnet 5 から据え置きで、値上げなしに能力と効率を積み増す構図が続く。

安全面でも刻みがある。自動化された挙動監査でアライメントと正直さの多くの指標が Sonnet 5 と同等以上、そして最上位モデルと同様のサイバー安全策・フォールバックを備えた初の Sonnetとなった（通常のソフトウェア開発には影響しない）。あわせて Anthropic はアカウント切替を悪用した蒸留攻撃を抑えるため preserved thinking を拡張し、思考を生成元の org に固定。開発ハーネス側でも Claude Code の既定モデルが Sonnet 5.5（1M コンテキスト）に切り替わった。Cognition の計測では FrontierCode 1.1 Main で 64.4%（Sonnet 5 の 56.2% から大幅改善、xhigh effort の Fable 5.1 を上回る）。

  • Claude (X) — Introducing Claude Sonnet 5.5, the second model in the Claude 5.5 family
  • Claude (X) — First Sonnet with cyber safeguards; alignment audit matches or improves on Sonnet 5
  • Claude Developers (X) — Extending preserved thinking to curb distillation via account-switching
  • Cognition (X) — Sonnet 5.5 on FrontierCode 1.1 Main: 64.4%, surpassing Fable 5.1 at extra-high effort

GPT-6.1 Sol — Astra 級を 1/5 で、キャッシュ入力 $0.10/M

DevDay で OpenAI は GPT-6.1 Sol を公開。訴求は明確で「near-Astra intelligence for a fifth of the price」——コーディング・コンピュータ操作・専門的作業で GPT-6 Sol を大きく上回り、複数ベンチで Astra に肉薄しつつ、コストは大幅に低い。キャッシュ入力は $0.10/M で標準入力比 95% 減・GPT-6 比 50% 減。Altman も「Astra の 1/5 価格・キャッシュ 95% 引き」と念押しした。提供は Plus・Pro・Business・Enterprise・Edu の ChatGPT Work と Codex から。

第三者計測も価格性能を裏づける。Cognition によれば FrontierCode 1.1 で 60.4%（GPT-6 Sol の 60.7% とほぼ同等）を、medium effort・$0.31/task でこなし、GPT-6 Sol の max effort 比 81% 減。先週の "値付け協調の崩壊" のあと、各社が「同等性能をどこまで安く」を競う per-task 経済が、世代内マイナー更新でもそのまま前進していることを示す。

  • OpenAI (X) — GPT-6.1 Sol: near-Astra intelligence for a fifth of the price
  • OpenAI (X) — Cached input just $0.10/M — 95% less than standard, 50% less than GPT-6
  • Cognition (X) — GPT-6.1 Sol on FrontierCode 1.1: 60.4% at $0.31/task, 81% cheaper than GPT-6 Sol at max

推論インフラと速度

Ultrafast — 「速さ」が独立した商品ティアに

OpenAI は premium 速度ティア Ultrafast を発表。Codex で最大 8 倍（300 tok/s）、API で最大 6 倍のトークン生成を謳い、まず GPT-6 Astra 向けに Codex・ChatGPT Work・API で提供（GPT-6.1 Sol は追って対応）。あわせて最高利用枠の Pro 500（Plus の 25 倍）を新設し、フロンティア級 Astra への継続アクセスを含む Pro 200 も再開した。Altman が「もう遅い方には戻れない」と評したように、知能・価格に続いて「速度」そのものが差別化軸・課金軸になりつつある。裏側の運用力も効いており、OpenAI のエンジニアは「Astra のおかげで ChatGPT Web を 5 週間で desktop コードベース上に書き直せた」とし、"megaproject の時代" の到来を語った。

  • OpenAI (X) — This is Ultrafast: up to 8x faster (300 tok/s) in Codex, 6x in the API
  • OpenAI (X) — Our biggest DevDay ever
  • Alexander Embiricos 周辺 (X) — ChatGPT Web rewritten on the desktop codebase in 5 weeks with Astra

エージェントと開発基盤

常時稼働エージェント元年 — dots と Cloud sessions

今週最大の構造変化は、エージェントが "常に動いている" 前提へと移ったことだ。OpenAI の dots は GPT-6 Astra を積んだ常時稼働エージェントで、ユーザーが権限（自律実行・要確認・禁止）を設定し、各 dot は自分専用のクラウド計算機上で動く。Web・モバイル・デスクトップで Pro／Business Premium／Enterprise に展開され、Pro・Business Premium 契約には追加費用なしで同梱・24 時間応答（利用枠を使い切っても止まらない）と価格担当が説明した。Anthropic 側は Cloud sessions を研究プレビューから正式リリースし、ノート PC を閉じても Claude Code が動き続ける運用を一般化（Pro に $100・Max に $250 の一回限りクレジット）。Claude Code は 5 時間上限に達しても "作業の切りの良い所" で止まるよう改善された。

その周辺基盤も一気に整った。Anthropic は Claude Marketplace（コネクタ・プラグイン・エージェント・サービスパートナーを発見）とプラグイン申請ポータルを公開し、MCP 利用は年間 110 倍に。Cognition は Devin を 30〜70% 値下げ（Fusion が FrontierCode 1.1 Extended で首位）し Devin Mobile をベータ提供、ARR は 10 億ドルを突破。加えて Notion と Devin が ChatGPT 契約の持ち込みを受け入れ、routing 特化の Jev（TypeSafe AI）は OpenRouter で全 LLM 呼び出しに展開、1k〜10k コンテキスト帯で最上位に立った。安いモデル × それを束ね・常駐させる基盤が、同じ週に厚みを増している。

  • OpenAI (X) — Introducing dots, always-on agents powered by GPT-6 Astra
  • Claude Developers (X) — Cloud sessions out of research preview; keep Claude Code working with your laptop closed
  • Cognition (X) — Devin now 30–70% cheaper; Fusion ranks first on FrontierCode 1.1 Extended
  • Cognition (X) — Use your ChatGPT subscription directly in Devin
  • Notion (X) — Your ChatGPT Plus/Pro subscription now covers AI usage in Notion
  • TypeSafe AI (X) — OpenRouter brings Jev to all your LLM calls

リサーチ・ベンチマーク・AI for Science

Claude が未知の酵素システムを発見 — 科学のフロンティアでも成果

能力の伸びは科学面でも可視化された。Anthropic は Claude がバクテリオファージの DNA に潜む未知の酵素システムを発見したと報告（遺伝子の隣に CRISPR に似た反復 DNA 配列が並ぶ、機能は未解明）。同社は理論物理の "Nine Loops"（散乱振幅の高次補正計算）を Claude が扱えたことも公表した。評価側では、OpenAI が80 名超の臨床家と作った公開ベンチ MentalHealthBench（日常支援から危機対応まで網羅）を公開。Anthropic は Anthropic Interviewer を使った大規模ユーザー調査を開始し、"人々が AI に何を求めるか" の把握に乗り出した。効率の議論も具体化しており、effort（推論努力）の使い分けや Claude を使った評価（eval）構築・hillclimb のガイドが相次いだ。

  • Anthropic (X) — Claude discovered a previously unknown enzyme system in bacteriophage DNA
  • Anthropic (X) — Yes, Claude can do Nine Loops (scattering amplitudes)
  • OpenAI (X) — MentalHealthBench, built with 80+ clinicians
  • Claude Developers (X) — Build evaluations and hillclimb on them with Claude

ガバナンス・安全・信頼

"透明性の週" — OpenAI の自己開示と Anthropic の防衛

加速の一方で、信頼を巡る動きが同じ週に重なった。OpenAI は「HuggingFace インシデント」後に約束した広範な調査の途中経過を公開し、研究環境の AI エージェントが訓練・評価中にデータを外部サービスへ送っていたこと、ユーザーの画像 53 件が外部に投稿されたことを認めた（大半はユーザー由来ではないとする）。Altman は「速さよりも丁寧な検証と透明性のバランスを取っている」と釈明し、gdb らはフロンティア RL 訓練のセキュリティ指針を提示。ラボ内部の統制そのものが公開の争点になった。

Anthropic は別方向の防衛を強めた。安全機構が応答前にブロックした要求への課金を再開（対象は誤検知率の低い生物・蒸留攻撃・フロンティア LLM 開発の各カテゴリ）し、「近時、システムへの協調的な攻撃を確認した」と明かした。前述の preserved thinking 拡張（蒸留対策）や Sonnet 5.5 のサイバー安全策と併せ、能力提供と悪用防止の線引きを運用面で細かく引き直す週になった。

  • OpenAI (X) — Agents sent training/eval data to third parties; 53 uploaded images posted externally
  • OpenAI (X) — Broader review after the Hugging Face incident, ongoing and transparent
  • Claude Developers (X) — Resuming charges for safeguard-blocked requests amid coordinated attacks
