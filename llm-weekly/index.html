まとめ

先週は DeepSeek の開放重み価格ショックと Amodei「We Must Pace the Frontier」という二つの伏線が並んだ。今週はそれが48 時間で衝突した——Grok 4.7（9/21）、Claude Opus 5.5・GPT-6 Sol/Luna（9/22）とフロンティア三社が立て続けに更新し、どれも「per-task の安さ」を前面に掲げた。Opus 5.5 は Fable 5.1 級の性能を Opus 5 比 4 割安く、GPT-6 は 5.6 系比 5 割減、Grok 4.7 は据え置き価格で長時間タスク改善。同時に各社は先週の「減速」宣言を具体策に落とし込み、第三者評価者への深いアクセスや誤整合の開示枠組みを相次いで発表した。だが値付けの協調は2 日で崩れ、フロンティア級の安全性が $2/$10 のモデルに届いたいま、「高価格＝安全のため」という説明の説得力が問われ始めた。能力の軍拡から、価格とガバナンスの二正面へ——ねじれは今週さらに深まった。

今週の重要ポイント

フロンティア三社が 48 時間で一斉更新 — Grok 4.7・Opus 5.5・GPT-6 Sol/Luna

9/21 に xAI Grok 4.7、翌 9/22 に Anthropic Claude Opus 5.5 と OpenAI GPT-6 Sol/Luna が90 分差で登場。いずれも訴求は生の知能ではなく「タスクあたりのコスト」で、フロンティアの競争軸が能力から価格効率へ移ったことを一週間で可視化した。

値付けの協調が 2 日で崩壊 — per-task 経済へ

Musk が Amodei の減速案に同調してわずか 9 日後、Grok 4.7 が $10/$50 のフロンティア圏を 8 割下回り、Opus 5.5・GPT-6 が続いた。「Amodei のペース枠組みで保たれていた価格協調は 2 日足らずで崩れた」（Yahoo Finance）。Altman は「per-task 価格こそ見るべき指標」と重ねた。

「Pace the Frontier」が宣言から実装へ — 評価者アクセスと開示枠組み

各社は先週の減速論を具体策に落とした。Anthropic は Accenture と各 10 億ドル超で評価能力を構築し評価者を常駐化、OpenAI は訓練・評価・展開の全段で第三者に深いアクセスを約束、さらに誤整合の追跡・開示枠組みを公開した。Opus 5.5 はMETR と Frontier Design の事前評価を経て出荷された。

エージェント開発の基盤が前進 — Claude Projects・AGENTS.md・Devin

モデル競争の裏で「動かし方」も動いた。Claude Projects は 1 会話を並列クラウドスレッドに分割し PC を閉じても走り続け、Claude Code が AGENTS.md をサポート（標準化論争に一区切り）。Devin はターミナル常駐と ssh を追加、Notion Skills API は skill を各エージェントへ横断配布し始めた。

モデルリリース（フロンティア一斉更新）

Claude Opus 5.5 — Fable 5.1 級を 4 割安く、5.5 ファミリー始動

9/22、Anthropic は新しい 5.5 ファミリーの第一弾 Opus 5.5 を公開した。位置づけは明快で、大半のタスクで前フラッグシップ Fable 5.1 と同等の性能を、Opus 5 比で運用コスト約 4 割減・出力 30% 高速で提供する。API 価格は入力 $4/M・出力 $20/M（Opus 5 の $5/$25 から 2 割減）、キャッシュ読み出しは $0.20/M（6 割減）。ベンチは SWE-bench Pro 89.9%、Terminal-Bench 4.0 66.4% で自社表の首位を取り、Cognition の FrontierCode 1.1（Extended）でも 65.3% と Fable 5 を上回って首位——しかも「a fraction of the cost」で、と評された。

効きどころは「フラッグシップ級の性能が主力価格帯に降りてきた」点にある。VentureBeat は「主要なエージェント系ベンチで Fable 5.1 を上回りつつ API は約 6 割安い」と報じた。あわせて Anthropic は Pro・Max・Team の 5 時間枠を引き上げ、サブスク利用者にレート制限のリセット枠を配布。価格を据え置いたまま能力を積み増す従来型ではなく、同等性能を安く出すという、先週の DeepSeek ショックへの直接的な返答になっている。

  • Claude (X) — Introducing Claude Opus 5.5, the first model in our new Claude 5.5 family
  • VentureBeat — Anthropic releases Claude Opus 5.5, beating Fable 5.1 on key agentic benchmarks at 60% cheaper API price
  • LLM-Stats — Claude Opus 5.5 Benchmarks, Pricing & Context Window

GPT-6 Sol / Luna — Astra を速く安く、三層家族で価格全域を覆う

Opus 5.5 の 90 分後、OpenAI は GPT-6 Sol と Luna を投入した。GPT-6 Astra の強みを、速く手頃なモデルに移した位置づけで、キャッシュと推論の効率化も加わる。価格は Sol が入力 $2/M・出力 $10/M、Luna が $0.10/M・$0.50/M——5.6 系比で 5 割以上の恒久値下げ（プロモではないと OpenAI が明言）。据え置きの Astra（$10/$50）と合わせ、企業級推論から大量処理まで覆う三層家族が完成した。Cognition の計測では、Sol は 5.6 Sol と同点を per-task 61% 減で、Luna は 5.6 Luna 超を約 1/4 コスト・$0.10/task 未満でこなし「リーダーボード最安」。Altman は「per-task で比べれば市場に競合はいない」と価格軸を強調した。

  • OpenAI (X) — Please welcome GPT-6 Sol and GPT-6 Luna to the GPT-6 universe
  • Sam Altman (X) — per-task pricing is the metric that should matter
  • VentureBeat — OpenAI releases GPT-6 Sol and Luna models, slashing API costs 50% or more

Grok 4.7 — 据え置き価格で長時間タスク改善、ただし FrontierCode では 4.6 に一歩譲る

9/21、xAI は Grok 4.7 を公開。2.1 兆パラメータの新ベース（4.6 比 4 割拡張）に長い RL 実行と数時間級の難タスク重視の学習を重ね、「難問により長く取り組み、検算を丁寧にする」ことを謳う。価格は 入力 $2/M・出力 $6/M と 4.6 据え置きで、自社表では CursorBench 4.0（46.3 対 40.4）・DeepSWE v1.1（71.0 対 65.2）・Terminal-Bench 4.0（38.0 対 20.3）と全項目で 4.6 を上回った。ただしコーディングや長タスクの一部で Fable 5.1 Max が依然先行し、Cognition の FrontierCode 1.1 では総合で 4.6 をわずかに下回る（難問には強いが一部で over-scope）と評価が割れた。前週の Grok Voice Transcribe 2.0（世界最高精度を主張）と合わせ、xAI は能力と周辺機能を刻みつつ価格は動かさない戦略を採る。

  • Grok / xAI (X) — Grok 4.7 is here. A notable improvement over Grok 4.6 at the same price and speed
  • LLM-Stats — Grok 4.7 Release: Same Price, Longer Horizons
  • Digital Applied — Grok 4.7 Costs the Same as 4.6. What Actually Changed

価格と per-task 経済（協調の崩壊）

「安全のための高価格」論が揺らぐ — フロンティア級の安全性が $2/$10 に到達

今週の 3 連発は、値付けを据え置きの料金表から動く標的へと決定的に変えた。時系列は象徴的だ——9/12 に Musk が Amodei の減速案に同調し、その 9 日後の 9/21 に Grok 4.7 が $10/$50 圏を 8 割下回り、翌 9/22 に Opus 5.5、その 90 分後に GPT-6 が続いた。Yahoo Finance は「Amodei のペース枠組みで保たれていた価格協調は 2 日足らずで崩壊した」と総括する。しかも Sol はGrok 4.7 と同じ入力 $2 に並び、90 分前に出た Opus 5.5（$4/$20）を下回る。値下げは横並びのドミノになった。

ここにガバナンスとの緊張が生じる。GPT-6 系では欺瞞率が 10.4% から 1.3% へ低下するなど安全指標は実際に改善したが、記事は鋭く問う——フロンティア級の挙動安全性が $2/$10 のモデルで得られるなら、$10/$50 という価格を「安全のため」と正当化する論拠は弱まる。すると残るのはマージン防衛ではないか、と。減速と値下げが同じ週に同居した結果、「ブレーキ」と「価格戦争」のどちらが各社の本音かが、四半期の実務的な争点として前景化した。

  • Yahoo Finance — OpenAI's GPT-6 Sol and Luna Cut Prices 50% — and the Three-Tier Family Just Ended the Coordinated Slowdown
  • Sam Altman (X) — per-task pricing, the metric that should matter
  • The Cryptonomist — OpenAI GPT-6 Pricing Slashes Costs with New Sol and Luna Models

ガバナンスと第三者評価（Pace the Frontier の実装）

評価者への深いアクセスが具体化 — Anthropic×Accenture、OpenAI の全段開放

先週の「減速」宣言は、今週第三者評価の制度化へ進んだ。Anthropic は評価者を常駐させる約束の一環として Accenture と提携し、両社が今後 5 年で各 10 億ドル以上を評価能力の構築に投じると表明。OpenAI も「pace the frontier の一環」として、訓練・評価・展開の全段で第三者に深いアクセスを与え、自社の前提に第三者が挑めるようにすると述べた。実装の証左として、Opus 5.5 は出荷前に METR と Frontier Design が評価し、Anthropic は「最も包括的なアライメント試験で自社最高スコア」と報告している。宣言の応酬だった減速論が、評価者の中への埋め込みという運用の話に移った週だった。

  • Anthropic (X) — Partnering with Accenture on independent evaluation; ≥$1B each over five years
  • OpenAI (X) — Supporting independent assessments with deep access across training, evaluation, and deployment
  • Claude (X) — Opus 5.5 tested by external evaluators including METR and Frontier Design

開示・測定・標準 — 誤整合フレームワーク、AI 進捗の指標、権力集中への警戒

評価と並んで「見える化」の動きも重なった。OpenAI はモデルの誤整合を追跡・調査・開示する枠組みを公開し、まだ十分に説明・緩和できていない挙動も含めて公開する基準と期限を定めた。同社は数学者の独立アドバイザリ群とも組み、成果の評価・発信の作法を整える。Anthropic は「AI R&D のうち AI が担う割合」など3 つの測定で、自己改善が進む現状を公衆に可視化し始めた。Altman は「ラボの外の人々が、この技術の進み方に発言権と、安全か否かを判断する明確な手段を持つべきだ」とし、権力集中を防ぐ標準の必要を説いた。減速の議論は誰が・何を・どう開示し測るかという制度設計へと具体化している。

  • OpenAI (X) — New framework for tracking, investigating, and disclosing model misalignment
  • Anthropic (X) — Three measurements to track AI development, including how much AI R&D is done by AI
  • Sam Altman (X) — People outside the AI labs should have a real say; standards to prevent concentration of power

エージェントと開発基盤

「1 会話＝並列クラウドスレッド」へ — Projects、AGENTS.md、Devin、Skills 配布

モデル更新の裏で、エージェントの動かし方が実運用寄りに整った。Anthropic は Claude Projects を投入——1 つのプロジェクト＝1 会話で、Claude が自らタスクを並列スレッドに分割し、クラウドセッションとして PC を閉じても走り続け、共有メモリで文脈を渡す。まず Claude Code（デスクトップ／ウェブ）から Pro・Max 向けにベータ提供。あわせて Cowork とチャットが一つの Claude に統合され、Claude Docs／Slides／Design が会話内や Claude Code から使える。

ハーネス側では、Claude Code 2.1.277 が AGENTS.md をサポート——CLAUDE.md が無ければ AGENTS.md を読む挙動を /config で選べ、「Claude Code mods」という新しいカスタマイズ機構の上に built-in mod として実装された。長く続いたプロジェクト指示ファイルの標準化論争に一区切りがついた形だ。周辺でも動きが続き、Cognition は Devin Cloud をターミナルに常駐させ devin ssh で専用マシンに直結、Notion Skills API はNotion で書いた skill を GitHub 経由で ChatGPT・Claude・Grok など各エージェントへ横断配布し、TypeSafe AI の Jev は待機列を撤廃して一般公開に至った。モデルの安さと、それを束ねる開発基盤が同時に厚くなっている。

  • Claude (X) — Projects now run from one conversation, starting in Claude Code
  • Thariq (X) — Adding AGENTS.md support to Claude Code (v2.1.277, via Claude Code mods)
  • Cognition (X) — Introducing Devin Cloud in Terminal and devin ssh
  • Notion (X) — Introducing the Notion Skills API

来週の注目ポイント

まず値下げドミノの次の一手——据え置きの Astra（$10/$50）や、Fable 5.1 系の価格・提供にフロンティア各社がどう応じるか。per-task を基準にした比較が定着すれば、料金表そのものの意味が変わる。ガバナンス面では、Anthropic×Accenture・OpenAI の「深いアクセス」が実際にどこまで開かれるか、他社が評価者の常駐や誤整合の開示枠組みに追随するか、そして先週から続く業界標準機関が具体像（参加者・権限）を得るか。開発基盤では、Claude Projects の一般提供と AGENTS.md 標準化の波及、Devin・Jev・Notion Skills を含む「安いモデル×束ねる基盤」の実運用が焦点になる。「減速」と「価格戦争」という相反する二つの流れが、来週どちらへ振れるかを見ていきたい。
