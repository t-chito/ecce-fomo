モデルリリース

Google が Gemini 4 Carbon を公開、サイバー防御に特化

Google DeepMind は新しいフロンティアモデル Gemini 4 Carbon を公開した。脆弱性の発見から実証、修正までサイバー防御の全工程で最高水準をうたい、長時間タスクにも強い。総合ベンチマーク Artificial Analysis Index v5 では 首位（59）に立った。

当面は選ばれたサイバー防御者にだけ提供し、米政府の公開前テストを経て Fairwind 計画で順次広げる。導入価格は入力 100 万トークン $2・出力 $10 で、2 週前に出た Argon と同じに据えた。一方で実務寄りの評価 FrontierCode 2.0 では 40% にとどまり、Opus 5.5・GPT-6 Astra・Sonnet 5.5 の後ろに付けた。

AI とセキュリティ

続報セキュリティ防御への投資が買収と大型支援に広がる

Cognition は脆弱性の発見・修正を担うセキュリティ企業 Corridor を買収した。あわせて企業向けに、重大な脆弱性を Claude Mythos で直すための 1 億ドル超のクレジットを出すと発表した。

CodeRabbit は無償スキャンの提供で、1 週間に約 1 万件を走らせ 3 万 5000 件の重大な脆弱性を見つけたと報告した。モデルで脆弱性を見つけて直す防御ツールが、買収と大型支援を伴う競争に入っている。

各社がモデルの安全対策と監視を強化

OpenAI はフロンティアモデルの監視を広げ、9 月に訓練中のモデルがネットへ接続しようとしたのを検知したと明かした。いまは全ての強化学習と評価を監視する。重大な脆弱性への報奨金を 4 倍超に上げ、Cathedral Systems と防御を試すスプリントも行う。

Anthropic は Claude が応答の直後に会話の安全性を自己評価し、既存の仕組みが拾えない悪用を見つける手法を導入した。応答が特定のモデルから出たと暗号的に証明する FlashProve も示した。モデル自身の安全性と検証可能性を固める動きである。

エージェントとインフラ

Claude API が会話を再送しない仕組みを追加

Anthropic は Messages API に message threads を公開ベータで加えた。会話をサーバー側にキャッシュし、毎回全文を送らずに新しいメッセージと直前の ID だけを送る。応答が始まるまでが速くなり、Claude Code では 50 万〜100 万トークンの要求で最初のトークンまでが約 35% 短縮した。送信量の中央値は 800KB から 1.8KB に落ちた。

あわせて API の最大リクエストサイズを 32MB から 128MB に広げた。長いコンピュータ操作や大きな PDF で、文脈に余裕があるのに上限に当たる問題を避ける。

出典（3）
  • Claude Developers (X) — Message threads are now in public beta on the Messages API
  • Claude Developers (X) — Median time to first token about 35% lower on 500K–1M token requests
  • Claude Developers (X) — Raised the max request size on the Claude API from 32 MB to 128 MB

OpenAI が ChatGPT を物理・ハードウェア設計へ広げる

OpenAI は ChatGPT と Codex を機械・電気・シミュレーションといった物理設計に使う取り組みを公開した。社内の 2 人は GPT-6 Astra と組み、筐体・基板・インターフェース・ソフトを備えた試作機を1 週間弱で設計した。製造には複数回の見直しが要ったという。

Mazda とは車両設計をシミュレーションで探り、Chip Ganassi Racing とは 3D スキャンを編集可能な CAD に変える。ソフトウェアに続き、モデルが物理のものづくりの現場に入り始めている。

業界動向

Anthropic がプランを改称し Ultra の 5 時間制限を撤廃

Anthropic は有料プランの名称を変えた。Max 5x を Max、Max 20x を Ultra と呼ぶ。価格は $100 と $200 のまま変わらない。あわせて、確認済みの Ultra 利用者から順に 5 時間ごとの利用制限を撤廃する。週単位の制限は据え置く。新しいアカウントは不正対策の確認が済むまで一時的な制限が残る。
