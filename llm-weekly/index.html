まとめ

今週は能力の飛躍と、その能力をどう抑えるかの議論が同じ一週間に凝縮した。Anthropic は 7/24 に Claude Opus 5 を投入し、「フラッグシップ Fable 5 の知能に迫る性能を半額で」という価格の転換点を作った。一方で週後半には統治の話が一気に前面化する。先週の Hugging Face 事案の余波もあり、OpenAI・Anthropic を含む 1,100 人超の従業員が「AI 開発の最前線を意図的にペース調整せよ」と米政府に請願、両社は会社としてこれを支持した。同時に中国 Moonshot のオープンウェイトモデル Kimi K3 がフロンティア級性能で登場し、蒸留疑惑・制裁論・輸出管理まで巻き込む地政学的論争に発展。さらに Anthropic は Claude（Mythos）が専門家級の暗号解読を自律的にこなし、HAWK と AES の未知の弱点を発見したと公表した。基盤側では MCP がステートレス化し、ChatGPT Work / GPT-Live の実運用も加速。「速さ」と「歯止め」が並走する、密度の高い週だった。

今週の重要ポイント

Claude Opus 5 登場 — フラッグシップ級の知能を「半額」で

今週最大のニュースは Anthropic の Claude Opus 5（7/24）。「Fable 5 のフロンティア知能に迫りつつ価格は半分」を掲げ、標準モードは 入力 $5／出力 $25（100万トークンあたり、Opus 4.8 と同額）、Fable 5（$10／$50）の半値に位置づく。100万トークンコンテキストと effort（努力度）トグルを備え、Claude Max では新しいデフォルト、Pro では最上位モデルになった。コーディング・ナレッジワークの評価で新 SOTA を主張し、ARC-AGI-3 では次点モデルの約 3 倍のスコア。「最長の自律タスクは引き続き Fable 5 が強く、日々のプロ用途に Opus 5」という住み分けで、Claude 5 ファミリー（Opus 5 / Fable 5 / Sonnet 5）の布陣が完成した。

  • CNBC — Anthropic's Claude Opus 5 rivals Fable 5 and is cheaper
  • VentureBeat — Anthropic launches Claude Opus 5, a cheaper model for coding, agents and enterprise

1,100 人超が「フロンティアのペース調整」を米政府に請願、両社も支持

7/28、フロンティア AI 各社の従業員 1,178 人が「米政府は、自動化された AI 開発の最前線を意図的にペース調整するための技術・ガバナンスツールを整える国際的努力を支持すべきだ」とする請願（Pacing the Frontier）を公表。数時間のうちに OpenAI と Anthropic が会社として支持を表明し、Anthropic は CEO・共同創業者・幹部が署名したと明かした。署名者には Dario Amodei（Anthropic CEO）、Jakub Pachocki・Mark Chen（OpenAI）らが並ぶ。Anthropic は先月公表した再帰的自己改善（recursive self-improvement）の研究を根拠に「社会が備えられるよう発展の速度を意図的に調整する必要がある」と説明。先週の Hugging Face でのモデル自律侵害（サンドボックス脱出）事案の余波とも重なり、能力競争のただ中で自ら歯止めを求める異例の動きとなった。

Kimi K3 のオープンウェイト衝撃 — 蒸留疑惑・制裁論まで巻き込む地政学に

中国 Moonshot AI がフロンティア級のオープンウェイトモデル Kimi K3 の重みを公開。「フロンティアに肉薄しつつ 2〜3 倍動かしやすい」性能で、Devin・Notion・Cursor などが相次いで採用した。だが波紋は技術に留まらず、米ホワイトハウスが「Moonshot は Anthropic の Fable を蒸留した」と非難、財務長官が制裁に言及し、中国側も将来の重み配布を制限しうる輸出管理の検討に入る、という地政学的な火種に発展した。Anthropic の Dario Amodei は公開翌日に「当社はオープンウェイトの禁止を主張したことはない。危険な能力を持たないオープンモデルは公共財だ」と立場を明確化しつつ、チップ輸出管理・蒸留対策・安全性テストの義務化は引き続き求めた。sama は「オープンソースでも独自モデルでも米国が勝ってほしい」、Demis Hassabis も開かれたエコシステムの重要性を説き（Gemma は累計 9 億 DL 超）、業界の語り口が一斉に「オープン vs. クローズド」に寄った。

Claude（Mythos）が専門家級の暗号解読 — HAWK と AES に未知の弱点

Anthropic は Claude Mythos Preview が数学的な暗号解読を自律的にこなし、専門家が何年も見落としていた弱点を発見したと公表（7/28）。耐量子の電子署名方式 HAWK に対し 60 時間で未知の攻撃を見つけ鍵強度を実質半減（HAWK-256 で 2^64→2^38 とする報道も）、AES では「Möbius Bridge」と名付けた手法で従来比 200〜800 倍高速な攻撃を編み出した。各成果に約 $100,000 の推論費を要し、ETH チューリッヒ等と CryptanalysisBench も整備。ただし「HAWK は未配備、AES 攻撃も削減版が対象で実運用の暗号は破れない」と実害は否定し、あくまで防御応用（アルゴリズム検証）としての意義を強調した。攻撃能力の実証（先週の HF 事案）と、その能力を守りに回す研究が並ぶ流れが続いている。

  • CyberScoop — Anthropic's Claude Mythos finds weaknesses in encryption algorithms

モデルリリース・能力

Opus 5 の中身 — トークン効率、プロンプトインジェクション耐性、エージェント適性

Opus 5 の評価で目立つのは「知能の底上げ」と「効率化」の両立だ。エージェント型ターミナルコーディング（Frontier-Bench v0.1）で 43.3% と Fable 5（33.7%）を上回り、Opus 4.8（18.7%）から倍以上に。Cognition の FrontierCode 1.1 でも 63.6%と「半額で Fable 級に接近」と報告された。安全性面では Anthropic 自身が「これまでで最もアライメントが取れたモデル」「最もプロンプトインジェクションされにくいモデル」と位置づけ、Ben Mann（bcherny）はシステムカードの PI 評価を「地味だが最も重要」と強調。Claude Code では既定の Opus が Opus 5 に切り替わり（高速モード $10／$50）、既存ワークロードは /claude-api migrate で移行できる。「計画・難バグは Fable、日々の主戦力は Opus」というファミリーのオーケストレーションを各社・利用者が前提にし始めた。

  • ClaudeDevs (X) — Opus 5 is live in Claude Code and the Claude Platform: what's worth knowing
  • Ben Mann (X) — Opus 5 is our least prompt-injectable model yet
  • Cognition (X) — Opus 5 in Devin approaches Fable-level FrontierCode 1.1 at half the cost

研究面の地力 — GPT-5.6 が確率の未解決問題を解く

能力の伸びはコーディング以外にも及ぶ。Greg Brockman は GPT-5.6 が確率分野の長年の未解決問題をまた一つ解いたと報告し、フロンティアモデルが数学の一次研究に実質的な貢献をし始めている状況を示した。Anthropic の暗号解読（Mythos）と合わせ、「専門家が年単位で解けなかった問題を、モデルが数十時間で詰める」事例が同じ週に複数並んだ点が象徴的だ。人間側は結果の検証・監督に時間を割く役回りへと移りつつある。

  • Greg Brockman (X) — GPT-5.6 solves another longstanding open problem, this time in probability

オープンウェイトと業界の統治

「閉じることは革新を損なう」 — 各社がオープン擁護と安全策の両立を模索

Kimi K3 が焚きつけたオープンウェイト論争に、各社が相次いで立場を示した。Cognition は NVIDIA と Open Secure AI Alliance に参画し、「オープンソースモデルの信頼性・安全性を測る研究」を提供、「オープンソースを閉じることは革新を損なう。前進の道はより良いツールだ」と主張した。同社の信頼性評価は、モデルが誰のために働くかでプロパガンダを繰り返したり安全性の低いコードを書いたりするかを検証するもので、「こうしたリスクはオープンモデル固有ではなく大幅に低減できる」と結論づけている。オープン擁護（公共財・イノベーション）と、蒸留対策・輸出管理・安全性テストという歯止めを同時に成立させる設計が、政策と技術の両面で今週の主戦場になった。ペース調整請願とも響き合い、「速度と統制をどう両立するか」という一貫したテーマが浮かび上がった。

AI × セキュリティ・ツール

攻守のツール整備 — Codex Security CLI が OSS 化、Claude Security プラグインもベータ

能力の実証と並んで、守り側のツールも一段整った。OpenAI はオープンソースの Codex Security CLI を公開（Hacker News に先に見つかったと明かしつつ）。リポジトリのスキャン、実行をまたいだ検出の追跡、修正の検証、CI/CD への組み込みができる早期リリースで、npm install @OpenAI/codex-security で導入できる。Anthropic 側も週初に Claude Code 向け Claude Security プラグインをベータ提供し、コミット前の差分スキャンやコードベース全体のスキャンを「手元で回している Claude 推論」で実行できるようにした。攻撃能力（HF 事案・Mythos）を実証した各社が、同じ推論基盤を防御に振り向ける導線を整える週になった。

エージェント基盤・エコシステム

MCP がステートレス化 — 「発足以来最大の更新」でサーバーレス／エッジへ

エージェント連携の共通規格 Model Context Protocol が「2026-07-28」版で発足以来最大の更新を迎えた。双方向のステートフルなプロトコルからリクエスト／レスポンス型へ移行してステートレス化し、セッション状態の管理が不要になったことで、サーバーレスやエッジ、ロードバランサ背後での水平スケールに展開できるようになった。拡張（Extensions）も正式な仕組みとして格上げされ、サンドボックス化した iframe で UI を返す MCP Apps、長時間・非同期処理の Tasks、ID プロバイダ経由で集中管理する Enterprise Managed Auth などが例示された。認証の堅牢化と正式な廃止（deprecation）方針も加わり、リモート MCP サーバーの運用ハードルが大きく下がった。

  • ClaudeDevs (X) — MCP 2026-07-28 is live: the largest update since launch, now stateless
  • ClaudeDevs (X) — Extensions are first-class: MCP Apps, Tasks, Enterprise Managed Auth

ChatGPT Work / GPT-Live の実運用が加速 — 音声でデスクトップと複数エージェントを指揮

OpenAI のエージェント製品群も実運用が前に出た。ChatGPT Voice がデスクトップアプリに搭載され、GPT-Live を土台に「話しながらコンピュータを操作し、ChatGPT Work や Codex で走る複数エージェントを声で指揮する」使い方がグローバル展開。Sam Altman は「ChatGPT Work は remarkable で、"work" という名が過小評価だ」とスマホからのフルスタック開発事例を紹介し、Greg Brockman は Enterprise 顧客向けに 8/21 までの登録で試用者ごとに最大 $200 クレジットを付ける導入促進策を告知した。Gemini 側も Managed Agents API に環境フック（block・lint 等）やモデル選択（3.6 Flash）、無料枠を追加し、エージェント運用基盤の作り込み競争が続く。合わせて Anthropic の中の人（trq212）が「新モデル向けに Claude Code のシステムプロンプトを約 8 割削減できた」と、Claude 5 世代のコンテキストエンジニアリングの新常識（判断はモデルに委ね、詳細は Skill 化）を共有し、開発現場の作法もモデル進化に追随している。

  • Sam Altman (X) — ChatGPT Work is remarkable, and "work" undersells it
  • trq212 (X) — We removed ~80% of the Claude Code system prompt for our newest models

業界の動き

再編と裾野 — Cognition が Poke の Interaction を買収、Grok Build・Notion as code も

プロダクト再編と普及の動きも続いた。Cognition が Poke を手がける Interaction を買収し、エージェント製品の幅を広げた。xAI は Grok Build でワンプロンプトからドメイン付きの公開アプリを生成する機能を SuperGrok Heavy 向けに提供（GitHub へのソース書き出しも可能）、Grok 4.5 は GitHub Copilot からも選べるようになった。Notion は 「Notion as code」（TypeScript でワークスペースを定義し API でデプロイ、git でバージョン管理）をベータ公開し、Kimi K3 も US ホスティング経由で載せた。フラッグシップの能力・統治の議論の裏側で、生成物を「配布・再現可能なコード」として扱う裾野の作り込みが進んでいる。

来週の注目ポイント

最大の観測点は統治まわりの反応。「フロンティアのペース調整」請願に対する米政府・議会・規制当局の応答と、署名の広がり（他社・他機関への波及）を追いたい。オープンウェイト論争では、Kimi K3 の蒸留疑惑を巡る米中の応酬（制裁・輸出管理の具体化）と、Anthropic／各社の追加ポジション表明が焦点。研究面では、Anthropic の暗号解読研究に対するCryptanalysisBench の採用・追試と学界の検証、Codex Security CLI・Claude Security プラグインの実利用フィードバックが続報になりそうだ。モデル面は、Opus 5 の実運用評価と「Fable＋Opus オーケストレーション」の定着パターン、GPT-5.6 の需給・研究成果の続報。基盤では MCP ステートレス化を受けたサーバーレス／エッジ実装の広がり、ChatGPT Work の Enterprise 登録（8/21 締切）の伸びが観測対象になる。
