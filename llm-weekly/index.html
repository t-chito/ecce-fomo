OpenAI が GPT-6.1 Terra を公開、コンピュータ操作に軸足

OpenAI は GPT-6.1 Terra を公開した。画面を理解してアプリをまたいで操作するモデルで、標準 API 価格は前世代比 50% 安い。GPT-6 Astra 並みの性能をトークン単価 1/10 で出し、処理は 3 倍速いという。ChatGPT Work・Codex・API で使える。

Sam Altman は「コンピュータ操作の新時代」と位置づけ、Greg Brockman は自分が手で操作するより速いと感じる水準に達したと述べた。安価なコンピュータ操作モデルが、仕事の自動化の前提になりつつある。

Google が対話的な世界モデル Genie 4 を公開

Google DeepMind は世界モデル Genie 4 を公開した。リアルタイムの物理・推論・音声を備え、自然言語で天候やカメラ、登場する要素を動かせる対話的な環境を生成する。初めて API で提供する予定だという。

生成 AI がテキストや画像にとどまらず、操作できる環境そのものを作る方向に広がっている。Demis Hassabis は「シミュレーションの中のシミュレーション」と表現した。

AI とセキュリティ

続報AI が PHP と Brotli に重大な脆弱性を発見

OpenAI は取り組み「Patch the Planet」で、推定 7 割の web サイトが使う PHP の重大な欠陥（php2shell）を見つけ、メンテナや研究者の連合を組んで修正を調整した。広く使われる圧縮ライブラリ Brotli（Node.js・Bun・Envoy などが内包）の未認証リモートコード実行も発見した。

強いモデルによる脆弱性発見が、実際に使われている重大な OSS バグの修正につながっている。影響確認用の Codex スキルも配られた。

出典（3）
  • OpenAI (X) — OpenAI models helped discover critical security flaws in PHP, used by ~70% of websites
  • OpenAI (X) — An unauthenticated remote code execution in Brotli, included in Node.js, Bun, and Envoy
  • Greg Brockman (X) — Leading a coalition to mitigate php2shell, found via Patch the Planet

セキュリティ防御ツールの投入が各社で相次ぐ

Anthropic は Claude Security を Enterprise で公開ベータにした。リポジトリをつなぐと深くスキャンし、変更が入るたびに再スキャンして指摘を最新の状態に保つ。Cognition は Devin Security、CodeRabbit は Deep Scan（11 月 8 日まで無償、総額 100 万ドル分）を出した。いずれもフロンティアのサイバー向けモデルを土台にする。

OpenAI は訓練環境も固め、フロンティアモデルの訓練中はネット接続を外し、キャッシュした「オフラインの web」を使わせるようにした。攻撃と防御の両面で、AI を使ったセキュリティ競争が立ち上がっている。

エージェントと標準化

Anthropic が能動的エージェント Claude Duet を公開

Anthropic は、Claude が自分から動くアプリ Claude Duet の研究プレビューを始めた。土台は Opus 5.5 で、必要なことを持ってきて、離席中も作業を続け、代わりに動く前に確認する。米国の Pro・Max でウェイトリスト制である。

あわせて web・デスクトップ・モバイルの既定動作を、危険な操作だけ自動で止める auto モードに切り替える。対話に答える道具から、自分で動くエージェントへと軸が移りつつある。

出典（3）
  • Claude (X) — Opening a research preview of Claude Duet, where Claude works as a proactive agent
  • Claude (X) — Claude Duet is designed around Claude Opus 5.5
  • Claude (X) — Sessions will run in auto mode by default on Pro, Max, and Team plans

Anthropic が Agent Skills を標準化団体へ寄贈

Anthropic は、MCP に続いて Agent Skills を中立の Agentic AI Foundation に寄贈した。2025 年 12 月以降 70 を超えるエージェント基盤が採用し、ChatGPT・Cursor・GitHub Copilot・VS Code が含まれる。

運営する技術委員会には Anthropic・Google・Microsoft・OpenAI などが並ぶ。ライセンスは変わらず、参加しなくても利用や貢献ができる。競合も交えてエージェントの共通規格をまとめる動きである。

出典（2）
  • Claude Developers (X) — Donating Agent Skills to the Agentic AI Foundation; 70+ platforms have integrated it
  • Claude Developers (X) — A Technical Steering Committee of Anthropic, Google, Microsoft, OpenAI, and others

Claude API が初の版付け、MCP に長時間タスクを追加

Anthropic は、2023 年以来初めて Claude API に版（2026-10-21）を付けた。破壊的変更を新モデルの登場前に扱えるよう、今後は版を頻繁に出すという。SDK と CLI も新しい版を既定にした。

あわせて MCP に Tasks（深い調査などの長時間ジョブを任せ、終わったら報告させる）と Elicitations（作業の途中でユーザーに確認を求める）を加えた。エージェント連携の土台が整理されてきた。

出典（2）
  • Claude Developers (X) — API version 2026-10-21, our first official version release since 2023
  • Claude Developers (X) — Adding MCP Tasks and Elicitations in Claude
