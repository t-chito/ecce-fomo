Claude Code

Claude Code を TypeScript で改造できる Mods が登場

10/1、Claude Code Mods が 2.1.287 で入った。Claude Code の挙動・UI・機能をユーザー自身が書き換える仕組みで、数行の TypeScript で書けるほか、Claude に作らせることもできる。mod はプラグインとして配布され、CLI でもデスクトップでも /plugin で導入する。中の人の bcherny は「とんでもない」と評し、trq212 は「ソフトウェアは可変になりつつあり、Claude Code でも第一級の機能にした」と書いた。

組み込み mod「You should Know」も加わった。別のエージェントが応答を監視し、ユーザーや Claude が見落としそうな要点を知らせる。/plugin enable cc-plugin-you-should-know@builtin で有効になる。公式のサンプル mod 集に加え、HTML で実装プランを練る html-plan や過去プロンプトへ飛ぶ prompt-rail など、コミュニティ製の mod も早速出てきている。

Haiku 5.5 が既定の Haiku になり安いサブエージェント役に

10/7、Anthropic が Claude Haiku 5.5（claude-haiku-5-5）を公開し、2.1.293 で Claude Code の既定 Haiku になった。1M コンテキストに対応し、実行コストは Haiku 4.5 より平均 75% ほど安い。effort（思考の深さ）を調整でき、要約やコンパクションのような大量・低コストの処理を Opus 5.5 や Sonnet 5.5 のサブエージェントとして任せる使い方に向く。

価格は 100 万トークンあたりで次の通り。Devin も同日に採用し、コーディング指標 FrontierCode 1.1 で 58.4% と、Sonnet 5 を約 8 分の 1 のコストで上回ったとした。Max・Team 向けには Claude Platform の月次 API クレジットも始まった。

クラウドセッションに実務向けの手引きとツール整備

クラウドセッションは、タスクごとに新しい VM で Claude Code を動かす仕組みだ。複数を同時に走らせられ、ノート PC を閉じても処理は進み続ける。Anthropic は向いている 7 つのワークフローと、GitHub を一度でつなぐ手順をまとめた手引きを公開した。長時間・並行で回す使い方を前提にした整理だ。

実行環境の整備も進んでいる。以前は gh コマンドすら入っていなかったが、GitHub CLI などがあらかじめ使えるようになった。エージェントに実際のツールチェーンを渡し、人手の準備なしでタスクを委ねられる方向に寄せている。

週次リリースはエージェント連携とプラグイン導線を整備

この週は 2.1.287〜2.1.294 が出た。エージェント周りでは、teammates が共有エージェントを生成する agent.spawn が入り、Agent tool に effort を指定するフラグが付いてサブエージェントごとに思考の深さを変えられるようになった。プラグインは claude plugin install --marketplace <source> でマーケットプレイスの追加と導入を一手でこなせる。

開発者向けには、Python・TypeScript の SDK に Computer use と Browser use のツールセットが組み込まれ、クリックや入力のループを自前で書かずに済むようになった。地味な更新では、UNC ネットワークファイル読み取りで権限確認を迂回できた問題の修正や、ローカル MCP サーバーの既定プロトコルを 2026-07-28 に上げる変更が入った。

Devin がセッションをまたぐ記憶を持つ

Devin が夜間に自己改善する記憶グラフを導入

10/5、Cognition が Devin に Dreaming を導入した。セッションをまたいで「ユーザーがどう働くか」の記憶グラフを作り、夜間に古い記録を自分で整理し、埋もれた情報を見つけて自己改善する。初期の実験では、指示していないのに複数の Devin が記憶を介して大規模に連携する様子も見られたという。

仕組みはオープン仕様「Agent Memory Repo」として公開された。エージェントがセッションをまたいで知識を保持・更新するための標準で、skill として導入できる。エージェントの「記憶」を各ツール固有の機能から、共通基盤へ広げようとする動きだ。

  • @cognition: 複数 Devin が記憶を介して自発的に連携した初期実験
  • @oikon48: オープン仕様 Agent Memory Repo の紹介（skill で導入）

Devin がクラウド Mac で iOS 開発も任せられるように

Cognition は Devin の各セッションに専用のクラウド Mac を割り当てた。xcodebuild や iOS シミュレータ、画面を操作する Computer use が動くので、モバイル開発もほかのチケットと同じように委任できる。ベータ版の Devin モバイルアプリも出ており、リポジトリを明示しなくてもプロンプトから探し当てるという。
