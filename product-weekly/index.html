Claude Code

Sonnet 5.5 が Claude Code に追加、速く安い日常作業向けの選択肢に

9/28、Anthropic が Claude Sonnet 5.5（claude-sonnet-5-5）を公開した。Claude Code でもすぐ選べるようになり、2.1.284 で既定の Sonnet モデルになった。Sonnet 5 より 30% ほど速く、同じ作業にかかるコストも最大 30% 低い。位置づけは「よく定義された日常作業」向けで、バグ修正や機能の素早い反復に向く。重い設計判断は引き続き Opus 5.5、軽い反復は Sonnet 5.5 に振る使い分けが公式ガイドでも示された。

価格は Sonnet 5 と同じ入力 $2・出力 $10（キャッシュ読み出し $0.20）／100万トークンで、1M コンテキストに対応する。中の人の bcherny は Claude Code 上で Sonnet 5.5 がバグを直す様子を共有した。ベンチマークによっては Low/Medium の effort でも Sonnet 5 の最高スコアを 10 分の 1 ほどのコストで上回るとされ、Claude Code の使用量を伸ばしたい用途で現実的な選択肢になった。

  • @ClaudeDevs: Sonnet 5.5 を Claude Code で使う（日常作業向け・使用量が伸びる）
  • @bcherny: Sonnet 5.5 が Claude Code でバグを直すデモ
  • Claude Code Changelog（2.1.284：Sonnet 5.5 を既定 Sonnet に・1M・$2/$10・$0.20 キャッシュ）

5時間上限でも作業を途中で切らず区切りまで進めるように

9/25、Claude Code に 5 時間の利用上限に達しても作業を途中で打ち切らない挙動が入った。これまでは編集の途中でも止まったが、今後は区切りのいい場所を探してそこまで進める。このために週次上限から引く小さめの固定枠が割り当てられる。長いタスクを回しているときに、中途半端な状態で手が止まるのを防ぐための変更だ。

提供範囲は、Pro は週 1 回、Max と Team Premium は 5 時間セッションの上限に当たるたび。区切りの先へ進めたい場合は追加の使用量で続行できる。無人で長時間走らせる使い方が広がるなか、上限との当たり方をなめらかにする実運用寄りの調整といえる。

  • @ClaudeDevs: 提供範囲（Pro 週 1 回・Max/Team Premium は上限のたび）

続報effort は常に max が最適ではないと中の人が検証

effort（思考の深さ）の使い分けが引き続き話題だ。中の人の trq212 は「effort とは何か、なぜ常に max を使わないのか」を evals と自前の検証で掘り下げ、全部を max にするのが最適とは限らないという結果を公開した。深く考えさせるほど良いわけではなく、作業に合わせて段階を選ぶほうが速度とコストの両面で効く、という整理だ。

ツール側も追随した。2.1.286 で Ultracode が /effort の独立トグルになり、xhigh を強制しなくなった。どの effort レベルでも Ultracode を併用できる。「別モードで深さを決める」より「ダイヤルで深さを選ぶ」操作へ寄せる動きが、発信と実装の両方で進んでいる。

出典（2）
  • @trq212: What is effort really?（max 一択が最適でないという検証）
  • Claude Code Changelog（2.1.286：Ultracode を /effort の独立トグルに・xhigh 強制を廃止）

週次リリースはプラグイン導線と使用量表示の整備が中心

週を通して 2.1.282〜2.1.286 が出て、中身は使い勝手の地固めが中心だった。プラグイン周りでは提出・レビュー追跡・利用状況を見る導線が整い、claude plugin configure でオプションを設定できるようになった。/usage には使った金額のドル表示が加わり、Opus 5.5 のコストを試算する計算機も用意された。claude --desktop でデスクトップアプリを現在のディレクトリから開ける導線も入った。

OpenAI DevDay——Codex の高速化とセキュリティ強化

Codex に毎秒300トークンの超高速モードとリポジトリ常時監視

OpenAI は 9/29 の DevDay で開発者向けの発表を重ねた。目玉のひとつが Ultrafast で、Codex では最大 8 倍・毎秒 300 トークン、API でも最大 6 倍の生成速度を出す有料の速度ティアだ。sama が「速すぎてもう戻れない」と評すなど、エージェントの反復を体感速度から変える方向の投資といえる。

もうひとつが Codex Security Cloud の大型更新だ。サイバー向けモデル（Daybreak Blue）を既定で使い、GitHub リポジトリ全体を走査して新しいコミットを継続的にレビューし、検出を調査・重複排除したうえで修正案まで用意する。背景には常時稼働の個人エージェント dots（GPT-6 Astra）や低価格の GPT-6.1 Sol の発表があり、「安いモデルで大量に回し、本番前に機械で検証する」路線が一段進んだ。

ChatGPT 課金の持ち込みが広がる——Devin・Notion

自分の ChatGPT Plus/Pro を Devin と Notion の AI 利用に使える

自分が契約している ChatGPT の枠を他ツールで使える動きが同じ週に重なった。Devin は 9/29、ChatGPT Plus/Pro でログインすると、Devin 内の OpenAI モデル利用がその契約枠から引かれるようにした。Devin Cloud・Desktop・CLI で有効だ。別途のモデル課金を増やさずにエージェントを使える点が、個人ユーザーには効く。

Notion も同日、ChatGPT Plus/Pro の契約で Notion 内の AI 利用をまかなえるようにした。プランをつなぎ、使う GPT モデルを選ぶだけで済む。各社が「モデルの課金は利用者が持っているものを使う」方向に動くことで、ツールごとに AI 料金が積み上がる負担を下げ、乗り換えや併用のハードルを下げようとしている。

出典（2）
  • @cognition: ChatGPT の契約を Devin で直接使える（Cloud・Desktop・CLI）
  • @NotionHQ: ChatGPT Plus/Pro の契約で Notion の AI 利用をまかなえる
