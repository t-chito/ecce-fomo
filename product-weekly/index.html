Claude Code

Claude が JavaScript を書いてツールを呼ぶ Code Mode が入った

2.1.323 で Code Mode が実験的な opt-in として追加された。従来はツールを 1 つずつ呼んでいたところを、Claude が JavaScript を書いて自分のツールを呼ぶ。複数のツール呼び出しをコードでまとめられるので、繰り返しの多い作業で往復が減る。

2.1.326 で agent teams を有効にしたままでも Code Mode を使えるようになった。2.1.328 では、Code Mode はスクリプトの出力に対して UserPromptSubmit hook を走らせないよう変わった。

権限とサンドボックスのチェックが各所で締め直された

2.1.325 で、zstd 圧縮レスポンスのデコードにあった脆弱性が直された。あわせて、複合コマンドが確認なしに走る穴、allow ルールが名前と違うプログラムを実行できる問題、cd 後に Read(./.env) のような相対 deny ルールが効かなくなる問題を修正した。sandbox 内の Bash も既定で通常の権限フローに従う。

2.1.326 では多くの sandbox・Bash チェックがより頻繁に確認・拒否するようになり、追加ディレクトリの .claude 配下への書き込みは拒否される。2.1.325 からは scheduled task と /loop が、allowed-tools や hook を宣言した skill を走らせる前に確認を挟む（permissions.allow に Skill(name) を足すと無人で動く）。

auto モードが主要クラウドのゲートウェイに広がった

2.1.328 で、Opus 4.6 と Sonnet 4.6 が Amazon Bedrock・Google Cloud の Agent Platform・Microsoft Foundry・Claude apps gateway でも auto モードに対応した。権限モードを指定しない対話セッションは auto モードで始まる。

2.1.326 では、Claude Code + Cowork の HIPAA 構成を持つ組織の端末・VS Code セッションが既定で auto モード開始になった。disableAutoMode で止められる。

/code-review が bug の指摘に専念し /simplify と分かれた

2.1.328 で、多くのモデルで /code-review がバグと CLAUDE.md 違反だけを報告するようになった。再利用や効率化の整理は /simplify に回る。レビューの出力が目的別に分かれ、バグ探しとクリーンアップを別々に走らせられる。

同じ版で /bug は送信前に Yes / No を聞くようになり、permission プロンプトで Esc が取りこぼされる不具合も直った。

エージェントがエージェントを束ねる

Cognition が Devin を束ねる管理エージェント Devin Bots を出した

11/17、Cognition が Devin Bots を発表した。個々の Devin の上に立つ常駐の管理エージェントで、大きなプロジェクトをタスクに割り、複数の Devin セッションを立ち上げ、進捗を追い、人の承認が要る判断だけ上げてくる。各 Bot はプロジェクトをまたいで記憶を持ち、数日から数週間にわたって動く。

Bot は計画・設計・computer use など場面ごとに適したモデルを選び、単純なコードには速く安いモデルを使う。Slack やテキスト、電話、CI・Linear を見るスケジュール起動で外から呼べる。Cognition はこれを Anthropic の Duet や OpenAI の Dots への対抗と位置づける。ツールが「タスクをこなす」段から「プロジェクトの成果を預かる」段へ動いている。

エージェントをテストする仕組み

GitHub Copilot に skill や MCP を検証する Evals が入った

11/17、GitHub が Copilot Evals を public preview で出した。自分の Copilot に入れた skill・カスタムエージェント・MCP ツールが、プロンプトやモデルの変化の後でも期待どおり動くかを、繰り返せるテストとして確かめられる。

/eval か自然言語でテストを作り、実行（開始前に毎回承認する）、合否とその理由を見て、変更の前後で結果を比べる。AI の出力は実行ごとにぶれるので、1 回うまくいっただけではカスタマイズの良し悪しは分からない、という前提に立つ。VS Code・Copilot CLI・Copilot アプリで使え、Individual・Business・Enterprise が対象。

Google が Jules を畳む

Google の自律コーディングエージェント Jules が年末で終わる

Google が Jules の終了を進めている。11/11 に read-only になり、過去のセッションは見られるが新しいコーディングは走らせられない。12/31 に完全終了する。残したいセッション履歴・設定・リポジトリ接続は、閉じる前に書き出しておく必要がある。

Google はこれを agentic coding の取り組みを一本化する動きと説明し、エージェント優先の基盤として Antigravity を挙げる。1 年ほど前に注目された自律コーディングエージェントが、別プロダクトへ畳まれる形になった。
