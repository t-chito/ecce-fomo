Claude Code

Fable 5.2 が既定の Fable モデルになった

2.1.321 で Claude Fable 5.2（claude-fable-5-2）が既定の Fable モデルになった。context は 1M トークン、価格は $8 / $40 per Mtok、cache read は $0.20/Mtok。保存済みの Fable 5.1 指定は Pro・Max で自動的に新しい既定へ寄せられる。Team・Enterprise は組織が許可してから移る。戻すなら /model claude-fable-5-1 を使う。

あわせて 2.1.322 で、Vertex 上でも fast モードが使えるようになった（global・us・eu リージョン）。Vertex が受けない場合は標準速度へ下がる。

MCP のツール呼び出しを背後で動かせるようになった

2.1.319 で、MCP サーバーがツール呼び出しを「タスク」として走らせたとき、Claude Code がそれをバックグラウンドに回し、終わったら結果を受け取るようになった。ツールの中で待たせたいときは CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND を立てる。

権限の挙動も増えた。permissions.denyInsteadOfPrompting を立てると、本来プロンプトで止まるツール呼び出しを確認せず拒否してターンを続ける。self-paced の /loop は、再スケジュールなしでターンが終わると自動で止まるようになった（CLAUDE_CODE_LOOP_KEEPALIVE=1 で従来動作）。

Claude が書いた mod を無断で有効化しなくなった

2.1.321 で、Claude が書いた mod は auto・bypass モードでも確認なしには有効化されず、dontAsk モードでは読み込まれなくなった。一方で mod 自身のツール呼び出し（$.tool.call・$.mcp.call）は許可プロンプトを出さなくなった。deny ルールと組織ポリシーはそのまま効く。

権限バイパスの修正も続いた。2.1.319 では、細工した環境変数のプレフィックスで Bash の権限チェックを回避できる問題と、accept-edits・auto モードで sed の権限チェックを抜けられる問題が直された。

エージェントの音声操作が広がる

Cursor がエージェントと音声で会話できるようにした

11/6、Cursor がエージェントとのリアルタイム音声通話を追加した。口頭で変更を指示し、作業中の内容を尋ね、進捗を音声で聞ける。Agents Window・IDE・web・iOS で使え、待機中に入力欄が空のとき waveform ボタンから始める。iOS では「Hey Siri, call Cursor」で呼び出せる。

音声エンジンは Grok Voice で、声は複数から選べる。Privacy Mode を有効にするとデータ保持なしで動く。入力欄に文字起こしするだけの dictation とは別の機能である。

出典（1）
  • Cursor Changelog: Voice Chat with Agents（2026/11/6・Grok Voice・Agents Window/IDE/web/iOS・Privacy Mode でゼロデータ保持）

Google Antigravity も音声モードを追加した

同じ 11/6、Google の Antigravity も Gemini Live を使った音声モードを足した。アプリと CLI で音声指示でき、エージェントは既定では静かに働き、答えや確認が要るときだけ話す。CLI では /voice live で始め、/voice duplex on にすると話しかけて割り込める。

11/9 時点では Cursor・Antigravity・Codex がいずれも音声でエージェントを操作し、進捗を聞けるようになっている。Claude Code の音声入力は、いまのところ文字起こし（dictation）にとどまる。

Cursor がアプリ公開まで引き受ける

Cursor がアプリを作って公開するところまで担う

11/5、Cursor が Build Live Apps を出した。cloud agent にアプリを頼むと、Cursor が雛形を組み、必要なら Postgres を用意し、Cursor SSO の裏で認証を設定し、hosting まで用意する。公開するときは独自ドメインを選び、セキュリティチェックを通ってから明示的に公開する。

チーム管理者は全アプリとシークレットを見られ、独自のレビュールールを足し、公開を取り消せる。共有は特定の人・グループ・チーム単位で Cursor サインインの裏に置ける。個人プランは一般公開もできる。cloud agents を有効にした有料プランで使える。
