Claude Code Projects が Pro・Max ユーザーへ開放

10/9、Claude Code Projects の待機リストにいた Pro・Max ユーザーが全員開放された。Projects は、1 つの長い会話の中で Claude が調整役になり、関連するタスクを並列のクラウドセッション（スレッド）に振り分けて進める仕組みだ。ローカルの作業と組み合わせることもでき、リポジトリ・指示・メモリは全スレッドで共有される。まだベータで、容量に応じて順次開放される。

Claude Managed Agents に動的ワークフローが入る

10/9、Claude Managed Agents の動的ワークフローがパブリックベータになった。リードエージェントが計画を書き、多数のエージェントがフェーズに分かれて走り、最後に結果を統合するマルチエージェント構成だ。トークン消費が大きいため、まずは範囲を絞ったタスクから始めて徐々に複雑にすることが推奨される。Claude Code からは /claude-api managed-agents-onboard bug-hunter で始められる。

あわせて Max・Team プランに月次 API クレジット（Max 5x で $100、20x で $200、Team は最大 $500）が付いた。クレジットは Messages API・Managed Agents・Agent SDK で使えるが、対話型の Claude Code セッションには使えない。定期実行で Slack や GitHub を読んで報告するエージェントを組む、といった自動化の土台になる。

続報週次リリースはアイドル圧縮と可観測性を追加

この週は 2.1.295〜2.1.300 が出た。大きいのは 2.1.299 のアイドル圧縮で、20 万トークンを超える会話が約 54 分放置されると、1 時間のプロンプトキャッシュが切れる前に自動で圧縮する。2.1.300 では Claude Platform と連動し、OpenTelemetry のトレースに GenAI セマンティック規約の属性が乗るようになった。

Devin が並列化と自動修正を押し出す

Devin が仕事を分割して並列実行する動的ワークフロー

Cognition が Devin に動的ワークフローを入れた。大きな仕事を分割して個々の Devin に渡し、結果を統合する。計画がエージェントの頭の中ではなくコードに残るので、どの Devin がどの順で何をするかが分かる。Devin は自分の配下に Devin を立てられ、タスクが数階層の木に広がる。直列なら全部の和の時間がかかる作業が、分割すれば最も遅い部分の時間で済む。同じ週に Anthropic も Managed Agents で似た動的ワークフローを出しており、並列オーケストレーションが各社の主題になっている。

Devin がセキュリティ調査と外部連携を広げる

Devin のSecurity Swarm は、並列の Devin をコードベースに送り込んで脅威モデルを作り、ファイルをまたいで連鎖する悪用可能な脆弱性を探し、サンドボックスで実証して修正を PR で渡す。サポート基盤 Pylon との連携では、チケットを Devin が自動で修正する（新規顧客に $15,000 のクレジット）。

モデル面では Gemini 4 Argon が Devin Desktop と CLI で使え、FrontierCode 1.1 で 60.5% と Gemini 系で最高を記録した（10/27 まで Devin ユーザーは 75% 引き）。課金では、個人の ChatGPT プラン（Go・Plus・Pro）を Devin につなぎ、GPT の利用をそのプランの枠から引けるようになった。

Claude に Dashboards と Motion

Claude がデータからダッシュボード、アイデアから動画を作る

10/8、Claude に Dashboards と Motion がベータで加わった。Dashboards は、データ基盤や CRM をつないで自然言語で質問すると、Claude がクエリを書いてダッシュボードを組み、データの変化に合わせて更新する。各チャートにはその元になったクエリが紐づく（有料プラン）。

Motion は、レポートやチャート、製品の操作手順を短いアニメーションにする。動画モデルを使わず各アニメーションをコードとして書くので、語句・数値・タイミングを後から変えて MP4 に書き出せる（Team・Enterprise プラン）。

出典（3）
  • @claudeai: Claude Dashboards と Claude Motion がベータに
  • @claudeai: Dashboards はクエリを書いて更新し続けるダッシュボードを作る（有料プラン）
  • @claudeai: Motion はアニメーションをコードで書き MP4 に書き出せる（Team・Enterprise）
