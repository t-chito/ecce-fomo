まとめ

先週の Opus 5 一斉展開が「載せ替え」の週だったのに対し、今週は各プロダクトが足元を固めるハードニングの週だった。Claude Code は 2.1.221／222／223 の 3 本を立て続けに出し、合計 79 変更の多くが権限・サンドボックス周りの穴埋めに割かれた——Bash 権限チェックの回避（[[ ]] 正規表現、タブや不可視 Unicode でのコマンド隠蔽）を塞ぎ、worktree 隔離を「ファイル編集と Bash」にも広げてメインリポジトリへの破壊的 git を遮断し、SendMessage は他エージェントへ渡す前に権限分類器を通すようにした。この流れは 1 社だけの話ではなく、Codex CLI 0.146.1 も「cyber 能力を持つモデル向けの安全寄りな auto-review 既定」を入れ、OpenAI・Anthropic・英 AISI がそろってサイバー評価の結果を公表——エージェントに長く任せる前提が広まったぶん、業界の関心が一気に「安全に走らせる」へ寄った一週間だった。プロダクト面では Devin が Fusion を安く・賢くし、Vercel Sandbox 上で隔離実行する Outposts を追加。コミュニティでは t_wada の「レビューが収束しないのは設計が誤っているサイン」という一言が広く共有され、CodeRabbit は「指摘」より「説明可能性」を売りに Claude レビュースキルと切り結んだ。

Claude Code

2.1.221〜223——権限とサンドボックスの穴を塞ぐ「ハードニング」の 3 連発

この一週間の Claude Code は 2.1.221（39 変更）・2.1.222（21 変更）・2.1.223（19 変更）の 3 本。派手な新機能より、エージェントを安全に走らせるための権限・サンドボックス修正が主役だった。権限チェックの回避を塞いだ修正が並ぶ：zsh の [[ ]] 正規表現条件で隠しコマンドが実行できた穴、PowerShell がクォートを含むパスを取りこぼす穴（2.1.221）、そして 2.1.223 ではタブや不可視 Unicode でパディングしたコマンドが承認ダイアログの表示から一部を隠せる問題や、細工したコマンドが権限チェックから自分の一部を隠せる Bash バイパスを修正した。

隔離まわりも一段強くなった。2.1.222 は worktree 隔離をファイル編集と Bash にも適用し、隔離セッションやその subagent がメインのチェックアウトに対して破壊的な git コマンドを実行できてしまう問題を全セッション種別で塞いだ。あわせて auto モードでは SendMessage で他エージェントセッションに送るメッセージをディスパッチ前に権限分類器で評価するようにし、PreToolUse の auto-allow フックがバックグラウンドエージェントのタスクでツール制限を迂回できた穴も修正。組織運用向けには、GitHub org 配下の全 marketplace リポジトリをまとめて許可／ブロックする owner/* ワイルドカードが managed settings に入った（2.1.223）。単に賢く動くことより、「任せても事故らない」の土台づくりに寄せた一週間だ。

Focus view と /review→/code-review——使い勝手の地味な底上げ

ハードニングの陰で、日々の操作感を上げる変更も入った。VSCode 拡張には Focus view が追加され、ツールの実行ログを「ターン単位の折りたたみサマリ＋実行中インジケータ」の裏に隠して画面のノイズを減らせる（Ctrl+Alt+F でトグル）。レビュー系は整理され、/review が /code-review のエイリアスになり、現在の diff や PR を対象に /code-review <level> <pr#> でレビュー、深いクラウドレビューは /code-review ultra、というふうに窓口が一本化された。effort を省くと前回指定したレベルを再利用する。

プラグイン／スキル周りも手触りが改善している。/plugin から入れたプラグインは安全なら即座に有効化（/reload-plugins 不要）、スタートアップ時にはワークフローエージェントや forked スキルが要求した subagent モデルが制限されて親モデルにフォールバックした場合の警告が出るようになった。クラウドセッションからローカルへ続きを引き継ぐ /teleport ヒントの表示（claude --teleport <session id>）も入り、実行環境をまたいだ継続が案内されるようになっている。

  • Claude Code Releases（GitHub）— Focus view／/code-review／/teleport
  • @ClaudeCodeLog — 2.1.221（Focus view ほか 39 変更）

「レビューが収束しないのは設計が誤っているサイン」——t_wada の一言が広く共有

使う側の知見として今週最も回ったのが、t_wada（和田卓人）の投稿だ。「レビューが収束しないのは設計の方向性が誤っているからだと判断し、学びだけをドキュメントや Skill に残してブランチを破棄した」——AI と往復しながらコードを直しても収束しないとき、それは細部の問題ではなく設計の問い自体が間違っているサインだ、という手触りの共有で、続く投稿でも「誤った問いを正しく解こうとしても収束しない」と重ねた。13万インプレッションを超え、実装を任せる側の間で強く共感を集めた。

エージェントに書かせる時代の実務では、生成物そのものより「どこで見切って、何を資産（ドキュメントや Skill）として残すか」の判断が効く、という話だ。プロダクトの新機能を追う一方で、同じツールをどう使いこなすかの知見が並んで注目された週でもあった。関連して、oikon48 らによる書籍『Claude Code 実践入門』の見本誌が届き 8/14 発売予定と告知され、変化の速い Claude Code を書籍に落とし込む登壇も行われた。

セキュリティ・権限管理が各社の主戦場に

Codex CLI 0.146.1 も「安全寄り既定」——業界そろってサイバー評価を公表

ハードニングは Claude Code だけの話ではなかった。OpenAI の Codex CLI 0.146.1 は「cyber 能力を持つモデル向けの、より安全な auto-review 既定」を導入し、ターミナル UI で権限変更の理由を説明し、0.146 のセキュリティ改善をバックポートした。前週の「Codex Security CLI を OSS 化」に続く、コーディングエージェントの実行を安全側に寄せる一連の流れだ。

背景として、同じ週に各社がサイバー評価の結果を相次いで公表した。OpenAI は外部評価パートナーによる cyber 評価中に起きた 2 件のインシデントを詳細化し、Black Hat では OpenAI–Hugging Face インシデントに関する発表を行った。英 AISI（AI Security Institute）は Anthropic の Claude Mythos 5 と OpenAI の GPT-5.6 Sol を対象に、通常の安全策を外した設定でのサイバーセキュリティ評価レポートを公開。モデルとエージェントに「悪用されうる能力」が積み上がるほど、プロダクト側の既定を安全に締める動きが同期している。

  • @Codex_Changelog — Codex CLI 0.146.1（cyber モデル向け安全既定）
  • @OpenAI — 外部サイバー評価での 2 件のインシデントを詳細化
  • @AnthropicAI — 英 AISI による Claude Mythos 5／GPT-5.6 Sol のサイバー評価

Devin：安く・賢く、そして隔離実行環境へ

Fusion が 27% 安く 4% 賢く、Outposts は Vercel Sandbox の microVM で走る

Cognition の Devin は、モデル差し替えより足回りのコスト効率で動いた。ハーネスとモデル双方の改善で、Devin Fusion が FrontierCode 1.1 で 4% 賢く・27% 安くなったと告知。派手なモデル更新のない週に、同じタスクを安く回せるようにする地道な最適化を前に出した。

実行環境の選択肢も広げた。Devin Outposts を Vercel Sandbox 上で動かせるようになり、隔離された microVM の中で Devin がアプリのビルドとテストを回せる。Vercel Sandbox 内では Docker を実行し、VPN 経由でプライベートネットワークに接続し、リポジトリ・依存関係・ビルド状態を保持したファイルシステムスナップショットから再開できる。エージェントを「安全に隔離した箱の中で実運用に近い形で走らせる」という、今週の業界テーマ（隔離・権限）とも重なる動きだ。

  • @cognition — Devin Fusion が FrontierCode 1.1 で 4% 賢く・27% 安く
  • @cognition — Devin Outposts を Vercel Sandbox の microVM で実行

コードレビュー：「指摘」から「説明可能性」へ

CodeRabbit が Claude レビュースキルと切り結ぶ、GitHub 30 万インストール

Claude Code に /code-review が整理され、カスタムの Claude レビュースキルも広まるなか、専業の CodeRabbit が立ち位置を明確にした。同じ PR で「カスタム Claude レビュースキル対 CodeRabbit」を比較し、「どちらも指摘は拾う。でも仕事は"指摘すること"ではない。文脈の中で・スケールして・説明可能であることだ」と主張。汎用エージェントのレビューに対して、専業ツールの差別化軸を「説明可能性（explainability）」に置いた。

数字の裏づけとして、CodeRabbit の GitHub アプリは 30 万インストールを達成。具体例として、Trivago が「toSorted が全ブラウザで未サポート」という CodeRabbit の指摘で修正を入れ、数か月後に約 21 万セッションの破損・最大 10 万ユーロの潜在的影響を未然に防いだ事例を紹介するなど、"どの指摘がなぜ効くか"を語れることを前面に出している。汎用コーディングエージェントがレビューまで飲み込みつつある局面で、専業側が何で勝負するかが見えた週だった。

  • @coderabbitai — GitHub 30 万インストール達成
