Claude Code

続報週次リリースで長文脈の自動継続と Monitor ツールが入る

この週は 2.1.308〜2.1.312 が出た。2.1.311 では、標準コンテキストのセッションが 200K トークンを超えると「1M 契約が要る」と止まっていたのを直し、自動で圧縮して続行するようにした。ultrathink は対応モデルで xhigh 相当の思考量で走るようになった。2.1.310 では Monitor ツールとプラグイン monitor が Bedrock・Vertex・Foundry でも使えるようになった。

安全側の修正も多い。2.1.309 は、サンドボックスの Bash が各コマンドの前にシェルの起動ファイルを枠の外で実行してしまう穴をふさぎ、--mcp-config で渡した設定ファイルを自動承認の編集が書き換えられる問題も直した。2.1.312 は、冒頭だけ見て巨大な CLAUDE.md や @ 取り込みファイルを上書きする不具合を直した。

Agent Skills を Agentic AI Foundation へ寄贈

10/22、Anthropic が Agent Skills を Agentic AI Foundation に寄贈した。MCP を寄贈したのと同じ財団で、仕様を中立な場に移して業界共通の土台にする狙いだ。Skills は Claude Code の実験として始まったものだという。

2025 年 12 月以降、ChatGPT・Cursor・GitHub Copilot・VS Code を含む 70 以上のエージェント基盤がこの仕様を取り込んでいる。特定のツールに閉じた拡張ではなく、どのエージェントでも同じ Skill が動く前提が広がりつつある。

Claude が MCP の Tasks と Elicitations に対応する

コーディング支援ツールが脆弱性対応へ向かう

続報Devin Security が脆弱性の発見と修正を担う

10/26、Cognition が Devin Security を出した。Claude Mythos とフロンティアのサイバー向けモデルを土台に、緊急の脆弱性をチームが見つけ、優先順位を付け、直すところまで Devin が手伝う。「サイバーセキュリティの新たな暗黒時代に入りつつある」とし、導入を後押しするため数億ドル規模のクレジットを付けるという。先週の Oncall・Fusion に続く Devin の機能拡張だ。

CodeRabbit が脆弱性を実証してから指摘する

10/27、CodeRabbit Secure の Deep Scan が更新された。脆弱性を連携済みのリポジトリ群にまたいで追跡し、使い捨てのサンドボックスで実際にエクスプロイトを再現して、本物だと確かめてから指摘する。指摘する前に実証を挟むことで、誤検知で開発者の手を止めない作りを狙う。
