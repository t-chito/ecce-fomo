Claude Code

MCP サーバーが提供する skill を使えるようになった

2.1.332 で、MCP サーバーが配布する skill を Claude Code 側で使えるようになった（beta）。これまで skill はローカルやプラグインから読み込むものだったが、MCP サーバーを足せばそのサーバーが持つ skill をそのまま呼べる。

あわせて PreSkillShellCommand hook が追加された。skill がシェルコマンドを実行する前にこの hook が走るので、外部コマンドを叩く前に確認や制御を挟める。

出典（1）
  • Claude Code Changelog（2.1.332：MCP サーバーからの skill を beta で追加・PreSkillShellCommand hook を追加）

定期タスクと /loop が最長30日まで動くようになった

2.1.330 で、スケジュールされた定期タスクと /loop の継続期間が、従来の7日から最長30日に延びた。長期で回す監視・巡回タスクを、途中で切れずに流し続けられる。

2.1.329 では /tasks にスケジュールタスクと /loop の起床予定が並ぶようになり、次にいつ何が動くかを一覧で確認できる。なお旧版で保存したスケジュールタスクは、新しいセッションで登録し直す必要がある。

出典（1）
  • Claude Code Changelog（2.1.330：定期タスクと /loop を最長30日に延長／2.1.329：/tasks に起床予定を表示・保存済みタスクは再登録が必要）

続報Code Mode が主要クラウドのターミナルでも動くようになった

2.1.331 で、Claude が JavaScript を書いて自分のツールを呼ぶ Code Mode が、ターミナルセッションでも Amazon Bedrock・Google Cloud の Agent Platform・Microsoft Foundry・AWS 上の Claude Platform で動くようになった。主要クラウド基盤のターミナルからも Code Mode を使える。

同じ版で claude doctor に API 接続のチェックが加わり、疎通が通らないときの切り分けがしやすくなった。

出典（1）
  • Claude Code Changelog（2.1.331：Code Mode を Bedrock・Google Agent Platform・Microsoft Foundry・AWS 上 Claude Platform のターミナルセッションで有効化・claude doctor に API 接続チェック）

続報root や作業フォルダを狙う rm に確認が入るようになった

2.1.330 で、root・ホーム・作業フォルダを対象にする rm コマンドの多くが、実行前に確認を求めるようになった。意図しない広範囲の削除を手前で止める。

2.1.332 では macOS の computer use の安全ルールも更新された。破壊的な操作を自動で走らせないよう、権限まわりの確認が各所で足されている。

エージェントの作業を見える化する

Antigravity が自律実行の進捗を逐次表示するようになった

Google の agent-first IDE、Antigravity が、自律実行中の進捗をリアルタイムのチェックリストで見せるようになった（v2.34.0）。補助ペインの Task タブに計画の各ステップが並び、実行中・並列中・完了がその場で分かる。各ステップを開けばツール呼び出しや差分、途中結果まで辿れる。

10〜20分かかる長い実行や、複数のサブエージェントが同時に動く場面で、ターミナル出力を拾い集めずに全体の進み具合を把握できる。無料クライアントでも使える。

出典（1）
  • AlphaSignal: Google Antigravity Now Shows Live Agent Progress（2026/11/24・v2.34.0・Task タブのライブチェックリスト・ステップ展開でツール呼び出しや差分・無料クライアントで利用可）

Codex CLI の TUI ワークスペースが既定になった

OpenAI の Codex CLI で、TUI ワークスペースが既定になった（0.171.0）。メインの会話の横に、検索できるドキュメントプレビュー・画像プレビュー・サブエージェントの記録が並び、長い作業で何が起きているかを 1 画面で追える。同じ版で GPT-6.2（Sol・Astra）がモデル一覧に加わり、Sol が既定になった。

続く 0.172.0 では、検索結果やトランスクリプトのリンクから、保存した会話やネストしたエージェントをターミナルで直接開けるようになった。
