Claude Code

続報この週の更新は個人情報と書き込みの安全策が中心

この週は 2.1.314〜2.1.318 が出た。安全側の調整が目立つ。Web 検索やシェルのツールがアカウントのメールアドレスを外部へ送る前に確認を挟むようになった。クラウドのスケジュール実行では、頼んでいない connector が付いたときに /schedule が警告する。

書き込みの制限も入った。permissions.blockWritesOutsideWorkingDirectories を立てると、Write・Edit・NotebookEdit が作業ディレクトリの外へ書くのを拒む。deniedMcpServers に挙げた URL は、同じ宛先の Anthropic 提供サーバーもまとめて止めるようになった。

Opus 4.8 の Fast モードが 11 月 30 日に廃止される

2.1.316 で、Opus 4.8 の Fast モードを 11 月 30 日に廃止すると告知された。廃止後は Opus 4.8 への Fast モード要求はエラーになり、別のモデルへは切り替わらない。速さを保つには Opus 5.5 へ移る必要がある。スクリプトで Fast モードを前提にしていると動かなくなるので、期日までの移行が要る。

あわせて思考量を環境変数から制御できるようになった。CLAUDE_CODE_SUBAGENT_EFFORT でサブエージェントの思考量を決め、CLAUDE_CODE_DISABLE_ULTRATHINK で ultrathink を無効にできる。

IDE 拡張をエディタ起動時に自動導入しなくなる

2.1.318 から、IDE のターミナルで Claude Code を起動しても IDE 拡張を自動では入れず、更新もしなくなった。入れたいときは外のターミナルから /ide を使う。2.1.314 では、放置したセッションの自動要約（idle compaction）が、ターミナルに続いて VS Code と Claude Desktop の Code タブにも広がった。

細かい使い勝手も直った。2.1.317 では Read ツールの「ファイル変更なし」のスタブをやめ、読み直すと中身がそのまま返るようになった。別モデルで動くサブエージェントは、セッション側ではなくそのモデルの思考量で走る。

Devin が低価格・高速の SWE-2 Flash を載せる

Codex がキュー再開とネットワーク診断を加える

Codex がキュー再開とネットワーク診断を加える

10/29、OpenAI の Codex CLI が v0.166.0 になった。codex queue --resume で、まだ読み込んでいないスレッドを、キューに積んだメッセージから再開できる。codex doctor --network-only は設定・接続・WebSocket の診断だけを回す。TUI ではキーボードだけでトランスクリプトを選び、検索もできるようになった。

モデル面では GPT-6.1 Terra が同梱・Vertex AI・Amazon Bedrock のカタログに加わった。安全方針で処理を止めたときは理由を示し、より安全な言い換えを選べるようにした。
