まとめ

先週が「任せるを既定にする」週だったなら、今週の Claude Code は手触りを磨く週だった。目玉は /design（リサーチプレビュー）——Claude Design のアートボード編集を CLI／Desktop に持ち込み、「コードを書く前にデザインを触る」導線が公式機能として入った。あわせて出力スタイル Concise、CLI が p99 で CPU 半減・Desktop 起動が約2倍速という地味だが効く性能改善、そして週次利用上限の +50% を 8/31 まで延長と、日々の摩擦を削る更新が並んだ。プロダクト外周では今週最大の地殻変動が起きている。Cursor が SpaceX による 600億ドルの買収を完了して SpaceXAI 傘下に入り、その 4 日後にエージェント前提のコードホスティング「Origin」を——よりによって GitHub が大規模障害を起こした当日に——投入して GitHub に正面から並んだ。Devin はモデルを次々と無料・大幅割引で開放し、CodeRabbit は先週の 1.43 億ドル調達を「5 日で 3 プロダクト」の製品ラッシュ（Security／Triage／Change Stack）に変えた。Claude 本体も Cowork のモバイル／Web 解放や Gmail・Drive 連携で外へ広がっている。

Claude Code

Claude Code がデザインできるようになった——/design でアートボードを CLI に

今週いちばんの新機能は /design スキル（リサーチプレビュー）だ。Claude Design のアートボード・ワークフローを CLI と Desktop の両方に持ち込み、Artifacts の上で動く。/design と打つと、作りたい UI の編集可能なアートボードが出てきて、気に入ったものを選んで手で微調整し、そのまま Claude に実装させる——「まず言葉で仕様を詰める」前に「まず見た目を触る」導線がコーディングエージェントの中に入った格好だ。

反応も早かった。@ClaudeDevs の告知は約 1.5 万いいね・166 万インプレッションに達し、個人エンジニアの trq212 は「/design <作りたいもの> を今すぐ打て」とだけ書いた投稿で拡散させた。日本語圏でも oikon48 が「Claude Design のキャンバスエディタを実行し、マルチアートボードのビジュアルを .dc.html のアートボードとして 1 枚のパン／ズーム可能なキャンバス上にドラフトする」と要点を紹介。コード生成一辺倒だったエージェントが「設計フェーズ」に足を伸ばした、プロダクトとしての方向転換を象徴する一手だ。

  • @ClaudeDevs — Claude Code can design now（/design リサーチプレビュー）
  • @trq212 — 「/design <作りたいもの> を今すぐ打て」
  • @oikon48 — /design スキルの中身を日本語で紹介

軽く・速く・簡潔に——Concise 出力と、CPU 半減・起動2倍速の地ならし

派手さはないが日々効く更新が固まって出た。2.1.237 で出力スタイル Concise が追加され、Claude は結論を先に述べ、前置き・冗長な説明・ナレーションを省くようになった（探索や確認を挟んでも、その過程ではなく結果だけを返す）。/config → Output style か settings.json の "outputStyle": "Concise" で有効化でき、必要なら従来どおり詳細も引き出せる。

性能面では、Claude Code CLI が p99 で CPU 使用量を半分に。原因は Bun のガベージコレクタが固定タイマーで動き、Claude が最も忙しい処理の最中に割り込んで CPU を奪っていたことで、これをプロセスがアイドルになるまで待つ方式に変えた。Claude Desktop の起動も 1 か月前比で約2倍速に——バックグラウンド起動時にタイマーが絞られて JS エンジンが省電力モードに落ちていたのを、ウィンドウが隠れていても全速で起動するよう修正した。「賢くする」だけでなく「軽く・速く・簡潔に」というプロダクト品質側の投資が、今週はまとめて表に出た。

  • @ClaudeDevs — 出力スタイル Concise を追加
  • @ClaudeDevs — CLI が p99 で CPU 半減（Bun GC の割り込みを解消）
  • @ClaudeDevs — Claude Desktop の起動が約2倍速に

利用上限まわりの緩和——週次 +50% を 8/31 まで延長、止まっても自動で再開

運用の一番痛いところ、レートリミットにも手が入った。週次の Claude Code 利用上限の +50% 増量を 8 月 31 日まで延長し、Anthropic は「恒久化したいが、モデル需要が強く今後数週間は capacity が厳しいかもしれない」と正直に添えた。この告知は約 2 万いいね・340 万インプレと、今週の x で最も強い反応を集めている。

上限に当たったときの体験も改善された。Desktop では「上限リセット後に自動で作業を続ける」チェックボックスが入り、CLI 側でも 2.1.234 でclaude.ai の利用上限がリセットされると自動でセッションを再開する挙動が加わった。長時間タスクを回す前提の運用で「上限で止まって放置される」事故を減らす、地味に効く一手だ。

  • @ClaudeDevs — 週次利用上限の +50% を 8/31 まで延長
  • @ClaudeDevs — Desktop に自動継続チェックボックス
  • Claude Code Releases（2.1.234：上限リセット時の自動再開）

2.1.232〜237——サブエージェント fork が既定、@メンションで別セッションへ、GitLab 一式

リリースは一週間で 2.1.232 から 237 まで。基盤側の効く変更が多い週だった。2.1.232 でサブエージェントの fork が既定になり、会話とプロンプトキャッシュを丸ごと継承するようになった。あわせてプロンプト内の @ メンションで別の Claude セッションに直接届く（先週の SendMessage の続き）。2.1.236 では新規セッションの既定モデルを指す ANTHROPIC_DEFAULT_MODEL 環境変数、SendMessage の notify_when_idle、auto モードで Monitor の許可ルールを Bash 同様に審査する変更などが入った。

GitLab 対応がまとまって進んだのも今週で、MR URL を --worktree やエージェントビューで扱えるようになり、フッターに MR バッジ、マーケットプレイスのクローン対応、glrt-／gloas- などトークンの秘匿化まで揃った。セキュリティ面では NTLM 資格情報の漏洩ベクタや Cygwin 風シンボリックリンク・PowerShell 経由の権限バイパスを塞ぎ、claude-api スキルの文脈コストを約 20 万→2.5 万トークンに圧縮。エージェント運用基盤の Managed Agents にも 3 更新が入り、Self-Hosted Sandbox の作業を memory に保存できるようになった。導入事例として、ABC Legal が 50 以上のエージェント群で特定の法務タスクのコストを最大 50% 削減した話も公開された。

  • Claude Code Releases（GitHub、2.1.232〜237 の一次情報）
  • @ClaudeDevs — Managed Agents に 3 更新（Self-Hosted Sandbox の memory 保存ほか）
  • @ClaudeDevs — ABC Legal が 50+ エージェントでコスト最大 50% 削減

Cursor：SpaceX 傘下入りと、GitHub 障害の日に投入した「Origin」

600億ドルの買収完了、4日後にエージェント前提のコードホスティングで GitHub に並ぶ

今週の外周で最大の動きは Cursor だ。8 月 14 日、SpaceX による 600 億ドル（全株式）の買収が完了し、Cursor は SpaceXAI 傘下に入った。公式アカウントは「Welcome to the SpaceXAI team! Cursor はソフトウェアエンジニアリングから知識労働へと、最も有用な AI への道を加速させる」と投稿し、約 1.6 万いいね・780 万インプレを集めた。

そして買収後初の大型プロダクトが 4 日後に来た。8 月 18 日、Cursor は「Origin」——エージェント前提で設計されたコードホスティングを有料ユーザーに投入した。PR・コードレビュー・リポジトリ保管を備え、Vercel／Depot／Buildkite が初日から連携。既存の GitHub リポジトリを同期して相互運用でき、Cursor デスクトップの新タブと専用 CLI から触れる。象徴的だったのはタイミングで、投入と同じ日に GitHub が約 6 時間 42 分・エラー率 2 割規模の大規模障害を起こし（Cursor 側は「狙ったわけではない」と釈明）、ネットは「GitHub の代替が来た日に GitHub が落ちた」と沸いた。コーディングエージェントがエディタからホスティングまで垂直統合しにいく——プロダクト選びの土俵が「補完の質」から「開発フロー全体をどこに置くか」へ広がったことを示す一件だ。

  • @SpaceXAI — Cursor が SpaceXAI チームに加わる
  • TechCrunch — Cursor が GitHub 対抗のホスティング「Origin」を投入
  • SiliconANGLE — Origin の機能と GitHub 同期
  • TechCrunch — SpaceX が Cursor 買収を正式完了

Devin：モデルを次々と無料・大幅割引で開放

SWE-1.7 と GLM-5.2 を1か月無料、GPT-5.6 Sol は70%オフ——「載せ替えの速さと安さ」で攻める

Cognition の Devin は、今週も「どのモデルを、いくらで使えるか」を武器にした。自社モデル SWE-1.7 と GLM-5.2 を 1 か月間無料で開放（Pro・Max・Teams が Devin Desktop／CLI で使い放題）、さらに GPT-5.6 Sol を 10 月 3 日まで 70% オフで提供すると告知した。Sol は FrontierCode 1.1 でトップ級の結果を出すモデルで、割引で「最もコスパの良いフロンティアモデルの一つ」に位置づける狙いだ。

実利用の裏づけも出した。GE Aerospace が Devin を導入し、あるチームは出力をほぼ倍増させたという事例を公開。基盤モデルが出るたびに最速で載せ替え、価格で選ばせ、導入事例で説得する——プロダクトとしての Devin の戦い方が、今週も一貫して見えた。

  • @devindesktop — SWE-1.7 と GLM-5.2 を1か月無料
  • @devindesktop — GPT-5.6 Sol を 10/3 まで 70% オフ
  • @cognition — GE Aerospace の Devin 導入事例

CodeRabbit：調達を「5日で3プロダクト」の製品ラッシュに変える

レビューから「変更管理」へ——Security・Triage・Change Stack を立て続けに投入

先週「1.43 億ドルのシリーズ C」と「Agentic Change Management への看板掛け替え」を掲げた CodeRabbit は、今週その宣言を製品で埋めにきた。同社は「1.43 億ドルを調達し、5 日で 3 プロダクトを発表した」として、CodeRabbit Security・CodeRabbit Triage・CodeRabbit Change Stack を立て続けに公開した。

目玉の CodeRabbit Security は「AI Deep Scan」でソースコードとインフラ設定を横断し、悪用可能な脆弱性を洗い出す。各指摘にカテゴリ・深刻度・CWE・ファイル・行範囲・到達可能性を付け、開発者が自力でも AI と一緒でも直せる形にする。「ルールベースのスキャナは、誰かが既に思いついた攻撃のリストにすぎない。まだ誰も書き留めていない攻撃のために作った」というメッセージで、汎用エージェントがレビューまで飲み込む流れに対し、専業らしく変更フロー全体の統制へ製品ラインを広げた格好だ。

  • @coderabbitai — 5日で3プロダクト（Security／Triage／Change Stack）
  • @coderabbitai — CodeRabbit Security の AI Deep Scan

コミュニティ：中の人が示す「保守を丸ごと任せる」運用

Boris の「Claude にアプリ保守を任せる」実験と、PR を緑にするまで回す使い方

プロダクトの使い方として今週共有されたのは、「任せる」を本気で運用に落とし込む話だった。Claude Code チームの Boris Cherny（@bcherny）は、ここ数週間、日々のアプリ保守を Claude に任せる実験をしていると投稿。proj-claude-maintains-apps という Slack チャンネルを作り、Claude（Claude Tag／Claude Code）に毎日自動で走るルーチンを複数実行させ、iOS・Android・Desktop・Web・CLI・Agent を対象にしているという。「まだ実験だが、成立しうる兆しが見えてきた」との温度感だ。

個人エンジニアの実践も具体的だった。amorriscode は「PR は全部 Claude Code デスクトップアプリから作らせ、CI が緑になるまで Claude 自身に反復させる」運用を紹介し、自分はより高レバレッジな仕事に集中できるようになったと書いた。auto モードの既定化や利用上限の緩和といった今週のプロダクト更新は、こうした「人はレビューだけ、実行は任せる」運用を後押しする方向で噛み合っている。

  • @bcherny — Claude に日々のアプリ保守を任せる実験
  • @amorriscode — PR を全部 Claude に作らせ、緑になるまで回す
