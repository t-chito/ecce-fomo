まとめ

今週は派手な新機能より、エージェントを本番で回すための「統制・コスト・実行基盤」を各社が同時に固めた週だった。最大の一手は Fable 5.1——Claude 5 系の最上位として 9/1 に GA になり、キャッシュ読みが 75% 安くなった。これが即座に効いて、Claude Code は Fable 5.1 を既定の Fable モデルに採用、Devin も Fable 級の実効コストを大幅に下げた。Claude Code 本体は --restricted・組織管理の MCP サーバ・モデル切替フック・支出上限バーと、"締める／見える化する"更新を積み上げた。周辺では Cursor が実行を自社ネットワーク内で回す self-hosted machines、Codex が Vim とプラグイン市場で日常の編集体験を、Devin がコードスキャンを定期自動化へ寄せた。

Claude Code

Fable 5.1 が既定の Fable モデルに——最上位モデルが「キャッシュ 75% 減」で降りてきた

9/1 に Claude Fable 5.1（claude-fable-5-1）が一般提供になった。Claude 5 系で Opus 5 の上に立つ最上位モデルで、数時間規模のコーディングや複数アプリをまたぐ長時間エージェント作業に振った設計だ。入出力価格（$10 / $50 per Mtok）は据え置きのまま、キャッシュ読みが $0.25 per Mtok と 75% 下がったのが実務上の目玉——同じ文脈を何度も舐めるエージェント用途では、繰り返し参照のコストがそのまま効いてくる。

Claude Code は 2.1.257 でこの Fable 5.1 を「既定の Fable モデル」に採用した。Claude Code / API では effort=high、Cowork / claude.ai では medium が既定で、思考は常時オン。1M トークンのコンテキストを持つ最上位モデルが、追加設定なしで手元のエージェントに載る格好だ。「賢いモデルは高くて常用しづらい」という前提を、キャッシュ価格の側から崩しにきた一週間だった。

2.1.248〜259——`--restricted`・組織管理 MCP・モデル切替フックで「締める」側の更新

今週のリリースは「エージェントに何をどこまで許すか」を細かく握る方向に厚かった。2.1.248 では --restricted フラグが入り、組み込みツールを外し、ファイルアクセスを作業ディレクトリ内に限定できるようになった。あわせて agent frontmatter の experimental.cacheTtl でエージェント単位の prompt キャッシュ TTL を持てる。2.1.259 では組織が全ユーザーに HTTP/SSE の MCP サーバを配る managedMcpServers 管理設定と、無人ヘッドレス向けの --permission-prompts none、GitLab のマージリクエスト記法（MR !N）認識が加わった。

2.1.251 の PreModelSwitch / PostModelSwitch フックは、セッション途中でモデルが切り替わる瞬間に処理を挟める。先週コミュニティで「セッション中にモデルを変えるとプロンプトキャッシュが壊れる」という注意が共有されたが、その"切替イベント"自体を捕まえられるようになった格好だ。実際 2.1.259 では OAuth トークン更新時にプロンプトキャッシュが無効化される不具合が修正され、2.1.248 でも「長時間セッションで 1 時間に一度ほどキャッシュがミスする」問題（ツール定義の再描画が原因）が潰された。地味だが、キャッシュを"壊さない"ための修正が今週まとめて入っている。

支出とキャッシュを"見える化"——/usage の支出上限バー、/cost の prompt キャッシュ行

コスト側の可視化も一段進んだ。2.1.251 で /usage に支出上限バーが付き、ステータスラインに rate_limits.spend_limit フィールドが追加された。同版の /cost にはセッション単位の prompt キャッシュ行（ヒット率と指標）が入り、キャッシュが効いているかを一目で確認できる。前段の Fable 5.1 のキャッシュ値下げと合わせて読むと、今週の Claude Code は「キャッシュを効かせて安く回す」を計測・制御できる状態に寄せてきたのが分かる。

あわせて運用者に効くのが週次上限の恒久化だ。夏の +50% 増量プロモは 8/31 に終了し、9/14 以降は各プランのベースラインに対する恒久 +25% 増へ置き換わる（Pro / Max / Team / Enterprise 対象）。一時的なボーナスから、常時使える底上げへと切り替わる。

Cursor：エージェントの実行を「自社ネットワークの中」で回す

self-hosted machines——AWS Lambda・Cloudflare・Modal・Vercel 上でエージェントを走らせる

Cursor は 9/2 に self-hosted machines を出した。エージェントのツール実行を自分たちのネットワーク基盤の中に留めるのが狙いで、個人の単一マシン向けの「My Machines」と、需要に応じて容量を伸縮するチームプールを用意した。実行先として AWS Lambda・Coder・Cloudflare・Daytona・Modal・Namespace・Vercel・E2B といった既存インフラを指定でき、アイドルなマシンを休止させてコストを抑える。Linux / Mac ではデスクトップ操作を伴う computer use にも対応する。

方向性は明快だ。Claude Code の --restricted や組織管理 MCP が「エージェントに与える権限を絞る」なら、Cursor は「エージェントが動く場所そのものを自社の管理下に置く」。コードや秘密情報が外に出ることを警戒する組織にとって、実行基盤を自前化できるかどうかは導入可否を分ける論点で、そこに正面から応えにきた。少し前（8/27）の「リポジトリ無しでゼロから始めて Vercel に公開まで」機能と合わせ、Cursor は"クラウドエージェントの入口と土台"を同時に広げている。

  • Cursor Changelog（9/2：self-hosted machines、8/27：リポジトリ無しで開始）

Codex：Vim とプラグイン市場で「毎日の編集体験」を作り込む

Vim の検索・undo/redo、リモート market からのプラグイン導入

OpenAI の Codex CLI は今週、地味だが常用者に効く作り込みを重ねた。0.152.0 で Vim の検索（/ と ?、マッチのハイライト）が入り、続く 0.153.0 で Vim の undo/redo（u と Ctrl+R）が加わった。プロンプト入力欄が本格的な Vim 操作に耐えるようになり、エディタから CLI に降りてきても指の運びが途切れない。TUI 履歴は完全なパッチと端末入力を表示するようになり、何をどう変えたかを遡りやすくなった。

拡張性も広げた。0.153.0 ではプラグイン CLI がリモートのマーケットプレイスからプラグインを list / install / remove できるようになり、0.151.0 では拡張がモデル処理の前に MCP ツールの結果を横取り・改変できる仕組みと、任意 MCP サーバのツール発見に猶予期間を設ける設定が入った。0.152.0 の操作つきレート制限バナー（使用状況の確認・クレジット管理・上限リセット・プラン管理へ導線）も、日々の摩擦を減らす一手だ。「賢さ」より「手に馴染む道具としての完成度」で詰めてくる週だった。

  • Codex Changelog（0.151.0〜0.153.0：Vim、プラグイン市場、MCP 結果の横取り）

Devin：コードスキャンを「定期自動化」の対象に

デッドコードを見つける cleanup scan、/scan コマンド、スケジュール実行

Cognition の Devin は 9/2 にコードスキャン周りを厚くした。新設の cleanup スキャンはリポジトリ内のデッドコードや整理候補を洗い出す。コンポーザから /scan で直接スキャンを起動でき、さらに自動化（Automations）がコードスキャンをエージェント種別として扱えるようになった——つまり定期スキャンのスケジュール化や、新しいコミットの自動再スキャンが組める。findings（検出結果）タブはトリアージしやすいよう作り直され、GitLab・Jira・incident.io・GitHub のトリガーではイベント詳細が richer になった。

コスト面でも Fable 5.1 の波が届いた。Devin ではFable 級の知能が実効で大きく安くなり（キャッシュ方式の変更により、Opus より安い水準）、GPT-5.6 Sol も 10/3 まで 70% 割引で使える。レビュー系（CodeRabbit の Blast Radius など）に続き、Devin は「書く」だけでなく「溜まったコードを定期的に掃除する」役割を自動化の型に落とし込みにきている。エージェントの仕事が"一発のタスク"から"回り続ける運用"へ寄る流れが、今週も各社で揃った。
